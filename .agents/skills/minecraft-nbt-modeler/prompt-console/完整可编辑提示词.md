# 全局设计与细节要求
空间分区与高差：入口过渡区连接主活动空间，主题节点布置在可见且可达的位置；辅助空间与主体联合设计。
玩家动线与空间连接：按普通玩家尺度保留连续通路，明确门口、平台高度与必要目标，具体坐标由 Agent 对照完整几何补齐。
主材石砖；次材安山岩；木构仅用于有支承的局部构件。先做结构层次，再做材质。

天花板与顶构：梁架/拱券有真实落点；顶面节奏对应柱网与功能；墙顶、梁端、吊挂基座收口完整。
地板与平台：铺装回应动线与功能；台阶、桥头、平台有厚度与连续收边；适量成片磨损，必要通路平顺。
墙面与开口：有墙脚、主体与顶部层次；门窗有厚度与过梁；壁龛保留外壳；避免所有墙等距复制同一组道具。
道具与密度：道具有安装与使用空间；关键节点集中细节，其余区域保留留白。
保留项：保留主轮廓、必要路线、端口、安全到达点、承重支撑和主题节点。
其他要求：不要为满足工具清单强行添加不适用效果。
