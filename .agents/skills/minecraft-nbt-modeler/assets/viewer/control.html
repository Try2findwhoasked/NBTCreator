怎么打开建筑？

先选择保存建筑的项目文件夹，再从列表选择建筑，应用会自动载入。找不到时，清空搜索、点击“刷新”，或用“打开 NBT / 主模型…”直接选文件。

默认每座建筑只列较新的版本；勾选“显示较早版本”可找回旧稿。每次预览都以当前选中的文件为起点，多次调参不会把效果一层层叠加到原文件上。

下面的数字怎么看？

尺寸按 X × Y × Z 显示，单位是方块；Y 是高度。“实体方块”是不为空气的方块数。“单独记录的墙体”是作者标记的墙层，不等于画面里所有看起来像墙的部分。

每次都从选中的建筑开始计算，效果不会一轮轮叠加。

什么时候手动填写路径？

正常从列表选择时无需填写。只有 Agent 给了你一组建筑文件，或自动识别不完整时才使用下面的入口。

完整建筑文件填主模型或引擎支持的完整 NBT；保护设置填门口、通路、支撑等约束的 JSON；视角文件填相机 JSON，可留空。路径必须对应同一份建筑。只有 NBT、缺少作者配置时，可以先查看 3D，修改和导出仍需补齐配置。

“份数”就是相对比例

例如石砖填 7、苔石砖填 2、裂石砖填 1，目标配比就是 70%、20%、10%。不必凑到 100，填 70、20、10 的含义相同。某项填 0 就不参与，至少有一项要大于 0。

会改到哪些方块？

先启用“方块混搭”，再在“要替换的原方块”中指定对象。例如只填 stone_bricks，就不会顺带替换木头。作用范围、保护设置和混搭强度也会限制实际改动。

“零散混搭”适合细碎变化；“成片混搭”适合成块的材质分区。色块越大，材质越容易连成片。

比例是目标配比，小区域或保护区较多时，实际数量可能有偏差。同一建筑、同一组参数和随机编号可以复现效果；修改后先看效果预览，满意再导出。

图片、3D、效果预览有什么区别？

图片是生成时的固定画面，不会随左侧调参更新。需要新的原建筑图片时，点击底部“为原建筑生成预览图”。3D 可以旋转、切层查看；打开后图片栏会隐藏，点击“看图与提意见”即可返回。

调参后点击“更新效果预览”，再用“看原建筑 / 看调整效果”对比。效果预览只展示候选变化，应用内执行导出才会保存新的建筑文件；也可以复制方案给 Agent，由 Agent 在原建筑工作文件夹保存下一版。

怎么描述要改的位置？

看图片时点击画面；看 3D 时先点“3D 选点评论”，再点击建筑表面。可连续选多个点，输入框会插入 #1、#2 等编号。例如“#1 柱脚加厚；#2 门口留出两格通道”。未保存的编号可点击移除；“清空选点”只清除当前草稿的位置。

没有选点也能保存，用来描述整张图或整座建筑。图片标记记录画面位置，3D 标记记录方块坐标；切换图片或模型时，请留意上方的当前对象。

怎么引用效果、保存和查看？

输入 @ 可选择已保存的效果文件，用 ↑↓ 选择、Tab 补全；新文件没出现时点“刷新 @ 文件”。写完点“保存这条意见”或按 Ctrl+Enter，文字和位置才会一起写入文件。下方是已保存意见，可搜索、筛选并标为已解决。

“下载修改意见”会导出当前图片或 3D 对象的已保存意见，方便交给 Agent。保存意见只记录需求，不会自动修改建筑，也不等于同意执行精修。

我只是想调好效果并保存建筑
选择建筑 → 调整左侧工具 → 点击“更新效果预览” → 对比原建筑与调整效果 → 点击“导出建筑下一版”。开启自动预览时，调参后稍等即可更新。若导出按钮不可用，先完成当前参数的效果预览。
我要交给 Agent 修改怎么做？
点击“生成 Agent 修改方案”，再点“复制给 Agent”，粘贴到 Agent 对话。交接文档和工具计划会保存在当前建筑的“Agent交接”文件夹；Agent 修改完成后在原建筑工作文件夹另存下一版，回应用刷新并选择新版本。提示词方案页用于更完整地编辑建筑设计需求，同样可以复制给 Agent。
这几个“保存 / 生成”有什么区别？
保存调整设置：保存比例、材质、随机编号和范围等参数 JSON，方便下次读取；不包含建筑，也不会导出 NBT。
为原建筑生成预览图：给当前源建筑生成多角度图片，供查看和评论；不会把左侧候选效果保存成建筑。
生成 Agent 修改方案：把当前设置整理成可执行操作，估算改动量，供你或 Agent 核对；这时建筑没有改变。Agent 高级精修执行前需要匹配当前参数的方案。
导出建筑下一版：将当前参数正式执行并另存主模型、NBT 等交付文件，保留原建筑。导出前仍需通过保护范围、改动上限等检查。
文件去哪里找？
参数保存和运行日志使用“效果文件保存位置与名称”中的目录，修改目录后要点“使用此位置”。Agent 交接文档、工具计划和审阅图统一放在当前建筑工作文件夹的“Agent交接”中，每次生成独立子目录。建筑下一版保存到源建筑的工作目录，实际产物链接见“方案与运行详情”或“任务记录”。

Agent 精修审阅与执行


主要用法是：在应用中整理参数和意见，生成并复制方案给 Codex 等 Agent；Agent 调用 skill 完成修改，在原建筑工作文件夹内另存下一版，你刷新列表后继续编辑。应用与 Agent 共用当前建筑下的“Agent交接”文件夹，计划和审阅任务各自新建子目录，保留旧记录。这里用于接续 Codex 等 Agent 按 skill 执行的精修任务。Agent 指能读写项目文件、调用建模工具的助手；应用内只生成建议的 AI 不会自动替你走完这套流程。


普通手动调参怎么用？
调整参数 → 更新效果预览 → 对比原建筑与调整效果 → 点击底部“导出建筑下一版”。这条流程通常不用填写审阅目录。


输入框到底填什么？
填一整个审阅文件夹的路径，不是 NBT 文件、提示词或某张图片。点击“准备建筑审阅图”成功后，应用会自动填入路径；再次打开建筑时会自动找回这个共用文件夹内、与当前源版本匹配的审阅记录。接续其他目录的任务时，也可粘贴 Agent 提供的目录。
例如，Agent 提供的目录可能是 nbt_models/某建筑/Agent交接/review-任务编号，应填写这整个目录，而不是末尾追加 review.json。这只是格式示例，不能直接使用；以实际生成的路径为准。


这个文件夹里有什么？
  • review.json：记录本次审阅对应的建筑和图片。
  • source.master.json.gz、config.json：保存审阅时的模型快照与保护设置，防止确认后换成另一份内容。
  • thumbnails.png：给你查看和确认的建筑审阅图。
  • approval.json：你看图并明确同意后，由 Agent 根据真实回复记录的确认；刚生成审阅图时还没有这个文件。
这些文件由工作流生成，无需自己创建或手工修改。


按什么顺序操作？
  1. 选择建筑、设置参数和保护范围，点击“准备建筑审阅图”。这里生成的是待确认的源建筑审阅图，不是修改后的效果承诺。
  2. 实际看过对应图片，在 Agent 对话中明确说明，例如“我看过这份审阅图，同意按约定范围继续精修”。只对你真正看过的版本确认。
  3. 由 Agent 记录确认，并准备或核对修改计划。应用中点击底部“生成 Agent 修改方案”可生成当前参数的计划和交接文档。
  4. 确认目录和当前计划匹配，如果需要由应用执行，展开“在应用中执行已确认计划（可选）”，再点“验证确认并生成新版本”。如果 Agent 已经完成下一版，直接刷新列表，不重复执行。应用核对源建筑、参数、保护设置、真实确认和数量上限后执行，另存新版本。


按钮变灰或提示不匹配怎么办？
尚未载入建筑、还没有生成当前方案、目录为空或任务正在运行时，执行按钮可能不可用。按钮可点击只代表可以提交检查，不代表确认已经通过。
参数变了就重新生成方案；源建筑或保护设置变了，需要重新生成对应审阅图，并重新看图确认。缺少确认文件时，把真实确认交给 Agent 记录。保存评论、采用 AI 建议不会自动生成精修批准。
结果会显示在“方案与运行详情”和“任务记录”中。原建筑保留；导出文件后仍需在游戏里检查实际效果。
