# 开放选型与空间设计语法

用于未指定骨架的原创设计、批量作品差异化，以及纠正“所有主题最后都变成同一种厅堂”。这是推演工具，不是需要全部填满的配方。用户指定的用途、简单程度和视觉方向优先；密闭、普通玩家通行、SAODG端口、整体切片与缩略图授权仍按 SKILL.md。

查阅路径：先看“从需求生成”，遇到布局惯性时看“组织与剖面”，需要判断取舍时看“设计偏好”，批量制作时看“差异复核”。原型按需查 [建筑知识库](architecture-knowledge-base.md) 和 [扩展场所原型库](structure-atlas.md)，无需全读后才开始。

## 从需求生成，而不是从例子抽签

把构想写成能改变几何的因果句：“某类使用者为了某种活动，在这样的场地上建造，后来发生这样的变化，因此玩家这样穿行”。变化可以没有；完整、安静、仍在使用的建筑同样成立，不默认废墟化。

| 推演维度 | 可探索的方向，仅为例子 | 应改变的设计决策 |
| --- | --- | --- |
| 使用者与行为 | 居民、船工、抄写员、园丁、朝圣者、测绘员、巨型生物；休息、交接、分拣、聚集、培育、封存 | 谁停留、谁经过；相邻与隔离关系；操作与观看尺度 |
| 场地与边界 | 窄长岩脊、缓坡、阶地、厚城墙内部、旧河道、被包裹的旧建筑、倾斜地层、分叉空腔 | 建筑顺应、跨越还是嵌入场地；空腔与实体的比例 |
| 组织来源 | 工序、家庭群组、交通换乘、仪式序列、自然生长、后期扩建、不同年代叠压 | 主次邻接；重复单元的生成规则；允许哪些偏离 |
| 剖面驱动 | 屋顶从低到高、楼板局部缺失、连续坡地、低带夹高带、架空底层、坑边作业、厚墙夹层 | 高度变化的原因；从哪里看见另一层；如何实际到达 |
| 空间状态 | 完整、扩建中、转用、迁空、淤积、局部修复、自然回收 | 哪些构造先存在；新旧交接、阻断与绕行的位置 |
| 感知目标 | 亲密、秩序、稀疏、压迫、庄重、好奇、方向明确、逐步理解 | 尺度、重复、遮挡、转折、留白；不只改变颜色 |
| 建造逻辑 | 堆砌、框架、挖掘、悬挂、折板、张拉的静态表现、枝生、层层包裹 | 落点、边缘、厚度和连接语汇；奇幻也要自洽 |

选择与任务相关的维度即可，不强制每件叠加灾变、混合风格或复杂背景。主题可以抽象成行为和空间需求再反推结构：例如“保存会生长的记忆”可能产生可扩展的侧室网络，而非自动变成圆形书库。

方向模糊或旧套路明显时，先在内部比较少量本质不同的骨架，再自行选最符合要求的方向实施初稿。比较的是路径与体量，不是三个漂亮标题。无需把所有备选交给用户审批；正常缩略图确认仍保留。清晰的小任务直接设计，不机械生成备选数量。

## 组织与剖面：可替换、可组合、可发明

以下关系可用于同一类型的不同变体，也可跨类型使用。没有“某题材必须用某拓扑”的对应表。空间组织不等于怪物、谜题或奖励流程。

| 关系 | 几何与体验 | 适合何种意图；容易出现的问题 |
| --- | --- | --- |
| 连续套间 | 空间直接相接，门位可同轴或偏移；尺度逐段变化 | 仪式、展陈、住宅都可；避免每间完全等大 |
| 梳状侧室 | 一条主带连接不同深度的侧区 | 功能分工清楚；主带要有节奏和目的地 |
| 双脊横联 | 两条不同性质的长带由局部横向通道联系 | 公共/服务、干/湿分流；不能仅凭外观声称有回路 |
| 枝状聚簇 | 分叉末端形成大小不同的群组 | 居住、库藏、生长空间；分叉要有可读的方向线索 |
| 非均质网络 | 多节点横向互连，局部密、局部疏 | 聚落、改建群落；避免任意打洞造成迷向与边界漏口 |
| 院落串联 | 几个内空区被不同厚度的建筑带包围 | 群体生活和渐进展开；庭院在本流程中纳入封闭壳 |
| 实体岛与绕行 | 一个或多个厚实体组织周边路线 | 厚墙设施、设备群、岩体；不必永远只有中央一个岛 |
| 偏心主室与附属群 | 主要空腔位于一侧，附属空间承担过渡和后勤 | 强化主次；不要把其余区域降为无内容的走道 |
| 交织带状空间 | 两种功能带相互穿插，交叉点有明确层级 | 温室/维护、街道/宅院；关系应落实为真实连接 |
| 斜向贯穿 | 主路径或长空腔斜穿整体，边角成为可用侧区 | 打破网格视觉；体素转角和斜口需留碰撞净空 |
| 扇面分区 | 由局部铰接点向外展开，边界可不规则 | 观演、分配、观察；铰接点不能堵塞全部流线 |
| 多中心组团 | 几个独立焦点以公共空间连接 | 小型城镇、园区；需让中心具有不同用途和尺度 |
| 渐变跨间 | 重复构架的宽、高、间距按逻辑缓慢改变 | 长厅、棚场、运输廊；变化不能任意抖动 |
| 厚边薄心 | 厚边界容纳服务空间，中心保留安静净空 | 集会、藏品、储存；厚边要有可用深度与入口 |
| 薄边厚心 | 主要功能在内部实体中，边缘形成连续通行带 | 船坞、机械设施、蜂巢；防止外围成为同宽单调环廊 |
| 连续阶地 | 地面沿用途或地形逐段升降 | 园艺、聚落、地质空间；高差从用途反推，不强制桥梁 |
| 斜坡与平台交替 | 行走持续改变高度，停留面保持水平 | 运输、展陈、坡地街区；Minecraft坡路用可走台阶实现 |
| 下沉袋状空间 | 若干局部低区嵌入较稳定的上部地面 | 作业坑、庭室、沉积地形；不默认贯穿全高的深井 |
| 架空与穿底 | 上部体量抬起，下部仍是有用途的完整空间 | 仓栈、潮岸聚落、支承设施；支点与上下入口要明确 |
| 局部夹层 | 只在部分高空间插入第二层 | 亲密与通高交替；不沿每面墙复制同一圈平台 |
| 分裂楼板 | 相邻楼板错高，短梯在不同位置连接 | 居住、工坊、改建；短梯和梁底净空逐处检查 |
| 折返长剖面 | 长路径在体量内折回，新段看到旧段 | 山路、运输线、展览；折返原因应来自场地或使用 |
| 横跨与穿越 | 路线穿过另一空间的上部或底部 | 表达不同流线；声称可换层时必须实际存在连接 |
| 嵌套壳体 | 内层独立体量与外层围护之间留出空间 | 温室、封存设施、旧建筑转用；夹缝宽度须有用途 |
| 窄缝与侧腔 | 连续狭缝间歇向侧面打开大空腔 | 岩层、街巷、裂隙居所；避免整条路径单调压迫 |
| 低穹连续群 | 多个低拱空间由鞍部或厚墩间通道相接 | 浴场、窑群、岩洞；不需每件都有巨大厅堂 |
| 错位断面 | 同一构造或地层在局部发生有原因的位移 | 修复、沉降、地质叙事；可走连接另行补足 |
| 渐次显露的终点 | 入口只见目标碎片，沿路线逐步理解整体 | 观测、纪念、探索；不必靠强制迷宫或锁门实现 |

这些名称仅方便讨论。可以先构造没有现成名称的空气体积、路径曲线和功能邻接，再描述其组织；不必为新方案寻找最接近的条目编号。环形可以扁平、偏心、破开后绕行或多环互接；线性可以宽松、多跨、转折或具有侧向渗透，不等于直走廊。

## 设计偏好与取舍

偏好用于选方案和复核，不是硬性指标或排行榜。同一作品可以追求安静、克制、平层或对称；取舍应服务于用户目标。

| 偏好 | 如何落实 | 何时收敛或换一种做法 |
| --- | --- | --- |
| 用途可读 | 进入、操作、停留、存放、维护之间有合理邻接与站位 | 抽象圣所可减少日常道具，以空间关系表达用途 |
| 轮廓有辨识度 | 从主要空腔与实体的关系形成形象 | 不为奇形割碎必要空间；整体辨识不要求每个角度都夸张 |
| 空实共同设计 | 厚墙、岩脊、设备体与空腔互相塑造 | 不把全部实体缩成薄壳，也不让厚体吞掉行走空间 |
| 剖面有因果 | 高差来自工序、地形、使用层级或建造历史 | 平层要求下用跨间、侧向关系和顶高变化丰富体验 |
| 行走有节奏 | 长短、宽窄、停留与通过相间 | 并非每十格就要转折或惊喜，长直段也可形成秩序 |
| 观察有变化 | 同一节点从侧面、下方或远处被重新理解 | 不是所有区域都需互相看见；保留私密、背面与遮挡 |
| 方向可判断 | 地形、构造、光线载体、地标构成可辨线索 | 迷向主题可局部弱化线索，必达路线仍要可验证 |
| 主次清楚 | 焦点、过渡、背景有尺度与密度差异 | 可选多个局部中心，不强制中央巨物 |
| 构造自洽 | 支撑、跨度、接头与厚度具有共同规则 | 幻想可用虚构规则，不必伪装现实工程验算 |
| 人的尺度与奇观并存 | 巨构旁留门套、台面、休息位等比较尺度 | 紧凑建筑不用硬塞巨构，宏大空间也不用遍布小物 |
| 重复中有差别 | 重复来自工序、柱网或居住单元，节点因用途变化 | 安静规则的空间可以高度重复，不必强行随机化 |
| 有内容的留白 | 空地承担聚集、搬运、观赏距离或视觉休息 | 留白不是遗漏建模；装饰密度也不能掩盖用途空缺 |
| 边缘有处理 | 平台尽端、转角、墙脚、顶面收口与整体一致 | 背景边缘可以简化，细节资源优先实际可见节点 |
| 历史痕迹有位置 | 改建、沉积、磨损对应明确事件与使用 | 完整新建筑不强制裂纹、苔藓或破坏 |
| 空间适应主题 | 气候、防御、存放对象或身体尺度改变组织 | 不只通过主题色或雕像命名建立差异 |
| 技术约束内诚实表达 | 先完整设计，再报告拼接与运行风险 | 不为迎合切片把空间默认隔成小方厅，不隐瞒不可行部分 |

照明意图用有载体的方块安排表达；未游戏验证时不声称真实亮度。水、烟、风、移动、声音与机械动作可以启发形态，但静态NBT只交付实际保存的几何与允许状态，不自动获得模拟功能。

## 打破惯性的方法

- **去掉熟悉主角**：暂时不用中央奇观、环廊或高桥，问场所靠什么用途仍能成立。此法用于发现替代方案，不永久禁用这些元素。
- **把背景变成主体**：从城墙内部、运输交接面、院落边界、炉体背面或居住服务带组织空间；随后补上使用它们的人与路线。
- **改变空实顺序**：从挖出的空腔而非房壳开始，从多个厚体之间的间隙而非大厅内部开始，或先布置必要站位与邻接再围合。
- **改变剖面来源**：不用“上层平台”增加高度，改问屋顶、地层、设备、岸坡、基础或多代扩建如何自然产生不同高度。
- **改写典型组织**：书库可以低矮梳状而非通高环形；兵营可以沿坡聚簇而非整齐院落；圣所可以是连续窄室而非高殿。改写需保留其用途可读性。
- **用冲突推演连接**：新旧柱网不对齐、干湿区相邻、运输需避开静室时，让转接、厚墙和绕行有具体位置；冲突不要自动升级为灾难剧情。
- **从未列出的事物发明**：选择任务世界里合理的活动、环境或物种需求，推导场所。无需证明它属于已有建筑名称，也不必把新名词塞进既有示例骨架。

## 批量差异复核与设计证据

设计笔记简记每件的“用途—主要空实关系—水平组织—剖面来源—进入与回望—代表节点”。记录帮助自查，不要求用户填写新表单，也不要求所有维度都不同。

对比去掉材料后的草模：若都能描述为“中间一个大物体、四边同高窄廊、沿墙上楼”，即使题材各异，仍应重新设计重复者。反过来，同为梳状布局但一件是缓坡公共街、一件是低穹嵌套窑群，其体量、层级和行走确有差别，可以成立。

不采用随机抽签、按类别轮换或强制搭配数量来冒充创意。允许共享风格、柱距或家族特征；成套建筑也可有意共享骨架，但需符合用户对统一或差异化的要求，不能把换皮宣称为空间多样性。

初稿说明用一两句讲清为何如此组织，以及玩家会走到或看见什么；不以长篇设定替代几何。缩略图从实际模型验证这些关系。任何声称的回路、跨层捷径和分流汇合仍需对应连接检查；未执行项目明确记为未验证。
