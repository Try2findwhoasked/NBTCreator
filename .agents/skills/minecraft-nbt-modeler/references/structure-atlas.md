# 扩展场所原型库

本库补充 [建筑类型与风格知识库](architecture-knowledge-base.md) 的12个基础原型，编号13～72便于检索，不表示推荐顺序。每行提供用途、空间关系和可落实的构造线索；名称相近的场所也可以拥有完全不同的骨架。它们是原创设计起点，不是历史复原、现成NBT、玩法定义或已验证模板。

选读与任务有关的一两类即可；没有对应条目时按 [开放选型与空间设计语法](design-grammar.md) 从行为、场地与建造逻辑继续发明。不要为了覆盖目录而轮流制作每种类型，也不要把以下关系固定绑定到该类型。

## 使用边界与类别索引

所有“庭、谷、街、港、天井、冰洞”等在当前工作流中均指完整封闭围护内的设计空间，或带独立完整外壳的内层场景；自然光、开天窗、海面、烟囱、崩塌和真实漏口不能混为一谈。外壳在入口视角与轮廓中也属于设计的一部分，不默认塞进随意的方盒。外门只按已声明协议开洞。水、冰、植物、轨道、悬物和设备优先明确静态几何表达；真实流体、更新、实体与交互按运行策略另验。

| 公共和集会 | 19～24 | 聚集、观看、分流、主次与公共界面 |
| 农业与食物 | 25～30 | 培育、处理、存放、不同使用尺度 |
| 生产与手工业 | 31～36 | 工序、物料、操作面、热湿与运输分区 |

| 交通与交接 | 43～48 | 方向、转接、装卸、人货分流 |
| 军事与管理 | 49～54 | 控制、组织、隔离、后勤与观察 |
| 学习、照护与创作 | 55～60 | 安静与活动、操作与观看、适宜尺度 |

## 生活与共同体

| 原型 | 用途、组织与剖面起点 | 构造节点与避免的退化 |
| --- | --- | --- |
| 13. 坡地聚居院 | 小型住组沿缓坡错开，公共巷道连接入口，私密侧院后退；不同屋面下形成各自高度的内部空间 | 门前停留台、挡土基座、共用水台、侧向短梯；不要用相同小盒子整齐堆满整层 |
| 14. 公共厨房与共享食堂 | 收货、备料、烹制、就餐形成相邻但不混杂的带状区，公共厅可低而宽，备料带局部抬高便于识别 | 长灶的静态台座、工作面、传递口、餐桌端部与服务侧；不是只放餐桌再贴一面炉墙 |
| 15. 集体宿舍与轮班休息站 | 入口储物带隔开公共休息区与睡眠组团，低隔间配共享挑空，夜间路线减少穿越私人站位 | 床位用许可几何表达，储物凹格、阶梯座、隔屏与转角；不能默认依赖带实体家具或塞满重复床阵 |
| 16. 浴场与洗衣所 | 更衣、干燥通路、不同深度池室与后部服务带分区；低穹相连，池岸标高不同而非全室通高 | 池缘、踏步、排水沟、坐凳、封闭蒸汽罩轮廓；先做干路，真实水和湿滑效果不默认实现 |
| 17. 避难所与公共物资站 | 厚边围护内组织入口缓冲、分配台、生活组团与安静区；储备带在侧面或较低层，不以狭井为唯一中心 | 加厚门套、配给台、分隔墙端、静态水罐与检修间；不把避难所简化成一条两侧全是同款小室的走廊 |
| 18. 家族工住合院 | 面客工作区、家庭共享区、私密住区以进深或高差区分；扩建翼可偏转轴线，楼梯服务具体房组 | 作业门槛、储物壁、内廊、屋架转接与后加扶墙；保留生活用途，不自动改成另一座宏伟神殿 |

## 公共和集会

| 原型 | 用途、组织与剖面起点 | 构造节点与避免的退化 |
| --- | --- | --- |
| 19. 议事厅与公会会所 | 接待、议事、文书及非正式会面形成公共到私密的梯度；座席可扇形、对置或分组，不必有中央高台 | 发言位、侧门、旁听区、桌组与屋架；柱子不挡主要视线，不能仅靠旗帜表达公共用途 |
| 20. 审议庭与仲裁所 | 等候、陈述、旁听和内部工作流分别进入同一核心；核心可横向宽展，服务室沿厚边布置 | 对置席位、分流门廊、记录台、边界扶手；区分可见与可达，静态几何不自带审判玩法 |
| 21. 剧场与排演厅 | 观众入口、座席、表演面、后台和侧台形成不同路线；看台沿地形缓升，台下可容纳服务通道 | 座席排端、台口厚度、侧幕支架、后台转场；不是普通大厅尽头放一块平台，逐处检查视线和净空 |
| 22. 展馆与珍藏陈列室 | 连续展室、开放展带与休息口袋交替，观察距离按展件体量变化；可采用低平套间而非中央展井 | 展台底座、凹龛、框架、观看站位与侧向绕行；展件需实际几何可读，文字标题不替代造型 |
| 23. 训练馆与竞技练习场 | 活动净场、观摩边带、准备区和器材储放分开；看台可以单侧，主场可与侧区同高 | 场地边线、换装壁龛、器材静态支架、看台入口；不自动加入比赛逻辑，不为高差侵占活动净空 |
| 24. 邮驿与文书交接局 | 面客窗口、分拣台、暂存格和出发带沿流程相接；前部亲切低矮，后部可有双层分类墙 | 交接台、投递槽的封闭背板、分类框、打包桌与侧门；不把快递系统功能当作NBT已有能力 |

## 农业与食物

| 原型 | 用途、组织与剖面起点 | 构造节点与避免的退化 |
| --- | --- | --- |
| 25. 阶地苗圃与种子育房 | 分株床沿坡地层层展开，主路绕端部连接，育苗、移栽与工具区共享服务带；台地宽度因阶段变化 | 畦边、灌溉槽静态轮廓、操作踏面、支撑框与封闭顶壳；不要把全部苗床做成同尺寸发光花盆 |
| 26. 菌圃与地下培育场 | 多个湿润低穹空腔串联，采收侧道与培养床交错，分区密度随生长阶段改变 | 培养台、床沿、菌簇承接面、干燥工作台；菌体成簇有主次，不靠随机撒蘑菇构成洞穴 |
| 27. 蜂房与授粉温室 | 蜂房组团面向植物带，人工维护通路位于侧后方；顶壳高度随冠层变化，人的路线与巢体层级不同 | 静态巢格、支架、观察壁与植物床；巢块与植物状态需满足导入策略，不默认实体蜂群或授粉功能 |
| 28. 磨坊与谷物加工所 | 收粮高台、磨制基座、筛分与袋装区形成纵向工序，重构件落在厚基础上，检修台局部错高 | 静态磨盘、轴座、料槽、装袋站位、传动罩；轴线与接口连续，不凭几个圆盘声称机械联动 |
| 29. 酿造窖与发酵作坊 | 清洗/压榨侧、发酵列和低温藏窖分区；藏窖可沿山腹弯曲，搬运坡路比中央楼梯更主导形态 | 桶体静态几何、压榨梁、沟槽、架脚与搬运平台；不要让道具堵塞工作侧或把真实容器内容写入模板 |
| 30. 粮仓与食物储备所 | 收货、验看、分类存放与发放按进深组织；架空底层、厚干燥边带或高低错开的仓格体现储藏逻辑 | 架空基座、卸料台、分隔挡板、封闭通风凹槽；仓体是厚实体与操作空间的组合，不是空厅里堆箱子 |

## 生产与手工业

| 原型 | 用途、组织与剖面起点 | 构造节点与避免的退化 |
| --- | --- | --- |
| 31. 窑场与陶工作坊 | 泥料准备、成形、晾置与烧制围绕不同温区组织；窑体顺坡爬升，工作路沿侧面连续到各窑口 | 厚窑壳、窑口台、装窑面、晾架与封闭烟道；不能用平墙贴火色方块代替有深度的窑体 |
| 32. 玻璃作坊与退火廊 | 原料、炉口操作、冷却长廊与成品展示分开；短而高的热区连接低而长的退火带 | 炉口护边、操作站位、杆架、静态制品与防护屏；不必使用危险流体，透明表面仍需明确实体边界 |
| 33. 造纸与抄印工坊 | 浸泡、捞取、压制、晾晒与装订构成跨湿干区的工序；局部架空晾台跨过服务道 | 槽缘、压床立架、晒架挂点、装订台；路径与纸架共同决定房形，不只是普通书库换名字 |
| 34. 制绳所与帆具工棚 | 长距离拉绳、端部收束、卷存与缝补需求形成细长但有宽窄变化的空间；侧室容纳短工序 | 拉绳端架、卷盘基座、横向支撑、帆布静态折面；长直段有用途，不为强求转折破坏工艺长度 |
| 35. 盐作与结晶车间 | 不同深度浅盘串联，收盐边台、干燥区与仓带在不同标高；可用多个宽浅盆地替代单一深井 | 池盘挡边、刮取通路、堆料肩台、封闭排气构造；水面与盐晶区几何明确，蒸发效果仅为设计意图 |
| 36. 织造与染整院 | 长机台、染槽、晾布和裁整面围绕人工操作侧分布；高晾棚与低工作带形成连续剖面 | 静态机架经纬面、槽口、布卷、晾杆支点；不以满墙彩条替代织造构件和真正的操作空间 |

## 水工与环境设施

| 原型 | 用途、组织与剖面起点 | 构造节点与避免的退化 |
| --- | --- | --- |
| 37. 船闸与升降水阶 | 两段不同水位轮廓经长闸室联系，干燥岸路沿一侧升高，闸头形成横向工作台 | 厚闸墙、导槽、系缆柱静态几何、检修阶与消力池轮廓；静态水位不等于能工作的船闸 |
| 38. 分洪廊与消能阶池 | 多条渠道从上游分开，经跌级与宽池重组；检修路可直达各节点，不与水路完全重合 | 分水鼻、池壁、阶缘、跨槽检修板、封闭渠端；先设计流向与高程，不能随机散布水池 |
| 39. 沉井与取水设施 | 厚环壁包围取水空腔，操作平台可偏在一侧，储水侧室与地面服务间分层联系 | 井口压圈、壁龛、卷扬静态支架、落地梯与排水台；井筒可以宽浅，不自动用极深中央高井 |
| 40. 岸堤与潮位观测站 | 一侧为不同潮位的台阶断面，另一侧为连续干燥维护带；观测间嵌在堤体厚部 | 护岸收分、刻度凹带、横向踏台、闸口封闭背墙；“潮汐”需以静态痕迹区分，不宣称周期变化 |
| 41. 排水渠网与地下检修枢纽 | 干燥服务路与低渠并行，支渠按地势汇集，汇合处局部扩大而不必设置大厅 | 渠帮、沉砂窝、检修台、封闭栅后空腔、不同年代接缝；走路图与排水图分别考虑，开口不穿外壳 |
| 42. 冰窖与季节储冷设施 | 低处储冷坑、隔温厚边与搬运坡道共同组成内核，前室作为缓冲，工作区绕坑侧展开 | 厚门槛、分层内墙、储冰台、干燥排水面；真实冰的融化或更新需另验，静态结构也能表达用途 |

## 交通与交接

| 原型 | 用途、组织与剖面起点 | 构造节点与避免的退化 |
| --- | --- | --- |
| 43. 船屋与修造坞 | 狭长坞槽、两侧作业岸、船体支座与后部工具带构成整体；一侧可以是连续坡台而非双侧环廊 | 坞头、龙骨支墩、吊架、工具站位、船体静态断面；港口在围护内，不向外壳开无声明海口 |
| 44. 货栈与装卸转运所 | 人流接待、验货、堆场、运输尽端各有方向，装卸面错高形成清楚交接；大门后保留转身范围 | 月台边、货垛托架、轨道或滑槽基座、雨棚内侧；不是堆满箱子的仓库，接口要有来向去向 |
| 45. 折线山道与步行中继站 | 长剖面沿岩台逐段爬升，休息窝、会车台和侧向观景点改变节奏；上下路线可看见而不直连 | 挡土墙、转弯放宽、踏步侧缘、落石防护廊静态构造；不用狭窄跳跃代替普通步行路线 |
| 46. 索道或吊运站的静态场景 | 上下货台、机房和锚固体围绕一条运输轴组织，步行检修路另设；吊运缺口改变空实关系 | 端部轮架、锚座、配重壳、装卸面与步行梯；不生成会移动的吊舱，不以空中缆线承担必达路线 |
| 47. 地下街巷与路口节点 | 几条有不同用途的街巷在偏心节点相遇，店前停留与穿行分开；地面可随坡连续变化 | 转角门廊、铺面后场、街宽变化、路口遮挡；避免正中十字路加四面同款房，外边界仍完整 |
| 48. 隧道转接与换乘前厅 | 不同方向、标高或截面的通路在缓冲区转换，等候区偏离快速通行线；上部不是必然有环廊 | 拱口渐变、坡阶、侧向检修带、隔屏和等待凹位；换乘感来自流线关系，不靠虚构传送功能 |

## 军事与管理

| 原型 | 用途、组织与剖面起点 | 构造节点与避免的退化 |
| --- | --- | --- |
| 49. 驻屯营房与操练院 | 宿舍、集合、补给、值守按日常活动邻接，操练净区与后勤道区分；住组可顺地形错落 | 集合台、武具静态支架、门前廊、补给台与内侧步道；不默认全轴对称，也不把兵营等同城堡大厅 |
| 50. 军械库与修护工房 | 收发、检查、修补和封存区沿控制深度排列，重物靠地基，轻器具在工作墙；维护夹层只占局部 | 武具槽、静态盾架、检验台、厚隔墙、吊点；装备只交付外观，不生成奖励或带内容容器 |
| 51. 指挥所与地形推演室 | 公共汇报、核心讨论、通讯侧区和休息空间形成权限层次；主室可低平，侧廊高低有别 | 地形桌的实体几何、卷图架、观察凹位、分流门；不以中央发光球替代信息与工作关系 |
| 52. 拘留所与监管前室 | 接收、看守、生活与探视分区，监管路线与被监管空间形成可见但受控的联系 | 静态栅格、厚门套、转接前室、生活台；可通行检查只针对声明目标，静态门栅不自带锁控机制 |
| 53. 工城器械装配棚 | 大型装配面、零件列、维修坑和侧向搬运带决定长宽；顶部吊装与地面承重对应 | 器械框架、轮座、试装基台、斜撑与拉结的静态表达；器械有部件和尺度，不是墙上贴几枚齿轮 |
| 54. 边境检验与隔离站 | 抵达、检查、等候、隔离和放行形成清楚分流，服务带绕后联系各区；低密度留白承担等候 | 检验台、侧门、隔屏、静态物资架和单独缓冲间；不给场景附加未经实现的身份或传染系统 |

## 学习、照护与创作

| 原型 | 用途、组织与剖面起点 | 构造节点与避免的退化 |
| --- | --- | --- |
| 55. 学舍与讲习工院 | 讲授、练习、展示和小组讨论相邻，动手区与安静侧室分开；地面可平层，顶高和开间分工 | 面向讲解的座位、样品台、练习工作面、门前交流窝；不把学习场所统一写成多层大书库 |
| 56. 诊疗所与疗养院 | 接待、处理、安静休息和后勤分区；明晰短路径连接主要功能，局部内庭提供观察距离 | 隔屏、护理台、静态床位、洗涤面与休息凹廊；高差克制，不为探索感增加无用途绕行 |
| 57. 炼金与标本实验室 | 清洁操作、材料准备、隔离观察与记录分开，厚实体舱穿插在工作路中；观察面与操作侧可不同高 | 器皿静态轮廓、台架、封闭观察窗、管线接口；实验与炼金功能仅在实际实现后宣称 |
| 58. 乐器工坊与共鸣室 | 制作、调试、独奏与共同演练形成尺度不同的空腔；曲面反射意图可指导体量但不当作声学验算 | 乐器静态部件、支架、台阶座、折面墙与工作台；不依赖声音功能，不用均匀色带代替乐器 |
| 59. 静修居所与冥想径 | 小型安静单元与共享停留处沿渐变路线相接，朝向、进深与天花高度细微变化 | 门前过渡、坐台、封闭借景窗、厚墙凹位；不强制祭台、穹顶或巨大奇观，留白可以是主体 |
| 60. 雕塑工场与模型院 | 粗加工、精修、观察退距和成品存放围绕作品尺度组织，大小不同工作单元串联 | 石坯、半成形轮廓、工台、承台与静态起吊架；制作阶段应由形体可辨，不能所有雕塑都用一根柱代替 |

## 自然空腔与地貌

涉及有机几何时同时按需读 [洞穴与自由形空间](organic-spaces.md)。先设计空腔、实体与可行走地形；纹理噪声不是成因。

| 原型 | 空实、剖面与路线起点 | 关键几何与避免的退化 |
| --- | --- | --- |
| 61. 溶蚀洞厅与地下河岸 | 低通道扩为不对称洞厅，支洞、岸台与沉积面共同组织路线；河道和步行岸并非处处同高 | 顶部溶蚀凹面、岩柱与堆积坡成组出现；不是方厅表面加钟乳石，水路采用何种静态表达须明确 |
| 62. 熔岩管与塌顶内层遗迹 | 连续弯曲管道在局部扩大或叠压，冷凝壳与堆积坡决定步行位置；塌顶只发生在完整外壳内 | 管壁层皮、流线褶皱、局部断壳与落块；不默认实际熔岩，不把整条管道做成等径圆筒 |
| 63. 冰裂隙与冰下空腔 | 倾斜裂缝在侧面打开透镜状空腔，冰台与岩基交错；窄高段与宽低段形成差异 | 层状冰体、夹杂带、裂隙交接和稳定踏面；真实冰状态另验，不能靠滑行或跳跃承担必达路线 |
| 64. 层理峡谷与沉积台地 | 岩层水平或缓倾，冲蚀切出窄谷和宽肩，路线沿不同地层转换；顶壳作为洞谷整体的一部分设计 | 连续层带、软硬岩退进、冲刷窝与侧坡；不把谷底统一铺平后只留两面装饰岩墙 |
| 65. 节理岩柱群与晶簇洞 | 密实体柱与稀疏间隙塑造多方向穿行，柱高由基底和顶部共同控制，局部通道嵌入柱间 | 柱截面族、断顶、群体密度与接地面；不均匀排列同高柱，也不将晶体尖端当作楼梯 |
| 66. 贝壳、珊瑚或根瘤空腔 | 由生长方向生成大小不同的腔室与颈部连接，可连续、分枝或侧向繁殖；路线沿稳定内壁展开 | 分层壳、枝根承接、孔颈厚度与局部沉积；视觉孔洞不必穿外壳，不用一个球壳加表面噪声代替生长 |

## 幻想与超常场所

虚构规则要实际改变空实、路线、尺度或构造。玩家通行仍依照普通Minecraft碰撞；旋转重力、时间倒流、移动机关、传送和生物行为不由静态NBT自动实现。

| 原型 | 规则如何变成空间 | 构造节点与避免的退化 |
| --- | --- | --- |
| 67. 梦境孵育与生长档案场 | 被保存的对象逐渐长大，存放腔随阶段扩展并向侧面迁移；观察路与维护路沿生长方向展开 | 扩展壳缝、静态孵育舱、支座、观察站位；不默认中央球体与四面环廊，阶段差异落实为体量 |
| 68. 巨型生物遗蜕中的聚落 | 外层骨架或壳体形成完整围护，生活单元嵌在支架间，通道适应骨节而非切成规则房间 | 关节、壳缘、修补支架、人工踏面和小尺度门前区；生物仅为静态遗蜕，不声称活体或动画 |
| 69. 重力偏转的校准设施 | 若干内层构件朝不同方向生长，玩家路线仍沿正常水平面和楼梯连接；视觉轴与步行轴形成张力 | 侧向“地板”、锚环、对位接头、真实踏台；不要求玩家走墙，不用相机倾斜掩盖缺乏实际路线 |
| 70. 不同年代叠压的修复工地 | 多套柱网、墙体与楼面在同一整体中保留交接，路线穿越被保留或截断的旧空间 | 新旧接缝、临时静态支撑、桥接短梯与展示断面；不是随机拼风格，叠压关系有先后且不破坏密闭 |
| 71. 晶体培育与能量分配场 | 生长基底、成熟晶群、采集操作与分配支路形成不同密度；能量线路以连续静态构件示意 | 晶体与基座过渡、支路接口、维护面、屏障厚边；不靠到处发光代替分配关系，不宣称电力系统 |
| 72. 风与云的凝结工坊 | 风道的收束、扩张与侧向分配塑造长剖面，低位收集面与高位静态导流体共同组织空腔 | 导流叶片、集雾网架、冷凝台、支撑与干燥步道；风云可用许可几何示意，闭合围护与通行照常检查 |

## 从目录继续生长

上述原型可按用途转用、场地变体、组织改写或虚构需求继续发展：同一处货栈改成学校后，装卸高台成为展示与讨论面，旧搬运坡道成为公共路径，而不是仅换门牌；同一种窑场可以是沿坡连续窑、低穹窑群或嵌入厚壁的侧烧单元，各自应重新设计空气与操作位置。

跨类型组合先找共同接口：苗圃与诊疗所可共享安静观察庭，船坞与军械修护可共享搬运侧带，冰窖与标本室可共享缓冲前室。不能简单各做一间再用细走廊相连，也不强制每件混合两种用途。组合过多使主题失焦时，保留一种核心活动和少量必要配套即可。

可以完全离开目录，从迁徙生物的停靠、季节性聚会、声音采集、地层记录或其他任务世界中的需求创造新场所。新名称只有在改变空间关系时才有意义；最终证据仍是模型、缩略图、实际坐标和对应验证。
