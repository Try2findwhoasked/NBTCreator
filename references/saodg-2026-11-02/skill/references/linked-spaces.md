# 多空间连通与跨层联动

用于多个空间通过通路、层次、观察关系或共同用途组成整体的模型。先确定是一个多格逻辑房间，还是多个独立房间通过布局图相连。前者共用一个房间定义与完成状态，后者仍有独立定义；资产不能自行改变运行时进度关系。

## 整体设计

先在单一全局坐标中生成完整建筑，再做分片。主模型是几何唯一来源，不能分别调用按单元命名的四个房间builder后把结果粘到一起。允许按设施、结构功能组织代码，例如给全局模型添加一条桥或一片岩体；这些构件不因存储单元而变成独立房间。

用最终拼接整体的尺寸界定设计范围。1×3沿Z时全局范围X0～47、Z0～143，L形在96×96中排除未占用象限，整体高度H由任务确定。不能把每个48格片段重复当成一个必须单独封闭的小房；在切面增设玻璃隔断或窄颈也不是默认的“兼容处理”。若当前49间距引擎无法保留这种整体，报告兼容缺口，不静默用隔断破坏整体空间。

一个区的通道、视线焦点、设施流向或高低差应能引出另一区；进门、穿行、转折、登高与回望有连贯体验。内部空间可混合洞穴、曲面与构筑物，桥、曲廊、挑空和设施可以穿过切割平面。切割线不得在设计上自动变成隔墙。

联动并不要求每区同高、对称或拥有相同功能。跨层可发生在各单元内部，通过坡道/楼梯回到合法接缝高度再去邻区。设计支线、两条主路线、跨层回路或观察联系时，要有对应的实际几何与证据，不把“各目标均可达”解释为这些关系全部成立。

## 当前SAODG的实际连接规则

制作前核对 `RoomGeometry.java` 与 `StructurePlacer.java`。当前作者单元48格，运行单元原点间距49；模板不包含那一格缝。多格房各片使用作者偏移48，同一height与door_y，且仅覆盖占用单元，不写入稀疏缺角。

当前 `RoomGeometry.internalSeamOffsets` 与 `StructurePlacer.prepare` 为同逻辑房间内部接缝延伸作者边缘状态：旋转后的单元东/南边缘存在同房相邻单元时，将该边缘各高度、各切向坐标的方块状态（含空气）复制到插入的一格缝；同时跨两个方向时补交点。不是仅在中央生成6×5通道，因此高位桥、连续空腔和顶构可以跨切面设计。两侧边缘仍须合理衔接，不能因复制一侧状态就假定所有碰撞与围护自动合格。

`StructurePlacer.bridge` 仅处理不同逻辑房间之间的布局图连接，不是同房内部接缝的生成规则。对外门仍是宽6、高5、世界脚位Y66，模板基底为世界66-door_y；不能把对外桥的门高规则反推为同一整体内部只允许该高度通行。

内部接缝不声明为外部ports。只在相邻非本房单元的合法边界声明标准外门。凹形三单元交点还存在当前加载器的角部补块逻辑，需要一并核对；不要仅凭上述概述宣称覆盖所有形状、旋转和碰撞情况。代码会变化，按本次实际实现检验；几何草图不证明运行效果，不能静默修改玩法代码来迁就素材。

## 检查与交付顺序

1. 在全局主模型中完成所有几何、内部通路和墙面mask，对外端口仍封闭。对整体室内腔体检查密闭，不能要求未来切开的分片单独密闭。
2. 整体通过后开标准外门，冻结并保存主模型。纯坐标切成每轴不超过48的NBT；不得在此循环修墙、补路或重新生成各单元内容。每片墙层也从原全局mask转换坐标，不另建墙。
3. 回读实际分片，按原48连续偏移重组，不添加任何连接块；必须与冻结主模型逐状态相等，所有整体路线与视觉关系仍成立。
4. 另做SAODG49间距适配检查，精确复现当前引擎的内部边缘延伸、交点处理及适用的对外连接。检查跨缝地板、顶面、空气、碰撞与围护，不兼容时明确标记未可接入，保留整体设计，不静默改回四个中央门小厅。不得把连续48重组通过写成49运行适配通过。
5. 检查入口到必要目标及具体路线关系，分别验证跨切面、回路和支路。对外门在副本重封后复查密闭。
6. 从重组最终文件制作整体剖视、跨切面玩家视角和局部图。明确标注48连续或49诊断，记录全部片段哈希。默认展示整体而非四张独立房间图。

只声明实际验证过的旋转。0度的重组器不能证明90/180/270度也能正常放置。静态素材可表达水利、机械或交通等空间关系，但不会自动实现动态开门、排水、升桥等玩法。

## 通用工具

默认使用 `scripts/nbt_whole_cut.py` 的open_master_ports、slice_master和reassemble_contiguous，保存主模型并机械切片。Volume支持超过48的全局内存建模/检查/渲染，但拒绝直接导出单个巨型NBT。

`scripts/nbt_assembly.py` 的assemble及 `check_assembly_fixtures.py` 仍镜像旧的内部中央短桥规则，不复现当前内部边缘延伸与角部补块。只在研究旧行为时运行，不能用于宣布当前49适配通过，也不能据其高位断桥反例缩窄主模型。当前运行适配须使用与本次加载器一致的诊断或实际Forge放置；未执行时列未验证，不为仅更新skill说明重建模组。
