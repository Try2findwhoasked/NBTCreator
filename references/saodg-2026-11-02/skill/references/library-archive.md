# 建筑库归档与中文描述

新作者资产使用 `nbt_models/<形状>/<中文房间名>/<版本>/`，创建和登记规则见[输出存储](output-storage.md)。控制台只扫描此库，默认隐藏bugged、测试、缓存和迁移证据；文件列表按“中文名-形状”显示，历史版本追加版本名，完整路径保留在提示中。

## 已有资产整理

只有用户要求迁移或整理时才执行批量搬移。按完整建筑版本归档，配套坐标、相机、验证、墙mask、修改意见和独特未选模型一起保留；不能仅按NBT扩展名删除其余创作材料。按文件大小/mtime快照和SHA256制定映射，先复制并校验所有文件，再重定向操作JSON中的实际文件路径和补充中文描述，最后再次核对源字节、目标字节/原始JSON备份才删对应源文件。只清理清单内文件和确实已空的原目录，不执行build整目录clean，也不改src生产资源、存档或参考仓库。

nbt_library_migrate.py提供审计、复制、重定向和清理阶段。审计报告与旧→新映射放 `_migration`；JSON使用唯一临时文件原子替换。重定向前保存原始JSON，保留原冻结/审阅哈希依据，不重签发批准。源在迁移期间变化时保留初始副本，并将更新件单独移至bugged/concurrent_updates，记录两份哈希；不能删除未保留的新修改。发生中断按持久清单恢复，不凭目录名盲删。

## 本次归档判定

通过集合检查完整主模型坐标/状态/几何哈希、显式非空气墙mask、尺寸与有效cells、完整坐标配置/可明确映射的旧字段、现有密闭和静态通路通过记录、与主模型一致的分层重建、完整含空气运行切片。最终另核对分层墙坐标与主模型全局mask一致。`probes`与`interior_probes`、`arrival`与`start`、`views`与标准相机列表的映射保留原值，检查探针也可读取已有密闭通过记录；不编造探针、路线或缺失墙归属。

这只说明对应文件及已有静态证据完整，不重新认证美术设计、49运行、旋转、真实游戏和多人。缺少交付、缺证明或格式失败的版本进入bugged/models并记录原因；测试夹具放test_fixtures，无法绑定完整建筑的归档包和资料放unbound_support。这些分类不意味着可以删除独特初稿，也不能把缺证等同于几何一定损坏。

中文名先读原设计/最终清单/坐标title；旧slug需翻译时记录name_source。描述文件room_description.json和可用坐标/最终清单均补name_zh、shape、shape_zh、display_name、description_zh。master_file_sha256可用于归档后目录的快速一致性索引，实际载入仍校验完整模型。模型不写入版本库，仓库.gitignore排除/nbt_models/。
