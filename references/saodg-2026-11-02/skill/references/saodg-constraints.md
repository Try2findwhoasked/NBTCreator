## SAODG 可拼接的硬性要求

以下针对当前 SAODG 加载器；独立建筑只遵守其目标格式。未来协议改变时重新核对，不将当前限制解释为 Minecraft 本身的通用限制。

### 占地与分片

- 一个逻辑占用单元为48×48格，房间高度为8～48格。占用单元必须四邻接连通并能放入目标地牢网格；单格、长条、L形、T形、十字和多格大厅都可使用。
- 每个 NBT 分片的每轴尺寸为1～48格。完整运行分片必须无重叠、无遗漏地覆盖声明占用单元的完整高度和体积，包括空气；schema 5的主体/墙面稀疏制作层先合成为完整分片，再执行这一检查。不能写入稀疏占地的缺角或其他未占用单元。
- 常规整单元分片按作者48格网格记录 `offset`；运行时相邻单元原点间距49格，由引擎处理一格连接缝。不要把49格缝隙烤入模板或将作者网格偏移改成49。

### 对外门洞与高度

- 制作时先保留全部外边界封闭，检查完整空间不漏气，检查通过后才切出下面的标准门洞。交付模板保留声明的真实开口；开洞后复查非预期泄漏和必要通路。多格房先按整体检查外边界，不能把房内接缝误判为外门。
- 门洞宽6、高5，位于所属占用单元的外边界中央。以单元局部坐标表示：西/东门 `X=0/47, Z=21～26`；北/南门 `Z=0/47, X=21～26`；所有门洞空气范围 `Y=door_y～door_y+4`，脚下有可通行地板。
- 同一逻辑房间的外门共用一个整数 `door_y`，范围为 `2～height-6`，默认2；自定义门高使用 `schema_version=4` 或5。引擎按 `结构基底世界Y=66-door_y` 放置，外门统一到世界Y66～70。到达点、刷怪及机关填写原模板局部坐标，由引擎一起平移。
- 按实际需要声明一门、对向/转角双门、三门或四门，不强制四面开门。端口定义与实际开口、朝向一致，厚墙后的通道也必须打通；不能将同一逻辑房间内部的分片接缝声明成外门。
- 除声明端口及引擎负责的连接位置外，不留能绕过房间连线进入邻房的边界通路。内部接缝要与引擎实际连接位置接通，但不要求每个分片都有隔墙或建筑对称。

### 必要通路

- 安全到达点、可用端口和必须到达的目标之间有普通玩家可行走的路线；门洞及落脚位置有足够碰撞净空。楼梯、坡道、桥梁、错层和地下空间均可，不强制平地、十字走廊或全房同一地板高度。
- 多格房跨分片的必要路线在49格运行间距展开后仍连通。不要求所有装饰空腔、封闭侧室或非交互平台可达；只有被声明为必要目标的位置必须能到达。
- 只验证房间定义声明的旋转；不能声称支持四向旋转却只检查原朝向。方向性方块应正确写入 `Properties` 并能随声明旋转变换，不限于完整方块台阶。

### 当前加载格式

- Minecraft Java 1.20.1 gzip NBT，生成器使用 `DataVersion=3465`；`size` 为X/Y/Z，单一 `palette`，无多变体 `palettes`，`entities` 为空。完整模板每个体积坐标恰好一个显式 `blocks` 条目，包括空气；坐标界内、索引合法，单片压缩文件不超过2MiB，palette不超过4096项。
- 自0.41.47起，`schema_version=5` 的 `parts` 每项可使用 `body_template`、`wall_template`、`offset`，与该项的 `template` 互斥。两层必须同尺寸、同局部原点，只保存各自非空气方块，层内不得重复、层间不得重叠；未写坐标由加载器补空气。两层合成后再检查完整体积和端口。旧schema及完整 `template` 方式继续支持，不把稀疏层当作两项普通parts叠放。
- 当前 SAODG 导入策略只接受原版 `minecraft:` 方块，不接受命令方块、结构方块、拼图方块、刷怪笼、传送门或带方块实体 NBT 的内容。这是加载器限制，不能为放宽风格而生成会被拒绝的模板；楼梯、半砖等合法方块不因此被禁止。
- 正式接入的 JSON 与模板路径、`size`、`cells`、`parts`/`template`、端口、旋转及标记一致，满足所选 schema。坐标说明只够作为建筑素材交付，不能替代实际加载所需的完整房间定义。

schema 5的分层项示例（只展示parts，不是完整房间定义）：

```json
{"body_template":"saodg:refined/sword_oath/p00_body","wall_template":"saodg:refined/sword_oath/p00_walls","offset":[0,0,0]}
```

墙面层按整体模型的墙mask保存，不是按边界重复铺设的通用墙片，也不是门模型。当前引擎处理一格连接缝、未使用出口的石砖封墙和主线煤炭块门；没有独立门NBT配置。
