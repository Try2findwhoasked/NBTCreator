# 房间风格与选址参考

本文件仅用于 SAO 风格地牢模组的房间类型选择、主题风格适配与迷宫内选址。  
不涉及：战斗数值、怪物配置、掉落表、生成算法、材质配比、建筑教程。

## 快速索引

- 需要判断“这个房间该放哪” → 查「房间类型选址规则」
- 需要判断“这个层适合什么房间” → 查「层主题适配矩阵」
- 需要检查“每层必须有什么” → 查「必选 / 可选 / 禁用」
- 需要输出选址建议 → 用「输出模板」
- 需要避免常见错误 → 查「反模式」

## 核心原则

1. 先定锚点，再填支线：Boss 房、安全区、主题暗示房是锚点；战斗房、陷阱房、宝箱房是填充。
2. 房间风格服从层主题：同一房间类型在不同层应有不同空间语言，但功能规则保持一致。
3. 安全区是“有代价的喘息点”：狭小、封闭、朴素，不与 Boss 房直接相邻，不强迫玩家经过。
4. Boss 房是层的终点门户：位于迷宫区顶层/终点，始终只有两个出入口。
5. 风险与信息绑定：陷阱、隐藏房、宝箱房应承担路径筛选或信息释放功能，而非单纯惩罚或奖励。
6. 每层至少有一条改变玩家空间阅读方式的规则：森林用非矩形/吊桥，水都用航道切割，常暗用光源约束。

## 房间类型选址规则

### 安全区

- 风格：狭小、封闭、朴素石造；四角特殊颜色火把标识；与外部危险仅一门之隔。
- 选址：迷宫区中段、长路径之后、分支节点附近，可服务多条探索路线。
- 禁止：与 Boss 房直接相邻；放在唯一主路径上作为强制 checkpoint；做成宽阔舒适大厅。
- 理由：保留“可休整但不安心”的压迫感。

### Boss 房

- 风格：形状随层变化；矩形强调直线冲锋与掩体，穹顶强调垂直空间；高难度层可设入口封锁。
- 选址：迷宫区最顶层/终点；两个出入口，一个来自迷宫，一个通往下一层。
- 禁止：随机放在支线末端；设置第三个逃生口；低难度层强行封锁。
- 理由：Boss 房是层的门户，位置应能被攻略信息逐步定位。

### 陷阱房 / 陷阱走廊

- 风格：与层主题一致；错误路径上陷阱密度更高，正确路径上更隐蔽但更致命。
- 选址：死路支线、错误分支、非安全区唯一通路附近。
- 禁止：无任何可感知线索的必死陷阱；放在安全区门口。
- 理由：陷阱应筛选路径并传递“走错了”的信息。

### 隐藏房

- 风格：偏离主路径的封闭空间；可存放 Boss 机制、下一层主题或世界观信息。
- 选址：主路径之外，需要观察线索或绕行才能发现；可与陷阱房、宝箱房相邻形成风险回报链。
- 禁止：无线索的纯随机墙后房间；把所有关键信息只放在隐藏房。
- 理由：隐藏房奖励观察与 mapping，而不是运气。

### 宝箱房 / 遗物房

- 风格：遗迹层可遍地遗物；其他层可用封闭小室或半开放平台。
- 选址：支线末端、隐藏房附近、陷阱走廊之后。
- 规则：宝箱房可以带风险，例如开箱触发遭遇或封锁；不应默认安全。
- 禁止：主路径上密集放置无风险宝箱；用宝箱房替代安全区功能。
- 理由：SAO 式风险回报结构，贪婪本身应带来遭遇。

### 主题暗示房 / 门厅

- 风格：壁画、浮雕、环境痕迹暗示下一层主题或 Boss 属性。
- 选址：Boss 房之前、通往下一层的楼梯/大门附近。
- 禁止：过早揭示全部机制；与普通战斗房混淆。
- 理由：低成本增强攻略叙事与沉浸感。

### 普通战斗房

- 风格：服从层主题；森林层可用树根空腔/树冠吊桥，水都层可用被水道切割的岛屿房间，监狱层可用牢房与铁栏走廊。
- 选址：主路径填充、连接锚点之间的节奏段。
- 禁止：所有战斗房同一形状；连续三个以上同风格战斗房无变化。
- 理由：保持层主题下的空间节奏变化。

### 连接房 / 走廊

- 风格：承担移动规则变化；水都层为水道航线，森林层为吊桥/树根通道，常暗层为低照明窄道。
- 选址：锚点之间、主题转换处、Boss 房前的最后一段。
- 禁止：纯直线无信息走廊；水都层用普通陆地走廊替代水道逻辑。
- 理由：连接房是改变玩家阅读地牢方式的主要空间。

## 层主题适配矩阵

| 层主题 | 高适配房间 | 中适配房间 | 低适配 / 慎用 | 选址备注 |
|---|---|---|---|---|
| 遗迹 / 地下墓地 | 陷阱房、隐藏房、宝箱房、战斗房 | 安全区、主题暗示房 | 水都水道连接房 | 适合密集内容与解谜；安全区可少而隐蔽 |
| 森林 / 巨木 / 迷雾 | 战斗房、连接房、隐藏房 | 安全区、主题暗示房 | 监狱牢房风格 | 用树干内部、树根空腔、吊桥改变空间感知 |
| 水都 / 水路 | 连接房、战斗房、Boss 平台房 | 宝箱房、主题暗示房 | 密集陷阱走廊 | 房间被水道切割，移动逻辑优先于房间形状 |
| 常暗 / 恐怖 | 陷阱房、伏击战斗房、稀少安全区 | 隐藏房、主题暗示房 | 宽阔明亮大厅 | 安全区应稀少；照明与声音是选址线索 |
| 监狱风格 | 战斗房、隐藏房、安全区 | 陷阱房、主题暗示房 | 森林吊桥连接房 | 窄小牢房、铁栏走廊适合高密度短兵相接 |

## 必选 / 可选 / 禁用

- 每层必选：Boss 房、至少一个安全区、Boss 前主题暗示房。
- 推荐包含：普通战斗房、连接房、至少一个陷阱房或隐藏房、至少一个宝箱房。
- 可选：额外安全区、额外隐藏房、遗物密集房。
- 禁用：安全区直接连接 Boss 房；Boss 房三出入口；无线索必死陷阱；所有房间同一风格；宝箱房全部无风险。

## 选址决策流程

1. 确定层主题：遗迹、森林、水都、常暗、监狱中选一个主主题。
2. 放置锚点：先定 Boss 房位置与两个出入口；再定 1—2 个安全区；再定 Boss 前主题暗示房。
3. 填充主路径：用普通战斗房与连接房连接锚点，确保每段有风格变化。
4. 填充支线：在死路或偏离主路径处放陷阱房、宝箱房、隐藏房；支线末端优先宝箱或信息。
5. 检查规则：安全区不与 Boss 房直接相邻；Boss 房只有两个出入口；陷阱有可感知线索；隐藏房有发现线索；宝箱房可带风险。
6. 输出建议：按“房间类型 | 主题风格 | 选址位置 | 必选性 | 理由”输出。

## 输出模板

| 房间类型 | 主题风格 | 选址位置 | 必选性 | 理由 |
|---|---|---|---|---|
| 安全区 | 狭小石室 + 特殊火把 | 迷宫区中段分支节点 | 必选 | 提供有代价的喘息点，不强迫经过 |
| Boss房 | 穹顶形，高难度层封锁入口 | 迷宫区顶层终点，两出入口 | 必选 | 层的门户，需攻略信息定位 |
| 主题暗示房 | 浮雕暗示下一层 | Boss房前 | 必选 | 增强攻略叙事 |
| 陷阱房 | 层主题一致，错误路径高密度 | 死路支线 | 推荐 | 筛选路径并传递错误信息 |
| 宝箱房 | 遗迹小室 / 半开放平台 | 支线末端 | 推荐 | 风险回报，不默认安全 |
| 隐藏房 | 封闭信息室 | 主路径外有线索处 | 可选 | 奖励观察与 mapping |

## 反模式

- 把安全区做成舒适主城或免费全恢复大厅。
- 把 Boss 房随机放在支线末端。
- 在唯一主路径上放无提示必死陷阱。
- 所有层使用同一套房间形状，只换颜色。
- 宝箱房全部安全且密集分布在主路径。
- 隐藏房无任何可感知线索，纯靠随机撞墙。
- 水都层仍以普通陆地走廊为主，未改变移动逻辑。
