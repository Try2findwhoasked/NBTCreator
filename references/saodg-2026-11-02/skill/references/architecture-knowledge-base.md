# 建筑类型与风格知识库

用于 Minecraft Java 1.20.1 NBT 建筑设计。本文是面向方块创作的设计词汇与原创方案库，不是历史建筑复原标准，也不是已通过运行验收的模板。建筑类型决定“这里如何使用”，建筑风格决定“它如何建成”；两者可以组合，但不能只改材料就声称改变了空间。

按需求阅读：基础原型查第一部分；更多生活、公共、生产、水工、交通、军事、文化、自然与幻想场所查 [扩展场所原型库](structure-atlas.md)；从原型之外生成新结构、选择布局与设计偏好查 [开放选型与空间设计语法](design-grammar.md)；确定构造语汇查第二部分；写生成器查第三部分；需要完整构想查第四部分。SAO 层主题与选址另见 [SAOartguide.md](SAOartguide.md)，通路和多空间检查见 [linked-spaces.md](linked-spaces.md)。风格不规定端口数或玩法。

本库与扩展库共同提供可改写的设计起点，不能视作穷举类型。表中常见组织不是某种建筑唯一正确的组织，完整构想也不比其他方向优先。允许从未列出的用途、非建筑地貌、临时设施、基础设施内部或虚构文明的生活方式发明空间；选择理由应落在用户主题、场地与体验上。

所有尺寸单位为方块。推荐值供试搭使用，应随总尺寸、玩家视点和通路调整。外观上的露天庭院、窗洞、烟道和破损，在本 skill 的密闭交付流程中应设计为有封闭顶壳的内部空间、封窗或内层遗迹；不能以风格为由产生未声明的外部漏口。缩略图确认与精修授权沿用 SKILL.md。

## 一、具体建筑类型

### 1. 城堡门楼与瓮城

- **用途与空间**：门前压缩空间 → 门洞 → 内部防御庭院 → 高处守卫廊。入口不要一眼看穿全部终点，可用折轴门道或偏置内门形成转折。
- **体量与剖面**：两侧塔体夹住较低门洞，内庭高于门道或设下沉路面；登塔楼梯藏在厚墙或侧塔中，上层横廊跨越门洞。
- **关键构件**：深门套、拱券、门轴凹位、墙顶压檐、射口内侧扩口、横廊支座。射口用封闭凹槽表达时保留背墙。
- **方块落地**：石砖主体配安山岩墙脚；柱墩向墙外突出1～2格，拱券形成连续轮廓。门栅可用静态几何表现，不自动具备门禁功能。
- **复核**：玩家应能在上层回望门道；塔体内部有用途。避免“两根实心柱子夹一个门”的空洞外形。

### 2. 修道院与回廊庭院

- **用途与空间**：环绕内庭组织回廊，礼拜厅、藏书间和生活翼共享庭院方向；选择一处通高厅堂作为层级最高的空间。
- **体量与剖面**：低回廊衬托高厅堂，侧翼局部设二层；内庭可下沉2～4格，通过侧阶抵达，使环路和穿庭路线产生差别。
- **关键构件**：重复拱廊、柱础、檐下阴影、井台、侧门、转角加厚支墩。回廊转角保留完整步行宽度。
- **方块落地**：建议先试5～7格的柱间节奏；石柱与木屋架分工明确。庭院上方仍有整体封闭顶壳，剖视时再隐藏顶壳。
- **复核**：从回廊看见庭院，从高翼看见低廊；不要四面完全相同且每间房都没有功能差别。

### 3. 礼拜堂与仪式大殿

- **用途与空间**：低门厅 → 高中厅 → 终端仪式台；侧廊承担绕行，避免所有移动都挤在主轴。
- **体量与剖面**：中厅高、侧廊低，祭台抬高2～4格；可在入口上方设可到达的唱诗廊，形成回望点。
- **关键构件**：拱脚、柱束、跨间顶拱、侧壁龛、台阶侧缘、终端背景。穹顶或拱肋的落点与下方支撑对齐。
- **方块落地**：先做一跨“柱—拱—顶”试件，再沿中厅重复；仪式台用完整台座、背板和两侧进场路径表达，不只放发光方块。
- **复核**：入口能读出主次，侧路不破坏焦点；没有在游戏里看过时，不宣称彩窗照明已实现。

### 4. 书库与档案馆

- **用途与空间**：收存、查阅、取书、阅读四种行为形成相邻区；密集书架区与开阔阅览区互相衬托。
- **体量与剖面**：高书墙围绕偏心阅览台，夹层沿部分边界展开；楼梯接在真实可停留的平台，避免每层只剩一圈窄边。
- **关键构件**：书架分格、取阅踏台、书桌、栏杆收口、廊桥托架、档案柜凹位。保留书架前站位与转身空间。
- **方块落地**：普通书架结合木框表达柜体，木阶/半砖做檐口与桌面；不要依赖带方块实体的书架或讲台存储内容来满足静态导入。
- **复核**：高低层看到不同的信息；书架排列产生路线变化，而不是在普通大厅贴一圈书架。

### 5. 锻造厂与铸造车间

- **用途与空间**：原料堆场 → 炉区 → 铸造/锻打区 → 冷却与成品区；检修路与运输路可部分分离并交叉观察。
- **体量与剖面**：重设备落地，炉台抬高，运输坑下沉，上层检修桥横穿车间。烟道止于封闭壳内或用静态实体表达。
- **关键构件**：炉口厚边、排气罩、烟道转接、吊架、轨道支撑、设备基座、排水槽。吊挂物需要顶部承接构件。
- **方块落地**：深板岩/石砖作为热区围护，铁块或铁栏杆表达接口；以几何制作炉体外观。真实熔炉、漏斗、容器是否允许由加载策略决定。
- **复核**：工人或玩家有操作站位；熔岩与火不是默认装饰选项，危险材料和动态机制需另行验证。

### 6. 蓄水池、渡槽与泵站

- **用途与空间**：进水渠 → 沉砂段 → 池体 → 出水结构；干燥检修路串联闸座与观察点。
- **体量与剖面**：池底、岸台、渡槽和上方检修桥至少形成有用途的高程差；渡槽支墩应避开主通路。
- **关键构件**：挡水墙、溢流堰轮廓、闸门导槽、桥头、扶梯落点、旧水位线。水痕按同一水位带组织。
- **方块落地**：先用干槽检查路线，再决定是否填水；蓝色玻璃或石材槽是静态表达候选，不能把它称为真实水流模拟。
- **复核**：普通玩家有连续干路，池体并非只能飞越；真实水方块的更新、流向与运行展开接缝另测。

### 7. 矿井与地下运输站

- **用途与空间**：主运输巷分出采掘面、储料台与检修支道；运输线应能从来向读到去向。
- **体量与剖面**：岩层空腔包住人工巷道，主井筒旁安排步行折返梯或盘绕坡道；吊笼仅作景物时不作为必经通路。
- **关键构件**：支护门架、横撑、转运漏斗外壳、卸料口、轨道尽端、岩层断面。支护跟随开挖方向，不均匀铺满自然洞壁。
- **方块落地**：木梁用原木与去皮原木区分，石墙脚承担落点；铁轨只在朝向和支承有效时使用，车辆不依赖实体交付。
- **复核**：运输空间与步行净空分开判断；不把随机洞穴加几根梁就当完整矿井。

### 8. 地下墓室与纪念陵寝

- **用途与空间**：前室压低 → 纪念主室展开 → 侧面墓廊或陪葬间；主墓与次墓在轴线、尺度或标高上区分。
- **体量与剖面**：主墓下沉、绕行廊保持较高视点，或通过折阶进入深处；让高差表达仪式序列。
- **关键构件**：棺台、封石槽、壁龛边框、碑板、排水边沟、被修补的券顶。静态棺体用台座与盖板组合辨认。
- **方块落地**：石材大面保持安静，重点在门槛、封口和墓台；裂纹集中在沉降、断面和受潮区。
- **复核**：次级墓廊不抢主室焦点；破损不能穿透交付边界，装饰墓穴不必全部可达。

### 9. 地下市场与商旅驿站

- **用途与空间**：主街连接公共节点，摊位朝向客流，后巷连接储货区；驿站另有入口卸货、公共厅和客房翼。
- **体量与剖面**：街道随坡升降，架空连廊连接上层房间；选一个广场或挑空大厅打断狭街节奏。
- **关键构件**：摊架、遮棚支点、台面、货垛托板、台阶门槛、楼梯入口。每个摊位留服务者站位。
- **方块落地**：木架和羊毛棚面按铺位组织，货物通过大小不同的静态堆件表达；不默认生成村民、交易或容器内容。
- **复核**：棚面不压迫主路净空；不是整齐复制十个同款摊位，货流和人流能解释布局。

### 10. 观测塔与星象台

- **用途与空间**：入口与校准室 → 登高路径 → 观测平台；资料或测量区围绕仪器操作面组织。
- **体量与剖面**：仪器占据高处偏心平台，楼梯与其轨迹错开；中段安排能回望入口的停留层。
- **关键构件**：仪器基座、转轴、环架、配重、刻度带、平台托架。静态仪器需要可读的支承关系。
- **方块落地**：石塔身配木/金属平台，环架先检查体素轮廓是否闭合、粗细是否稳定；星空可用内穹顶嵌点表现。
- **复核**：不以真实开天窗破坏封闭顶壳；“可旋转”“可观星”仅在功能实际实现后声明。

### 11. 巨木圣所与根系居所

- **用途与空间**：根间入口 → 树心空腔 → 枝杈平台；居住或仪式空间沿树体生长关系分布。
- **体量与剖面**：树根形成支承与路径，树心偏心挑空，平台依附不同高度的分叉；人工栈道弥补不能行走的坡度。
- **关键构件**：根与地面过渡、枝杈承台、树皮凹槽、绳桥锚座、木平台收口。曲面方法见 [organic-spaces.md](organic-spaces.md)。
- **方块落地**：原木轴向跟随主要生长方向，以整片色带表达树皮；叶团成簇并保留体积层次，不随机撒叶遮盖几何缺陷。
- **复核**：去掉树叶仍有可辨认的树体与路线；不要把圆柱筒加木色称为有机建筑。

### 12. 岩壁城寨与桥梁关隘

- **用途与空间**：岩台居所依崖面分组，桥梁控制跨谷路线，守卫与补给空间围绕桥头组织。
- **体量与剖面**：入口低台 → 岩壁侧阶 → 高桥 → 对岸关楼；谷底可有独立探索支路，但桥与谷底连接需明确。
- **关键构件**：嵌岩墙脚、桥墩、拱腹、桥头扩大台、岩壁托架、廊道内侧排水沟。
- **方块落地**：先做谷体和承台，再放桥梁；石桥用有厚度的拱腹，木桥用梁与斜撑。桥不应停在岩壁表面而无落点。
- **复核**：桥的上下空间都能被视线读出；跨切片桥面与岩壁属于同一全局主模型。

## 二、建筑风格与构造语汇

以下是适合方块设计的风格提炼，不概括全部地域与时代。选定主风格后，先确定轮廓、支撑、开间和顶盖，再选材料。每种风格都可以用于不同建筑类型。

| 风格方向 | 平面与轮廓 | 支撑、墙面和顶部 | 候选方块与细节 | 易失真的做法 |
| --- | --- | --- | --- | --- |
| 罗曼式石造 | 厚重体量，连续跨间，高中厅配低侧廊 | 厚墩、圆拱、深窗洞、连续筒拱或分跨顶 | 石砖、安山岩；门套逐层退进，墙脚加厚 | 薄片墙配极细柱，圆拱悬空无落点 |
| 哥特式幻想 | 强调纵向，窄高跨间，终端有高处焦点 | 尖拱、柱束、肋拱、扶壁；肋与支撑对位 | 石砖、深板岩砖、玻璃；先试一跨尖拱轮廓 | 只加尖塔和黑色，内部仍是平顶盒子 |
| 古典柱廊 | 中轴、前厅、柱廊与层级台基 | 柱础—柱身—柱头—上部横梁关系清晰 | 石英、方解石、平滑砂岩；檐口分层，台阶有侧缘 | 细柱托巨大薄板，柱头堆满台阶却无横梁 |
| 拜占庭式启发 | 中央聚合空间与侧向小空间相接 | 穹顶、拱、过渡支承共同解释方形基底到圆顶 | 石砖/砂岩壳，陶瓦色带，少量金色焦点 | 直接把球壳放在四柱上，过渡区域空缺 |
| 中式木构启发 | 院落串联，厅堂主次明确，屋面控制轮廓 | 台基、柱网、梁架、出檐；转角与屋脊有收口 | 去皮原木、木板、深色楼梯；檐下多级托件作简化表达 | 只有红柱和弯屋顶，柱网与室内布局无关 |
| 日式木构启发 | 廊下、庭院与隔间交替，体量有进退 | 清楚柱梁、轻隔断、深檐、较克制的屋面层次 | 云杉/深色橡木、白色实面、木活板门装饰 | 把所有东亚元素混用，以鸟居代替完整建筑 |
| 伊斯兰几何庭院启发 | 庭院、水线、轴向门厅或重复拱廊 | 厚门框、凹龛、拱与局部穹顶；纹样服从构件边界 | 砂岩、陶瓦、蓝青色局部嵌带 | 全表面棋盘纹，尖拱和圆顶无空间组织 |
| 北地木石长屋 | 长向共享厅堂，两端或侧面附属空间 | 石基、木架、陡坡顶、外露梁端 | 云杉、去皮原木、圆石；门前防护凹口 | 屋顶压扁内部、屋架阻断通行 |
| 矮人式山城幻想 | 山体内厚重台阶、桥与采掘空腔相接 | 巨型支墩、收分门套、切角拱、厚梁与金属扣件 | 深板岩、凝灰岩、磨制安山岩、少量铁 | 全是巨柱却无人的尺度，路线靠飞行 |
| 工业与蒸汽幻想 | 随工序布置，运输层与检修层分离 | 重基座、框架、管道接口、吊架、栈桥 | 深板岩、铁栏杆、切制铜、避雷针作静态小构件 | 管道随机终止、齿轮贴满墙、设备没有操作面 |
| 精灵式森林幻想 | 路径顺应树与岩，体量轻且有层级 | 分叉支撑、曲线梁、叶冠顶壳、细长桥 | 木材、苔藓块、绿色陶瓦、少量浅石 | 大量树叶遮挡无支承平台，所有曲线等粗 |
| 巨石遗迹与荒废石城 | 大尺度石块围出仪式或公共空间 | 厚台基、叠涩、石梁、局部塌陷与后期修补 | 石砖、裂纹石砖、安山岩，苔藓集中受潮区域 | 全面随机破坏，失去原有构造与清楚路线 |
| 干旱地区厚土构启发 | 紧凑聚簇、深门廊、厚边小室与内部庭室 | 收分厚墙、圆角体量、短跨度顶与层层台基 | 泥砖、陶瓦、砂岩；门洞深度、墙顶压边 | 只把石城换成黄色，忽略墙厚与阴影尺度 |
| 岩壁开凿与叠涩构筑 | 路线沿地层开挖，厚实体间形成大小不等空腔 | 岩柱、凿入凹廊、叠涩顶、开挖面与补砌面交接 | 凝灰岩、安山岩、深板岩；分区刻面与接缝 | 在薄墙贴石纹，没有可读的山体厚度 |
| 轻型棚帐与游牧营地启发 | 小型组团与公共活动面相接，内外圈疏密不同 | 杆架、斜撑、织物覆盖的静态形体；整体另有完整围护 | 羊毛、木杆几何、木板；布面分片、杆端锚点 | 所有帐体变成同款锥形，布面悬空且没有入口过渡 |
| 湿地架空木构启发 | 窄岸、平台与居住群错落，底层水岸空间可见 | 桩、横梁、连续承台、步道与屋架 | 去皮原木、木板；桩帽、梁端、登台梯 | 漂浮地板加水色背景，缺少支承与岸地关系 |
| 编织与壳膜幻想 | 分叉网架或多腔壳体组织空实，构造密度渐变 | 编肋交接、边缘加厚、壳脚与锚座 | 木材、陶瓦或许可玻璃；网格节奏先服从体量 | 满屏等距线条，没有壳厚、边界和落点 |
| 砖砌节奏与窄跨拱构 | 重复窄跨组成低厅、长带或多院群 | 砖墩、券带、墙脚与收边；重点节点改变砌体进退 | 砖块、花岗岩、红色陶瓦；分跨轮廓、加厚转角 | 把砖当随机色斑，拱券与支墩不对应 |
| 折板与薄壳幻想 | 连续折面或曲壳引导内部净高与侧向展开 | 折线脊、壳脚、边梁和连续支承带 | 平滑石、方解石、混凝土；体素阶进维持连续厚度 | 只有夸张屋顶，内部仍是不相关的平顶盒子 |
| 规则框架与现代厅馆 | 清楚柱网中插入不同尺度功能，服务核与开放区分工 | 梁柱框架、板边、填充墙和封闭玻璃面 | 石英、混凝土、铁与玻璃；接头、幕面分格 | 把所有现代性简化成全玻璃空盒，缺乏核心与尺度 |
| 厚重混凝土幻想 | 深凹口、厚体、挑出块体和留空共同塑造光影 | 巨型支墩、厚梁、收分基座、完整的挑出根部 | 混凝土、磨制安山岩、石材；凹槽和大面留白 | 每面都堆碎台阶，失去厚体与净空的主次 |
| 植物曲线与工艺装饰启发 | 主路径和开间可规则，节点顺生长方向转接 | 弧形托架、分枝框、连续栏板与收束边缘 | 木、铜、许可玻璃；线条粗细、分枝端部 | 所有面贴花藤，曲线没有支承或功能关系 |
| 几何装饰与阶梯轮廓启发 | 清楚轴向或组团关系，体量逐级退台 | 门套分层、竖向构件、阶梯冠部与几何嵌带 | 深浅石材、陶瓦、少量金属焦点 | 只用金黑配色和条纹，体量与入口没有层级 |
| 复古技术与仪表设施幻想 | 操作带、设备舱、观察面和服务路共同组织 | 重底座、护罩、管线汇接、分格面板和检修口 | 切制铜、铁、深板岩；静态指示面与统一接口 | 面板与管线随机铺墙，设备没有工作侧和连接对象 |

### 混合风格的方法

风格表不是文化与时代的完整分类，也不是题材和材料的固定绑定。可以发展地方性、非典型或完全虚构的构造语汇；先声明共同规则，再让方块状态与节点服从它。气候、工序、可用资源与建造者尺度都能产生新风格，不必从表中选标签。真实地域或历史复原需要另行核实，不把这些创作提炼当作史实。

混合先确定“谁建造、谁改造、为何改造”。例如旧石造修道院被改成泵站：原柱廊与券顶保留，设备沿既有跨间插入，新增钢架绕开旧支墩，管道穿墙处有统一接口。不能把每一跨随机换成另一种风格。

可以选择一个主构造体系，再让另一体系用于附加层；不设强制比例。若用户要求历史复原或特定真实建筑，另查可靠原始资料，不把本表作为史实依据。

### 材料不是调色盘清单

按部位指定主材、支承材、连接材和焦点材。例如“深板岩墙体—安山岩柱础—铁连接件—氧化铜仪器”，比“使用十种灰色方块”更能指导生成器。同类构件维持一致材质，损坏和修补才有意义。

铜的氧化状态、原木轴向、楼梯朝向、半砖上下部位等应显式保存；是否冻结状态及是否允许该方块，按实际导入策略确认。候选表不是方块白名单。模组材料只有确认目标环境存在后才使用。

## 三、把风格落实为方块构件

### 尺度试件

先按 [玩家尺度与尺寸起点](player-scale.md) 决定活动区净尺寸，再在完整设计所用尺度下试搭一个代表性跨间。下表偏向公共空间与较大构架，可调整，不是日常小室的最小尺寸、建筑或通行验收标准；后文的大体量完整方案也不是默认大小。

| 构件 | 可试搭尺度 | 调整依据 |
| --- | --- | --- |
| 次通路 | 净宽3～4格 | 会车、转角和栏杆碰撞；主通路可更宽 |
| 回廊跨间 | 柱间5～7格，柱宽1～2格 | 总体量与拱券轮廓；不要切片时重置节奏 |
| 厚墙门套 | 墙厚2～3格，框外再进退1格 | 门后转折、洞深与剩余净空 |
| 重要楼梯 | 净宽3～5格，转角设平台 | 实际方块碰撞与头部净空，不能按表直接判合格 |
| 平台 | 从用途反推深度 | 栏杆、设备、站位放完后仍有连续通路 |
| 主次檐口 | 大轮廓后再加1格级差 | 缩略图仍能看出主次，不让小构件吞掉轮廓 |

SAODG 对外端口仍按协议使用宽6、高5；上表中的普通门套和通路不修改端口约束。坐标记录区分地板方块顶面与玩家脚部高度，半砖不能按整格地板草率换算。

### 拱、穹顶与屋面

- **圆拱**：先设计内侧空气轮廓，再向外生成有厚度的拱圈。逐层收进的体素阶梯应左右连续，拱脚落在支墩上；不能只画一条弧线。
- **尖拱**：让两侧轮廓在顶点相交，检查顶点不变成狭长竖缝。按每跨一致规则生成，转角另设过渡。
- **筒拱与肋拱**：筒拱沿一个方向延展；肋拱需先定义跨间支点，再生成肋与填充顶面。装饰肋不能代替闭合顶盖。
- **穹顶**：记录起拱高度、顶点、内外壳及落座环；方形空间需要角部支承或过渡体块，别只截半球贴在墙顶。
- **坡屋顶与出檐**：先做完整坡面，再做檐口与脊。楼梯/半砖细化外轮廓时，背后保留闭合壳；檐下梁端与柱网保持关系。

### 梁柱、桥与楼梯

梁端落到柱头、墙垛或托座；偏离落点时增加可读的转接构件。奇幻悬浮也需要统一的锚固或能量支承语汇。

桥按“桥头—支承—桥面—边缘”组织，先保证两端接地与路线连续，再处理拱腹、横梁和护栏。重复立柱只有在横向构件或实际连接状态成立时才形成连续护栏。

楼梯从目标高差和可用水平长度推算，先保留梯段、平台与净空，再放梁、灯和装饰。转折点检查玩家头顶、栏杆碰撞及到达平台后的出口。装饰性的断梯不能承担必达连接。

### 墙面、道具与风化

墙面先分墙脚、主体、开口和顶部，按跨间组织进退；不必每面都同时使用所有层次。窗若只是视觉窗，采用当前策略允许的封闭窗面或实体凹龛，不能在初始外壳上偷留漏口。

道具按“主体—支承—接口—操作侧”设计：泵有机体与进出管，吊架有立架与横梁，书桌有桌面和站位。静态外观不能被描述为可交互设备。

风化按事件分区：积水沿低处，冲刷沿水路，烟熏集中炉口上方，倒塌有落块与残存支点。先保存原构造逻辑，再施加局部变化；不要对白噪声随机换材质。破损不得破坏必须路线和封闭边界。

## 四、可发展的完整构想

以下为未建模的原创设计提案。尺寸仅是起点，Y为局部坐标示意；不能把这些文字当作已有NBT或已通过通路检查的证据。可按用户要求改变骨架。

### A. 断渠修道院

- **组合**：修道院回廊＋古老水利改造；罗曼式石造为主。
- **全局体量起点**：96×40×48，两格连续整体，回廊节奏跨越X=48切面。
- **空间**：入口廊脚部Y=3，下沉沉砂庭Y=3，高渡槽与检修岸台Y=11，远端资料室Y=16。阶梯沿侧翼从岸台折返到高层，庭院有第二条侧阶。
- **主画面**：低入口先看见渡槽拱腹，绕过柱墩后看见庭院与高层资料室；登高后回望入口。
- **具体节点**：旧拱脚、插入式闸座、干燥检修桥、统一水位痕迹。两条侧阶若声称组成回路，分别验证其连接。

### B. 裂岩铸钟厂

- **组合**：矿井运输站＋铸造车间；矮人山城与工业附加层。
- **全局体量起点**：96×46×96的L形三格有效占地，不填缺角。
- **空间**：入口及原料台脚部Y=4，铸坑边作业台Y=9，上层吊架检修廊Y=20；步行道沿岩台连接各层，吊笼仅为静态景物。
- **主画面**：斜向岩缝里一半是自然壁、一半是厚重炉墙；巨大钟模位于作业层下方，检修桥从上方跨过。
- **具体节点**：吊架锚座、钟模分瓣、炉口厚墙、转运台与设备操作侧。岩缝属于内部空腔，外壳仍完整封闭。

### C. 树心星图馆

- **组合**：巨木圣所＋书库＋星象台；森林幻想结构。
- **全局体量起点**：48×46×96，两格整体，树干空腔斜向穿过切面。
- **空间**：根间入口脚部Y=3，侧枝阅览台Y=10，弧形档案廊Y=18，偏心星象台Y=27；人工阶梯补足根坡不可走的区段。
- **主画面**：入口只见下垂根系与侧面书墙，转折后树心展开；高处仪器朝向有星点的封闭内穹顶。
- **具体节点**：根系托住的平台、径向木梁、仪器环架与转轴、书柜前取阅面。不要把书墙、环廊和仪器都变成同心圆。

### D. 山门悬桥驿站

- **组合**：岩壁关隘＋商旅驿站；中式木构启发，石台基与木廊分工。
- **全局体量起点**：96×40×48，两侧岩台之间以偏轴廊桥连接。
- **空间**：卸货院脚部Y=4，桥面Y=12，住宿翼外廊Y=18；一侧石阶登桥，另一侧内梯接楼层，谷底另设可选检修支路。
- **主画面**：从压低的山门望见桥侧轮廓，过桥后进入错落厅堂；高廊可回看桥与卸货院。
- **具体节点**：桥头台基、梁端托座、檐下柱网、卸货台、客房门前廊。檐口不挡上层通路，谷体由全局岩壳围合。
