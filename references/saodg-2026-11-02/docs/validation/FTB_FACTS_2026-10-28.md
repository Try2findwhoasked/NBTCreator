## 准入脚本复现与修复

生成器 `python tools/prepare_admission_probe.py` 将当前真实准入脚本嵌入本地隔离配置/注册对象，输出忽略目录的测试脚本；不安装、不修改入场配置。复制到同一私有副本后通过实际 Rhino 运行，不调用真实入场。

修复前脚本 SHA-256 `f8d2f48fb243bb5b2debc6dd2871a0086ee183fd5b94318ab5ca8574cd231f73`：等级检查分支访问 Request 的不可变成员列表，Rhino 对 JDK 17 的 ImmutableCollections$List12 抛 IllegalAccessException。修复在脚本边界构造公开 ArrayList，保持 Request 原快照不可变。修复后脚本散列 `27062c3f0567b13f47bb9d472af5bfe5ba593c1dbfdd58fb4034f04efcca3809`。

同一日志中的 SAODG_ADMISSION_POLICY_PROBE 先 passed=false、再 passed=true。六个实际 Rhino 场景为：离线成员拒绝、可选 profile 跳过、配置关闭拒绝、最低等级未配置拒绝、任务前置未注册拒绝、迷宫区不在允许列表拒绝。只对克隆配置求值；真实注册仍每轮返回 pack_disabled，外部资产 UNKNOWN。

测试工具初版误用 JsonIO 读取脚本文本，后尝试的 Files 类被现有 class filter 拒绝；最终改为工具生成静态嵌入夹具，不读取受限类，也未修改白名单。保留工具失败日志，不作为生产脚本缺陷或成功场景。
