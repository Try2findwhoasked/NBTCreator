# 未连接门洞与房间墙体融合

2026-11-02，Minecraft 1.20.1 / NeoForge 47.1.106 / Java 17，版本沿用 `0.5.4-neoforge-dev`。在工作区已有修改之上继续，未修改上游参考仓库、生产建筑模板或房间池。

## 行为

未连接出口不再统一覆盖一层石砖。生成计划从当前房间已旋转、已对齐门高的模板取样，逐高度、逐深度延续门洞两侧墙面：左右各探测3格，左右半边分别采用对应材质，已有完整墙块保留。向内最多8格；从第二层起，任一侧没有可复制墙块就停止，避免跨过内侧空气去连接远处装饰。外层必须封实，缺少同高度样本时使用上下2格的墙面，最后回退石砖。

只复制无方块实体、无流体、非重力且碰撞完整的方块状态。材质的方向属性沿用模板旋转后的状态。不读取实例现有世界来猜测材质；新增填充写入仍经过原有异物预检、最后写入去重和分 tick 放置，位置限于所属房间内。已连接出口、钥匙门和虚拟首领入口沿用现有逻辑。

只影响新生成实例，不修补运行中的旧实例；不修改存档格式、网络协议或配置键。

- 范围 JUnit 6项通过：`RoomGeometryTest`，以及 `LayoutTest` 的标准端口四向对齐、稀疏形状旋转、断开形状/内部端口拒绝。日志 `logs/doorway-wall-unit.log`。
- `saodg_height` 的1项独立运行测试通过，覆盖自定义门高、实际放置、持久清单回读和清理，日志 `logs/doorway-wall-verified.log`。
- `saodg_wall_fill` 的4项独立运行测试全部通过，日志 `logs/doorway-wall-seals-batched.log`。覆盖三层墙体与保留原块的四向旋转、逐高度材质衔接、左右不同材质与上下取材回退、不安全材质排除，以及所有非虚拟/非传送场景房间在四个方向的生成计划出口封实。最后一项每 tick 检查一个房间方向；检查的是生成计划方块状态，不代表已在客户端逐房查看。
