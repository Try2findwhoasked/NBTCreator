# 游戏内 HUD 设置：0.41.28

源码提交 `5e9a75f46894e32d9f9c3cf6be38f57e8bc5ca97`。补充设计第 13 节要求的 HUD 位置/缩放配置交互，并修正关闭小地图连带隐藏队友状态、较大 HUD 超出小窗口的问题。

## 实现

- `/saodg` 面板右上角新增“显示设置”；Forge 的 Mods → SAODG → 配置同样进入本地设置页，无需依赖额外配置界面模组。
- HUD 开关、小地图开关、50%～200% 首选缩放，以及 0%～100% 水平/垂直位置；支持恢复默认。较低 GUI 高度按完整行显示，滚轮查看其余设置，底部操作固定。窄主面板标题收缩，避免与新增入口重叠。
- 设置直接复用既有 `ClientOptions`，退出设置页保存至本机 `config/saodg-client.toml`；返回原面板。不暂停服务器，不发服务端操作，不修改游戏权限、世界配置或其他玩家设置。
- HUD 放置使用当前 GUI 视口计算可用尺寸。首选比例超过可用宽高时临时缩小，并按归一化位置放置；不覆盖保存的首选值，扩大窗口后可恢复原比例。
- 小地图隐藏后，队友名、在线/倒地/淘汰等状态及生命条仍显示，改用完整行宽。整个 HUD 关闭时仍全部隐藏；外界淘汰者只读查看仍不绘制局内 HUD。
- 组队用法同步 0.41.21 已开放的开发生成/启动开关，移除必须使用旧 opt-in 和 STANDALONE 的过时配置指引。未改变入场、钥匙、奖励或实例隔离规则。

协议仍为 20，没有世界存档或服务端配置格式变化。所有新增界面和渲染类留在 client 包，配置入口沿用物理客户端注册路径。
