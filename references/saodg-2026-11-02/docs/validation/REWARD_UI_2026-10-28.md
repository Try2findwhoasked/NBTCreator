# 个人奖励页按钮重叠修复（0.41.1）

用户实际反馈“按钮重叠”。源码确认结算返回按钮与奖励分页按钮都放在 `panelHeight-50` 的左侧，确实占用同一矩形；另外固定四列档位和固定详情高度在窄/矮面板会越界。

## 修复

统一由 RewardPanelLayout 提供边界，列表分页、物品归还/经验重试、领取/结算返回分别放在不同横行；领取与返回分两列，底部完成按钮继续独立一行。
列表根据可用高度每页显示 1～4 条，超出继续翻页。档位按钮改为一组前后切换，不再固定四列排列；已锁定档位不能改选。未选档位时默认预览当前方案首个实际档位，领取前仍经服务端相同校验与回执。
详情区单独裁剪和滚动，长物品 ID 截断并提供完整悬停信息；价格/经验固定在详情内容首行，不覆盖页脚按钮。切换方案或档位重置详情滚动，不让旧方案数据残留。
代码与网络/奖励事务分离：版本 `0.41.1-dev`，协议仍 15，奖励与存档格式不变。当前进行中副本和已生成奖励不重掷。
