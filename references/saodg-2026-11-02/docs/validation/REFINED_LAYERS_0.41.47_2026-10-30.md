## 主体和墙模板

房间schema 5新增组合分片：

```json
"parts": [
    {
        "body_template": "saodg:refined/sword_oath/p00_body",
        "wall_template": "saodg:refined/sword_oath/p00_walls",
        "offset": [0, 0, 0]
    }
]
```

每对模板尺寸相同，使用相同局部原点，都是省略空气的稀疏层。加载器在内存中以空气初始化完整体积，再填入两层的实体方块，保存为既有不可变Part。后续体积覆盖、导入方块策略、场景标记、门高、旋转及放置流程继续验证完整合成结果，不直接将稀疏文件当作旧`template`读取。

拒绝层内/层间重复坐标（相同材质也拒绝）、显式空气、尺寸不同、越界、非法palette索引、多palette、实体/方块实体、禁用方块和错误Properties类型。每个源NBT仍限制2MiB、每轴1～48、合成palette最多4096。两层不修改源文件；门洞省略位置保留为空。schema 1～4的完整template/parts保持支持，不能在旧schema混用新字段。

这实现的是房间主体/墙层合成，不是独立门装饰NBT，也不是将完整墙层移入房间之间的49格接缝。未连接的门洞和钥匙门仍由原有石砖/煤炭块门禁处理。
