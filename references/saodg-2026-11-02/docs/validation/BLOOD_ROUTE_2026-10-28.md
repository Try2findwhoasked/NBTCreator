# 固定起点、主路钥匙与实体门（0.36）

术语同步（2026-10-31）：正文采用现用名称；版本、验证结果及代码/日志原文仍按当时记录。

2026-10-28，协议 9、目录 ruins-dev-10。按用户确认：通往封印大厅的主路保留清房/钥匙门，支路自由；用可见方块替代屏障。

当前入口使用固定入口模板、网格 `(2,5)` 与旋转 0。生成器在当前房间池中稳定选择同一入口，其余布局仍由种子决定。
BloodRoute 从入口到 OUTPOST（玩家称封印大厅）提取主路；主路每个中间房间完成后形成一份团队钥匙证明，右键下一道门才消耗；入口第一段自由。
钥匙数量由 completed 与 opened_route_doors 推导，不依赖背包物品；重复清房/点击不产生额外钥匙。
支路不继承活动房间封锁，封印大厅只要求主路完成；封印大厅完成后仍以独立首领钥匙和全队确认进入首领。
门和未连接端口使用磨制黑石砖，普通移动、技能、投射物与地图继续查询同一锁状态。
门区含未知方块或容器时拒绝改写，并在消耗钥匙之前校验。新 run 保存 route_policy=1 和 opened_route_doors；旧记录缺字段按 legacy 0 读取，重启沿用中止/回程策略，不替换活动布局。
