# 实际模板放置后的四旋转通行检查

术语同步（2026-10-31）：正文采用现用名称；版本、验证结果及代码/日志原文仍按当时记录。

新增 RoomTraversalGameTest，针对当前目录的 28 个逻辑房间及其全部允许旋转（四种），共 112 个场景。只读取已注册内容，未注册 beta 结构不参与也未修改。
使用独立 GameTest 世界、迷宫区维度的专用 fixture 区域 slot 32，与生产实例 0～3、制作预览 8～9 分开；不会指向用户客户端世界。

## 断言范围

每个场景调用生产 StructurePlacer.prepare/tick 实际分批放置模板，再以 Forge 实际碰撞形状查询做地面连通检查。以落点脚部高度、0.6×1.8 玩家碰撞体逐格遍历，不能穿过实体方块，不能踩入未占用的 L/T/十字缺角。
要求所有登记刷怪点、每个出口内侧门槛都在落点可达区域；秘密、铭文线索、谜题控制/提示/重置与首领封印，要求有六格范围内、在该连通区域中的站立点，射线首先命中确切目标。
外部端口仍按生产放置规则封闭，只检查房内至门槛的通路；主路实体门开启/碰撞通行由原实际战斗夹具另行覆盖，独立首领出口仍按用户要求封墙。
首领封印在转阶段才出现，原始模板中的位置应为空气。夹具先断言该位置无阻挡，再按现有阶段规则放置紫水晶块后检查接近与视线；不是声称所有原始模板都预先含封印。实际阶段生成回调由已有首领实局夹具覆盖。
每个场景完成后使用生产 CleanupJob 清理，并检查放置/清理两个票据所有者均释放；下一个场景的预检再次要求场地为空。故障时保留私有世界证据，不删除或接管未知资产。
