# SAO 文案与界面布局检查（2026-10-31）

当前版本：0.41.65-dev。本轮只调整显示和文案，不更改注册 ID、存档字段、协议或奖励规则。

## 显示处理

| 界面 | 本轮处理 |
| --- | --- |
| 攻略指南、队伍、当前房间、地图、战报 | 固定单行按实际字体宽度适配；按钮较长时补完整悬浮提示。原有指南与战报滚动保留。 |
| 队伍反馈、地图图例、房间说明 | 有限行数区域在超长时标记省略号，悬停查看完整正文；房间滚动后的悬停位置同步偏移。 |
| 个人奖励 | 状态、档位、经验/珂尔与物品名按详情列宽适配，不直接裁去后半段。 |
| 结算宝箱 | 汇总费用和按钮标签适配宽度；超过两行的通知标记省略号并提供完整悬浮正文。 |
| 攻略 HUD | 阶段、进度、钥匙/秘密、目标、交互提示、队友姓名与状态按各自区域宽度适配。 |
| 显示设置 | 预留说明与底部按钮空间；缩小窗口时减少可见设置行并滚动；总设置数量改为 6。 |
| 系统通知卡片 | 保留完整换行结果，按可用屏高显示；极窄窗口分段展示，不再固定丢弃第三行后的正文。 |

单行适配使用等比缩放；极长动态名称或数字仍可能较小。长说明通过悬浮全文阅读，不承诺全部正文同时平铺在小窗口里。
