# 谜题房间「挑战大积霸」

2026-10-31，分支 `codex/challenge-math-master`。用户在查看讲堂缩略图后明确同意精修，并要求接入神比 NPC、额外奖励与随机抽题。已保留原稿，基于同一完整主模型统一精修，再机械导出主体/墙面两层；运行资源为 `saodg:special/math_challenge`，已加入 `ruins_01` 房间池。验证结果见 [本次验收记录](validation/MATH_CHALLENGE_2026-10-31.md)。

## 玩家体验

右键「神比」（静止的图书管理员外观 NPC），在聊天中点击 A/B/C 作答，无交易菜单或答题 GUI。前三题答对即完成房间、获得正常参与记录并更新通路；答错可以重试当前题。随后可选择继续额外题，或结束挑战。

第四题为简单定积分，第五题为带初值的简单微分方程。每题只有一次作答机会，默认各增加 **30 副本经验**，默认两题都对共增加60；`0.5.1beta` 起可由管理员调整 `rewards.mathBonusXp`，每局开局冻结，聊天显示本局实际数值。第四题答错仍可做第五题。奖励随副本正常通关的个人基础奖励结算，遵循既有奖励启用门禁和参与资格；不直接修改 SAO 钱包。跳过额外题或答错不会撤销基础通关，跳过也不撤销此前已取得的额外奖励。见[配置说明](SERVER_CONFIGURATION.md)。

每个房间为本实例队伍共享进度，可接力作答。服务器依次接受当前 revision 的有效操作，旧题链接或重复点击不会推进下一题。玩家必须在本实例同一房间、神比 6 格范围内且无遮挡，并通过存活、非旁观、可行动及资产冻结检查。NPC 的真实实体 UUID 与出生坐标归服务器服务所有，复制 NBT/绑定信息不授予交互权限。

## 随机题库

实例第一次发现房间时，服务器用 `SecureRandom` 生成独立种子。基础题从以下六个题型中无放回抽三个，再生成小整数参数；每题三个互异选项重新打乱。因此前三题不固定，也不是每次重复同一组三道题。

| 阶段 | 题型 | 随机内容 |
| --- | --- | --- |
| 基础 1～3 | 四则运算顺序、一元一次方程、长方形面积、加法、平方、三个数的平均数 | 抽三个不同题型，随机参数与选项顺序 |
| 额外 4 | ∫₀ᵇ ax dx 或 ∫₀ᵇ a dx | 随机题型、正整数参数、积分上限和选项顺序 |
| 额外 5 | dy/dx=2ax 或 dy/dx=a，均给出 y(0)=c | 随机题型、系数、初值和选项顺序 |

`MathChallenge.VERSION=1` 的生成规则属于存档格式。`math_challenges` 保存每房种子、当前题号、revision、是否开始/跳过额外题及两个已答对奖励位。重建同版本状态会得到完全相同的题目和选项。后续若调整生成算法，必须新增格式版本并保留旧版本读取，不能用相同版本重新解释旧种子。

状态留在运行记录中，普通重连不会重抽。**服务器重启仍遵循项目既有策略：中止未完成副本、执行回收与返还，不恢复战斗副本继续答题。** 此功能不改变该策略，也不单独补发未完成副本的额外奖励。

奖励汇总由持久化的两个奖励位计算，结算快照加入 `mathBonuses`；非零时计入冻结奖励指纹。旧记录没有此字段时视为无数学挑战，旧的零数学奖励指纹保持原样。奖励领取继续走既有个人操作与玩家存档事务，重放领取不会重复支付。

## 建筑与内容接口

整体 48×28×48，单格占地，南侧一个标准 6×5 门洞，`door_y=2`，只声明 0 度。中央通道脚位 Y=2，讲台 Y=4，两侧座席 Y=3/4/5。黑板、积分符号、坐标曲线、算盘、桌腿、书册及柱头撑架均为真实方块。神比位于 `[24,4,12]`，讲台前侧，避免高讲桌遮挡交互视线；不在 NBT 中烘焙实体。

后排保留一个符合既有谜题房约定的观察铭文秘密：先阅读讲堂笔记，再调查对应铭文，沿用 `SecretService`。它与五道题的通关和额外奖励分别判定。

数学房使用 schema 5，`puzzle: "math"`、`math_npc: [x,y,z]`、空 `puzzle_controls`，不填写 `puzzle_scene`。加载器核对 NPC 坐标及其上方两格空气；运行时还检查实际落脚与实体碰撞。旧的六种方块谜题保持原接口，不能把数学房伪装成 `runes`。NPC 在首次发现时生成，关闭/回收时删除，不开放普通村民交易，不依赖归档 SAO rewrite 或 KubeJS 的内部 NPC 实现。

制作资产位于 `build/nbt_models/challenge_math_master/`：`draft_01` 为原稿，`draft_review` 为同源快照和实际对话授权记录，`refined_05` 为最终完整主稿、差异、对比图、检查和两份分层 NBT。保留中间版本；最后修正了书册、进度标记、书柜及壁灯的支承关系。生产资源只复制最终两层，制作脚本、模型和预览不加入源码提交。没有写入用户活动存档。
