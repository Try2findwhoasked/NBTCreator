SAODG / 建筑指南Minecraft Java 1.20.1

搭一间房，留好门，保存。

先做一间普通战斗房。配好模板与房间定义后，模组负责刷怪、开门和随机拼接。适用于当前 0.41.26。

01按这个尺寸建

房间：48 × 48 格

初次建议高 24 格；支持高 8～48 格。

门洞：6 格宽 × 5 格高

门开在墙正中；厚墙后面也要打通。

连接缝由引擎生成。每片模板宽 48 格，世界中相邻原点间隔 49 格，中间留一格连接。主线煤炭门生成在中间，未使用出口封石砖；支路及同一多格房内部无钥匙门。不要把外部连接缝存进模板。

02用结构方块保存

  1. 在单独的创造存档里建造。这个例子把房间最低西北角设在 0 64 0。
  2. 地板铺在 Y=65，玩家站在 Y=66；门洞从 Y=66 挖到 Y=70。
  3. 输入 /give @s minecraft:structure_block，把结构方块放在 -1 64 -1。
  4. 打开结构方块，切到 SAVE / 保存 模式，照表填写：
结构名称saodg:ruins/combat_01
相对位置 X / Y / Z1 / 0 / 1
大小 X / Y / Z48 / 24 / 48
包含实体关闭
显示边界开启

确认边框包含整个房间，再点 SAVE。

这个例子保存范围是 0 64 0 到 47 87 47。东西门横向为 Z=21…26；南北门则为 X=21…26。

文件在制作存档的：

generated/saodg/structures/ruins/combat_01.nbt

保存 .nbt，并配套房间 JSON。记录门口、落点、刷怪及秘密坐标；完整定义示例见文字指南第8节。

03用 door_y 对齐不同门高

地下室、洞穴或多层房可以把门开在不同的局部高度。每个逻辑房间用一个 door_y，所有外门共用它；房间内部的高低差自行设计通路。

默认模板门洞局部 Y2～6 → 基底世界 Y64
高 32 格，door_y=10门洞局部 Y10～14 → 基底世界 Y56
两种模板的外部门洞共同对齐世界 Y66～70
"schema_version": 4,
"door_y": 10,
"size": [48, 32, 48]

这是定义片段。门口 min.y=10、max.y=14，脚下地板 Y9；门高范围为 2～height-6。到达点、刷怪及机关写原始局部坐标，不预先减门高。引擎整体平移，不自动补内部楼梯。完整可填写示例见文字指南。

每片仍是48×48。多格可以连成一个大厅，内部不用加隔墙。导出时按作者的 48 格网格分片，偏移仍为 0、48、96；引擎在世界展开为 49 格间距并连通接缝。L形只存三片，缺角不存；同房所有分片共用高度和 door_y。

不要在模板里保存真实怪物、掉落物或刷怪笼。敌人由服务端按定义生成，普通房固定一批，精英房和封印大厅分轮。

05接入，再预览四种朝向

  1. 将模板放入 data/saodg/structures/...，定义放入 data/saodg/rooms/...。
  2. 把房间 ID 加入迷宫区定义的 layout.room_pool。仅放文件不会自动加入目录。
  3. 在独立制作世界执行 /reload，用 OP 2 权限检查：
/saodg admin validate
/saodg admin preview saodg:custom/combat_high 0
/saodg admin previews
/saodg admin previewvisit <预览UUID>
/saodg leave
/saodg admin previewclear <预览UUID> checked

示例房间需先自行制作并接入。preview 返回 UUID；状态 READY 后才能进入，且不能已有大厅或活动局。leave 返回原位置与模式，previewclear 排队清理。一次最多两个预览，清理后再依次检查 90、180、270 度；validate 不代替实际通行检查。

模板加载、随机拼接、旋转与预览已实现；新建筑仍需逐房验证。更多字段和完整 JSON 见 完整文字指南。本页可离线打开，也可用浏览器打印。
