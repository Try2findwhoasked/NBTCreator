# 副本事件音效

当前 `0.41.65-dev` 工作区包含 15 种原创合成短音效。素材为 44.1 kHz 单声道 Ogg Vorbis，总计约 141 KiB；不包含外部录音、其他模组素材或原版音频拷贝。运行时无需新增模组或音频库。

| 声音 ID（命名空间 `saodg`） | 触发事件 | 播放对象 |
| --- | --- | --- |
| `teleport` | 模组控制的传送成功，包括入本、房间/首领转移、重连落点、返回出生点或原位置、创作模式往返 | 被传送者；短促「呼」声 |
| `door_open` | 路线门/普通机关门的方块实际从封闭改为开放 | 本实例 16 格内成员；连续机械「咔咔咔」声 |
| `rune_portal_open` | 符文大厅尖拱门面由全空实际生成 | 本实例 48 格内成员；1.65 秒「呼——」风啸，带距离衰减 |
| `door_locked` | 缺少钥匙时尝试开路线门 | 操作者 |
| `room_clear` | 战斗、精英、封印大厅或解谜首次完成（首领完成使用胜利声） | 完成房间入口 16 格内的本实例成员 |
| `key_spawn` | 清房钥匙实体成功生成 | 钥匙 16 格内的本实例成员 |
| `key_pickup` | 钥匙确认收集，包括超时自动收集 | 本实例在线且未淘汰成员 |
| `puzzle_click` | 机关状态发生变化，尚未完成且未短路 | 控制器 16 格内的本实例成员 |
| `puzzle_reset` | 通过距离和权限检查的机关复位 | 操作者 |
| `secret_found` | 首次发现秘密，持久化共享事实后 | 本实例在线且未淘汰成员 |
| `boss_warning` | 首领开战、进入封印阶段、进入最终阶段 | 本实例在线且未淘汰成员 |
| `seal_activate` | 首领封印首次有效激活 | 封印 16 格内的本实例成员 |
| `victory` | 完成结果和结算场景准备成功 | 本实例在线且未淘汰成员 |
| `defeat` | 副本失败状态持久化后 | 本实例在线且未淘汰成员 |
| `reward_claim` | 本次实际执行奖励发放且持久化确认成功 | 领取者；重复领取、已有回执恢复、未确认结果均不响 |

所有新增音效由服务端业务事件触发，无客户端自报事件包。位置音效使用原版声音包逐个发送给本实例附近成员，保留距离衰减；共享进度音效仅向当前实例成员定向发送。个人提示使用玩家音量分类，位置音效使用方块音量分类，均尊重游戏音量设置。声音字幕已加入简体中文语言文件；按项目现有规则构建时同时生成基础语言文件。

本轮未更改存档格式、自定义网络包结构或准入/奖励规则。新增声音注册表和客户端资源需要客户端、服务端同步更新 JAR；本轮只生成本地构建产物，不安装到现有客户端或服务器。

门两侧作为同一图连接处理，一次真实开放只播放一段完整机械声；重复状态刷新或重复点击已开的门不会重播。解谜沿用原有服务端交互节流；历史接线短路的爆炸/雷击不再由当前接触器谜题触发，宝箱开关和战斗技能保留现有声音。

符文传送门首次生成时，同步向本局 48 格内、同维度且未淘汰的当前成员发送原版闪电生成包和电弧/扩散云雾粒子包。闪电落点为旋转后门面的底边中心，由原版客户端负责闪光、雷声和自行消失；服务端不添加闪电实体，因此不会造成雷击伤害、点火或实体雷击事件。风啸使用方块音量分类，原版雷声使用天气音量。门面已有传送门方块时的刷新/部分修复、关闭、外来方块检查失败均不重播；重启后保留的已开启门面也不重播。专项结果见 [符文开门验证](validation/RUNE_PORTAL_EFFECTS_2026-10-31.md)。

## 素材维护与试听

生成器：`python tools/audio/generate_event_sounds.py`，开发环境需 Python、NumPy、PATH 中的 FFmpeg（libvorbis）；不用于游戏启动。固定随机种子，不调用网络。`assets/saodg/sounds.json` 定义音效和字幕，`DungeonSounds.Cue` 负责注册、播放音量和事件 ID。

单独重生成符文风声：`python tools/audio/generate_event_sounds.py --only rune_portal_open`。该模式只编码指定 Ogg，仍刷新完整声音定义并补齐缺失字幕，保留其他已有音频文件。

可通过游戏的 `/playsound saodg:teleport player @s ~ ~ ~ 0.65 1`、`/playsound saodg:door_open block @s ~ ~ ~ 0.8 1` 单独试听，其他声音替换事件 ID 即可。游戏内验收应再检查：不同总音量/玩家/方块音量、字幕、双人不同距离、相邻双实例、跨维度返回和重连、重复开门/领取、首领阶段切换混音。自动化数据包测试不能证明实际客户端听感。
