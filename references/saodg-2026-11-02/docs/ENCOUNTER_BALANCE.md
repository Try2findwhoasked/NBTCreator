# 房间怪物与副本内战斗成长

2026-10-31。面向当前 Forge 1.20.1 开发代码；经验获取、经验发放和升级所需经验由独立任务维护。

## 刷怪分布

- 普通近战继续使用已审核的 SAO/Cataclysm、原版或构装体池；新增独立身份 `saodg:ruins_archer` 和 `saodg:ruins_brute`，分别复用原版骷髅弓手与劫掠兽的模型和 AI，不增加外部模组依赖。
- 每波先在每个实际占用的 48 格模板单元中扫描安全地面，并补充作者标记附近的逐格候选点。扫描上限为已声明最高刷怪层/门层加 2，受房间高度限制。只读取已加载区块，不扫描 L/T/十字形房间缺失的单元。
- 分配优先填充当前波怪物较少的单元，再选择距已放置怪物较远的位置。约每四个槽位一个弓手；弓手优先使用比最低安全层高至少 3 格的位置，攻击距离 32 格。大型怪使用独立近战槽位。
- 校验整个身体的碰撞、脚下支撑、房间边界和已准备实体间距。大型怪或蜘蛛放不下时，使用小型构装近战替代，保留该槽位的星标/小首领身份；小型实体仍无安全空间则停止该波，不重叠放置。
- 单波目标上限为 `min(16, max(作者数量, 6 + 单元数×2))`。进一步按整条路线波次数分配普通存活怪预算：`min(目标上限, max(单元数, 星标数 + floor(48 / 总波数)))`。当前试炼通常每波 8 只，标准 5 只，精英 5 只；均比旧 2–4 只增加。实际数量仍受原有单实例 64、全服 160 的限制。
- 保留只杀星标推进与可选怪残留规则。上述分配为长路线后段保留容量，不把消失当作死亡，也不通过扩大实体上限增加负载。

## 怪物原生数值（当前）

根据 2026-10-31 后续决策，已取消此前的统一数值试验：

- SAO、Cataclysm 与原版怪保留各自出生属性与修饰，不再用波次的 32–40 HP、4–5 攻击覆盖，不移除其生命/攻击/护甲/韧性修饰。
- 新增 `ruins_archer` / `ruins_brute` 分别继承原版 Skeleton / Ravager 的生命、攻击、护甲与韧性。弓手保留远程站位、32 格攻击距离和目标追踪范围，出生装备仍固定为受管弓。
- 不再附加人数 HP 倍率或大型/小首领角色倍率。原生小首领和原生最终首领也保留其自身数值。
- 独立模式的 SAODG 自有构装体、替代身体、自有首领和自有守卫继续使用既有遭遇/首领 JSON 中的自有参数，无新增截断或倍增。例如自有首领沿用定义的 320 HP，不因移除外部覆盖而退回普通僵尸的 20 HP。
- 移除怪物攻击属性×1.25 的单击伤害上限，普通攻击、特殊攻击和已登记投射物走原有伤害链；原有实例权限、玩家互伤拦截、阶段机制与资产保护仍保留。
- 原生数据跨等级存在差异；此决策保留其差异作为下一轮实战比较基线，不代表当前随机怪物池已通过平衡验收。

## 玩家成长（当前）

已移除 `DungeonCombatCurve`、`DungeonCombatScaling` 及其伤害事件订阅。玩家不再因副本等级增加输出或减少承伤，不附加有效生命倍率。

玩家继续沿用现有 SAO 等级、职业、装备、技能及既有平衡补丁。SAODG 独立等级的经验、显示、解锁和资格逻辑保留；原生经验发放、通关经验、基础奖励和宝箱逻辑本次没有修改。

本次数值取舍依据见 [玩家成长审查](validation/PLAYER_PROGRESSION_BALANCE_REVIEW_2026-10-31.md)，当前回归与未验证范围见 [原生数值恢复记录](validation/NATIVE_COMBAT_STATS_2026-10-31.md)。前一轮指数倍率测试仅是历史实现记录：[ENCOUNTER_BALANCE_2026-10-31.md](validation/ENCOUNTER_BALANCE_2026-10-31.md)。
