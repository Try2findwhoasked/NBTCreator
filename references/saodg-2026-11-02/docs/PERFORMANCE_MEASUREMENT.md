## 离线导出可核对报告

`tools/verification/export_metrics.py` 从 UTF-8 控制台日志读取一次完整命令输出，不连接服务器、不修改存档、不自动判断达标。命令示例：

```powershell
python tools/verification/export_metrics.py logs/server-sampling.log --scenario two_parties --context logs/sampling-context.json --output logs/two-parties-metrics.json
```

输出父目录需已存在，输出文件必须是新文件；既有日志/报告不能覆盖。`--context` 可省略，内容是管理员提供的 JSON 对象，可填写实际安装版本/产物散列、硬件、人数、采样时长和背景负载。工具不会用当前源码版本代替已安装服务器版本，也不会自行补全未测元数据。

报告保存源日志 SHA256、命令块原始首尾行号/头部时间、场景、九类样本数和毫秒统计。无样本指标使用 null，与测到 0ms 区分；不同分类滚动窗口不属于同一时间区间，也不能相加，报告明确保留此范围。TPS、内存和跨模组成本未由这些行测量。选择同硬件、版本、人数及实际背景负载一致的场景报告才能分析增量，场景名本身不证明相应负载发生。

默认取最后一个命令块，若不完整则拒绝，不能拼接上一条命令的行或静默回退。可显式 `--snapshot 1` 选择第一块；重复类别、非法数值、超出实际窗口容量及矛盾分位数均拒绝。当前解析器支持本项目中文命令格式，未知/损坏格式不会猜测。
