# 队伍准备、难度与 NPC 入口

2026-11-01，NeoForge 1.20.1 / Java 17。以下为当前实现。

- 主界面三个入口：队伍准备、探索与房间、奖励与战报。探索页显示当前目标，右上角打开房间详情；奖励与报告按运行 ID 互相定位。
- 攻略通过 `/saodg guide` 打开，主界面不再提供攻略标签。SAO 项目的地牢引导员提供攻略、`/saodg party`、`/saodg rewards` 聊天按钮。
- 管理员规则配置从 `/saodg admin config` 打开，包含难度分类；所有玩家可通过 `/saodg display` 或 `/saodg config display` 打开本机显示设置。游戏规则仍保留服务端权限检查；显示偏好仍写入本机客户端配置。

## 入场与死亡风险

准备时检查玩家所在世界及副本世界的 `keepInventory`；任一关闭则显示死亡物品可能全部遗失的警告。每名成员点击“确认遗失风险并准备”后，还须在确认窗口中接受。命令入口为 `/saodg ready confirm_loss`，普通 `/saodg ready` 不会默认为接受风险。

服务端将同意绑定玩家、队伍、修订号、成员、难度和游戏规则。修改难度/成员、退出或断线使旧同意失效；出发前再次检查。物品损失沿用实际死亡规则，不新增清空背包逻辑，不承诺物品找回。SAO 倒地不等于确认死亡。

## 四档难度

| 显示名称 | 稳定 ID | 默认最低 SAO 通关层数 | 默认生命/攻击倍率 | 默认地牢经验上限 |
|---|---|---:|---:|---:|
| 简单 | `trial` | 5 | 1 | 120 |
| 标准 | `standard` | 10 | 1.25 | 240 |
| 高难 | `elite` | 15 | 1.6 | 420 |
| 极难 | `extreme` | 20 | 2 | 640 |

旧 ID 保留，已有记录不改名。极难使用高难的房间序列、独立计时目标和奖励档位；详细属性、怪物池和密度由 [JSON 难度配置](DIFFICULTY_JSON.md) 定义；材料奖励沿用高难的物品规则。没有为极难新增或删除生产房间。SAO 原生通关经验保持最高 720 的现有限额。

“难度”分类可逐档修改 `difficulty.<ID>.requiredFloor`、`enemyType`、`enemyCount`、`healthMultiplier`、`attackMultiplier`、`supportMobs`。敌人类型可选自动、构装体随机或明确指定僵尸/尸壳/蜘蛛/卫道士。自动模式使用 JSON 加权池，其中 `AUTO` 抽签项沿用管理配置中的原生敌人/原版敌人开关；固定类型不混入弓手、重装兵，最终 Boss 类型沿用原配置。

每波数量 0 表示自动，1–16 为请求数量；仍保留星标必杀数、可选敌人存活预算和每实例/全服实体上限。生命和攻击倍率在 JSON 角色/种类/房间属性或原生基础属性上计算，新版 JSON 配置还覆盖阶段援军；其他模组独立计算的技能伤害不保证受基础攻击倍率影响。敌人配置与经验配置在新开局时写入运行日志，之后修改不影响该局。旧日志无此字段时保持原倍率 1。

## SAO 通关进度适配

权威来源是 FTB Quests 队伍主线最终登记任务的 `TeamData.isCompleted(QuestObject)`，每位成员使用各自所属 FTB 队伍的数据。不是当前维度、玩家等级、奖励领取标志，也不写回 SAO/FTB 进度。准备和最终出发时重读；达到所需楼层或更高楼层的最终登记即可通过。

优先读取整合包 `kubejs/config/sao_growth_and_weapons.json` 的 `clearQuests` 映射；无该文件时使用随包的 `saodg/sao_floor_quests.json`。映射包含 1–20 层，16 位十六进制任务 ID 始终以字符串解析。配置了没有映射的楼层、映射损坏、FTB 缺失或任务/队伍无法读取时拒绝入场，显示“进度不可用”。

默认四个最终登记为 `7FFFFAA39722F744`、`536EDBE03401ACFF`、`523203B267189569`、`493488E3C144DEDA`。对接依据为 SAO 项目 `docs/SAODG_NPC_HANDOFF.md`；另使用实际安装的 `ftb-quests-forge-2001.4.22.jar` 核实了反射 API 签名。

`difficulty.requireSaoFloors` 默认开启，即使 `unrestrictedDevelopmentEntry` 开启仍检查楼层。独立开发环境可明确关闭；隔离 GameTest 的专用启动夹具会关闭此外部依赖，楼层拒绝测试单独重新开启。

协议版本从 26 升为 27，客户端与服务端需要一起更新。现有配置文件增加缺省项，不迁移或覆盖已有玩家数据。真实 SAO/FTB 联机、进度重置及两客户端重连仍需在整合包里验收。

## 精细难度与等级奖励

新开局读取 `config/saodg/encounters.json`，提供角色/怪物/房间覆盖、加权怪物池与深度成长，并加入末地巨像和重甲卫士。地牢等级升级发放纪念品，具体优先级、预算和事务兼容性见 [DIFFICULTY_JSON.md](DIFFICULTY_JSON.md)。
