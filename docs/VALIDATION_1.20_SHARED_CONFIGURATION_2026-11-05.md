# 共用配方与操作状态核验

本轮检查任务状态与配置读取的一致性，不增加工作区按钮。

## 行为变化

- 建模任务暂时锁定控件，完成后恢复各控件原来的禁用状态，不再统一启用所有按钮。业务模块仍按当前候选、目标和任务状态更新自己的入口。
- 全部建模工具停用时，“添加到工具序列”不可用；已有步骤仍可编辑。仅启用一个工具后，保存配置即恢复其入口，并可跨重启保持。
- 配方编译期间，名称、参数、位置、主题和高级 JSON 一起锁定，关闭入口保留。
- 配方和材质主题的读取结果包含规范内容哈希。UI 编译绑定已读取版本；外部 Skill 修改同一编号配置后，拒绝旧结果，点击左侧名称重读后可以继续。候选及原稿不因拒绝发生变化。
- CLI 支持可选 `--revision-sha256`、`--theme-revision-sha256`，并返回实际采用的版本；旧调用不指定哈希时继续读取最新配置。数据目录与原 JSON 格式保留。

这不是同一建筑或整个工作区的全局写锁。配方版本校验解决“采用哪个已读取配置”的问题；对同一对象的同时写入仍遵守现有协作边界。
