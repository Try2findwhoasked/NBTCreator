# 1.3.0 · 单栏导航与Agent交接

## 行为

- “项目 / 视图”与功能页导航合并一行；保留Windows原生标题栏、窗口按钮与文件选择框。点击项目/视图按钮调用Electron原生系统菜单，不再固定显示独立菜单行。提示词方案排在模型编辑前。
- 模型页主面板去掉外侧大间距和圆角留白，保留控件内部间距及边界；提示词/API页适配44px顶部导航。900px窄窗口不与顶部导航重叠。
- 模型编辑的“生成 Agent 修改方案”生成交接文档、参数副本和原有操作计划/校验包。“复制给 Agent”写入系统剪贴板，文字明确由Agent完成修改并在原建筑工作文件夹另建下一版。提示词页载入当前模型时也以原建筑工作目录作为输出位置。
- 当前建筑的 `Agent交接/` 为共用资料目录，每次创建独立 `plan-任务编号`、`review-任务编号`。审阅区默认展开，显示共用路径；打开建筑自动关联匹配源路径和SHA256的审阅目录。保护配置、真实确认及计划仍在执行时验证，不制造批准。
- “在应用中执行已确认计划”为折叠的可选入口。Agent已经交付下一版时刷新列表即可，不重复执行；本地执行也另存在源工作目录的精修版本中。旧目录不删除，仍可手动指定旧审阅路径。
- 方块下拉选择延后到滚动布局完成后展开，解决紧凑侧栏下打开即关闭的问题；用户继续滚动页面仍会关闭下拉列表。
