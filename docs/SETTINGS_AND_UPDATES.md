# 设置、关于与下载更新

顶部“设置”分为常规、模型预览、工作区与存储、更新、关于五类。常规配置可调整启动页、界面密度、缩放、窗口大小记忆和视口提示；模型预览可调整自动预览、延迟、3D 质量、范围框及图片数量。

应用偏好保存到当前工作区 `.nbtcreator/preferences.json`，切换工作区时读取目标工作区的配置；首次缺少本地配置时，会迁入旧用户偏好并保留旧文件。模型质量和图片数量默认值用于之后打开的模型。API 密钥和更新访问令牌仍在本机用户目录独立加密保存，设置页列出实际路径和打开目录入口。

工作区与存储页显示 `.agents/skills/nbtcreator-workspace/SKILL.md` 的实际位置，可预览入口，并复制接入说明给 Agent。入口通过相对路径链接到工作区内的工具副本和已启用资料；Agent 需在同一项目下发现或主动读取入口，并非所有 Agent 都会自动加载。

新修改方案位于当前结构版本的 `Agent交接/plan-任务编号/`，审阅位于同版本的 `review-任务编号/`。上层目录中已有的旧审阅仍按源路径和哈希匹配读取，旧记录不会删除。

“关于”页显示应用版本、系统架构、Electron/Node 版本、Python 解释器与项目定位。

## 一键拉取更新

点击“检查更新”后，应用会读取固定项目在 GitHub 上的最新稳定 Release，比较版本数值以避免降级。选择应用包或完整便携包后，文件会下载到用户配置目录的 updates/版本/，页面显示下载进度。下载完成后检查长度与 SHA256，通过后才将 partial 文件转为正式 ZIP。校验失败时，保留先前已验证的文件，清理本次 partial 文件。

更新功能负责检查、下载和校验，**不自动安装或覆盖正在运行的程序**。点击“打开下载目录”，关闭应用后解压；依赖版本不兼容时选择完整版或配套 runtime。更新包不写入建筑工作区。

私有仓库需要对本项目具有 Contents 只读权限的 GitHub 令牌，可在更新页单独加密保存或删除。应用不会复用 AI Key，也不会把令牌传到下载 CDN。公开可访问的发行版无需令牌。下载地址固定为本项目资产接口，重定向仅允许GitHub 资产域；校验文件也从同一 Release 读取。

版本和下载协议参考 GitHub 官方接口：[Release](https://docs.github.com/en/rest/releases/releases#get-the-latest-release)、[Release asset](https://docs.github.com/en/rest/releases/assets#get-a-release-asset)。
