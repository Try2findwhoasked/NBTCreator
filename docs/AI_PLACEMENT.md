# 3D选点与AI立即生成预览

模型编辑 → AI建模 → AI添加小型结构，设置放置范围宽/高/深（1到64格），点击“3D选点放置”。在 3D 中点击建筑表面，以表面外侧相邻方块为参考更新局部选区，范围不会超出当前模型的整体尺寸。选点本身不会生成评论、调用 API 或改动方块。

选好构件参考并填写要求后，点击“生成并立即预览”后，会依次生成 API 候选、校验受限步骤、由本地引擎插入候选并刷新 3D 效果。生成期间源或参数发生变化时，会拒绝过期结果。失败信息显示在 AI 状态区；保护区、实际材质与数量上限仍由本地引擎检查。受限构件支持 box/beam/frame 组合，最多 128 步，不支持任意代码或大型完整建筑生成。

生成结果追加到工具序列，原模型不变。满意后点击“导出建筑下一版”；3D 候选效果不代表 NBT 已保存。仍可使用“生成建议”先审阅再采用，或通过修改范围直接指定 XYZ。放置范围暂不扩展原模型边界，边缘处会向界内收拢；插入可能与既有方块重叠，应检查预览。

1.7.1 修复了选点模式阻断左键旋转的问题：单击选点，拖动超过 5 像素则转动视角，不产生选点。部件支持简短 blocks/steps 数据、自动填常规字段、默认局部坐标、梁端点推导边界、air 开口和较多步骤；仍保留真实范围、状态、源保护与预算校验。放置尺寸上限为 64 格，仍不超出源模型。
