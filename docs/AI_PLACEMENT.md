# 3D选点与AI立即生成预览

模型编辑 → AI建模 → AI添加小型结构，设置放置范围宽/高/深（1到32格），点击“3D选点放置”。在3D里点击建筑表面，以表面外侧相邻方块为参考更新局部选区，范围不会超出当前模型整体尺寸；选点本身不生成评论、不调用API、不改动方块。

选好构件参考并填写要求后，“生成并立即预览”一次完成API候选生成、受限步骤校验、本地引擎候选插入和3D效果刷新。生成期间源或参数改变则拒绝过期结果。失败信息显示在AI状态区；保护区、实际材质与数量上限仍由本地引擎检查。受限构件支持box/beam/frame组合，最多128步，并非任意代码或大型完整建筑生成器。

生成结果追加到工具序列，原模型不变。满意后点击“导出建筑下一版”；不要把3D候选效果当作已经保存的NBT。仍可使用“生成建议”先审阅再采用，或通过修改范围直接指定XYZ。放置范围暂不扩展原模型边界，边缘处会向界内收拢；插入可能与既有方块重叠，应检查预览。

1.7.1修复选点模式阻断左键旋转：单击选点，拖动超过5像素转视角且不产生选点。部件支持简短blocks/steps数据、自动填常规字段、默认局部坐标、梁端点推导边界、air开口和较多步骤；仍保留真实范围、状态、源保护与预算校验。放置尺寸上限为64格，仍不超出源模型。
