# API与Skill配置 · 0.3.0

**0.3.0当前布局**：AI助手工作区仅保留API和AI相关配置，右侧为当前工作区的Skill暴露配置（可选知识组）。生成任务不在此页：提示词使用“提示词方案”的AI完善方案，结构建议使用“模型编辑 → AI建模”。结构建议控件已迁往模型编辑，协议与安全边界不变。

在桌面右上角点击 **AI 助手 / API**。API默认关闭；离线使用的skill、CLI、参数工具、标注和导出不依赖模型服务。

## 配置和调用

1. 选择DeepSeek预设，或兼容Chat Completions接口。
2. 填API根地址、模型ID、Key，勾选启用并保存。地址应为HTTPS；本机服务允许127.0.0.1/localhost HTTP。根地址后由程序追加 `/models` 或 `/chat/completions`；例如兼容服务通常需要根地址包含 `/v1`。
3. 点击“测试连接 / 获取模型”请求模型列表。模型ID可手动填写，不把静态预设当作账号实际可用模型清单。
4. 在本页保存API配置或知识组后，切换到提示词方案生成设计建议，或在模型编辑的AI建模页规划简单结构。保存配置、打开设置页不发网络请求。

Key由Electron主进程使用safeStorage异步加密，放在当前用户配置目录的api-settings.json，不保存进工作区/模型文件/导出参数/资料库。渲染界面保存后清空Key输入，仅得到hasKey状态。同一服务地址留空保留旧Key；更换服务来源而未输入新Key时清除旧Key，防止发给另一服务。“删除Key”显式删除。当前加密保护不意味着同一Windows用户下的其他程序绝对无法访问。配置文件损坏时回到关闭状态，不阻止离线建模。

无Key的本机兼容服务可以使用。没有Key但访问要求认证的远程服务会返回HTTP错误，不自动寻找环境或其他应用中的凭据。90秒超时，可取消，不自动重复计费重试。

## 两种任务

### 提示词方案工作区的 AI（0.2.1）

从顶部“提示词方案”进入，在右侧点击“AI完善方案”。直接复用已保存的主界面API配置，不在子页面保存Key；“API设置”切换到主AI工作区，关闭后返回原提示词页。主进程仍只接受主frame IPC，提示词iframe通过受限父页面桥接调用prompt模式，没有开放Key管理或任意IPC。

填写补充要求后生成候选，可手动编辑再“采用AI建议”。仅把AI文本用于设计要求段；本地任务输入元数据、阶段执行边界、工具序列JSON、验证上下文和交付要求继续由原参数生成。下载Markdown与复制读取实际采用的版本；计划JSON仍只导出本地操作计划。修改表单后AI稿失效，自动回到参数生成稿；可重新生成或点击“使用参数生成稿”。保存/导入方案保留与当前参数绑定的AI稿。

自动发送范围为建筑设计文字和筛选后的工具参数，不包含source/output/contextPath/reviewPath、保护配置或自动加入的源哈希说明。用户手写的补充文字仍会发送。方案过大时先缩短再生成；未启用API、独立浏览器/file页面均可继续离线编辑。

### 主 AI 工作区

- **提示词**：返回可复制/下载的中文任务正文，不执行工具。
- **简单结构**：先在“修改范围”取消整座建筑并指定局部XYZ。API仅生成局部填充、挖空、外壳、移动、地板、天花、围墙、边框或精确换块的settings_patch。检查结果后点击“载入参数并预览”，本地后端先检查源哈希和参数，再按原保护区计算效果。正式NBT仍需用户明确导出。

模型或任意效果参数在生成后改变时，旧建议不能直接载入。生成计划不能扩大用户选区；移动目标也必须在该范围内。不接受任意Python/shell、导出路径、批准字段或未支持工具。方块注册合法性、保护、预算、碰撞与导出验证仍由原引擎执行，JSON合法不代表建筑完成。

载入计划会替换结构/换块模块，保留其他效果模块。预览不等于运行验收；依然需要检查支承、净空和实际图像。第一版不是自主Agent循环，不自动读取图片或修改意见，也不自动批量导出。

## 发送范围

发送用户本次输入，以及已打开模型的尺寸、选区、最多32种材质/数量；不自动发送模型路径、完整方块数组、图片或意见文件。用户自己写入输入框的文字会随请求发送。API请求与响应不落入模型任务日志；用户可主动下载生成结果。

配置错误、空输出、截断输出、401等接口错误会提示；错误响应正文不直接展示，避免服务端回显密钥。JSON模式可针对不支持response_format的兼容服务关闭，但结构输出仍需能解析为合法JSON。

## 验证范围

`npm run test:api`：默认关闭不联网、加密保存/删除、最小上下文、受限结构、非法字段/越界、空/截断输出、错误信息、取消和并发拒绝。

`npm run test:api-desktop`：本机模拟HTTP接口 + 真实Electron safeStorage和Python引擎，检查配置、模型列表、提示词、局部计划、旧参数拒绝、本地预览和原稿保留。没有使用真实DeepSeek Key，不宣称真实服务连通或模型质量已经验收。

0.2.1联调还包含提示词iframe共用连接、AI稿采用/失效/方案往返、真实Electron文件下载、共用设计变量，以及顶部功能页和窄屏切换。
