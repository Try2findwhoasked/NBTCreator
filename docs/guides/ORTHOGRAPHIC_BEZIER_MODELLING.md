# 用三视图和贝塞尔曲线建建筑粗模

适合先确定外形再建模的建筑，例如层叠塔楼、外挑平台、曲面屋顶和不规则地基。先让使用者确认三视图。从三视图读取坐标，生成一版只含主要体量和构件的粗模。待轮廓、连接和留空通过看图后，再铺开材质与细部。

## 配准参考图

1. 先定正视、侧视、俯视的方向、共用原点和方块尺度。一种约定是正视从 −Z 看 X/Y，侧视从 −X 看 Z/Y，俯视从 +Y 看 X/Z。把朝向写在图上，同时记下俯视图 +Z 的屏幕方向。
2. 从参考图找能跨视图对齐的部位，例如基座顶部、裙边最宽处、层盘转折、挑台端点和尖顶。三张图保持同一方块比例，同一构件在正侧图的高度必须一致，端点在俯视图有对应的 X/Z。
3. 如果只有透视图，记录可见坐标的量读依据，把未知的进深、方位和被遮住的轮廓标为推定。生成式图像可以补充参考，三张图仍要用同一套坐标和共用锚点核对。出图时把图面比例、实际主体包围盒和制作画布尺寸分别写清楚。占满画布需要改变比例时，先让使用者决定。
4. 保存确认过的图与锚点数据。建议每条锚点记录构件名、坐标和依据，保留图与数据的 SHA-256，便于从同一输入重跑并确认对比对象。

## 把轮廓拆成可拟合的段

| 部位 | 锚点 | 建模方式 |
| --- | --- | --- |
| 分层塔体、裙边、尖顶 | 在相同的 Y 读取左右边界 `x_min/x_max`、前后边界 `z_min/z_max` | 按构件分段拟合四条边界。每个 Y 还原中心和两轴半宽，生成椭圆或多边形截面后放样。 |
| 挑台、桥体、檐片 | 俯视的平面外缘、正侧视的顶底高程及相邻构件的落点 | 沿平面外缘分段拟合闭合曲线，再按厚度拉伸。针塔和吊杆用独立中心、上下端及截面尺寸。 |
| 裂岩、洞穴和不规则底座 | 正侧视的轮廓折点、不同高度的凹口和独立的透空边界 | 分别拟合外缘与孔洞，先用投影约束截面，再按已有证据决定截面的深度和形状。 |

连续曲边用三次贝塞尔段。起点和终点落在确认的锚点上，相邻段共享端点。对于以 Y 为自变量的边界，可令两个控制点分别在此段高度的 1/3 和 2/3。侧向控制值由相邻坡度推导，在锚点局部极值处收住手柄，并按需要限制在两端包围内，避免鼓出额外体量。实际台阶、尖角、切口和薄檐保留分段接点，可以用短手柄或独立的直边。先保住能辨认的转折再决定平滑程度。

在创作项目根目录用 [共享工作区入口](SHARED_WORKSPACE.md#对齐目录和工具版本) 查询当前工具契约。外部制作脚本可以跟随已确认的数据生成采样截面。原生 geometry 的 `loft` 在指定截面之间做线性插值，使用它时可提前对贝塞尔段取样，并传入相同顶点顺序的全局 XZ 截面。geometry 的 `bezier` 适合沿三维曲线扫出圆管。截面字段、采样限制和写入规则见 [建模工具](../../.agents/skills/minecraft-nbt-modeler/references/modelling-tools.md)。

## 体素化与回投影

1. 对照真实方块尺寸采样闭合区域。先在统一的全局坐标中合并体量，扣除声明的裂口和孔洞。检查细尖、薄片、斜翼在取整后是否断开，按构件检查接触面和设计留空。
2. 从实际方块投影出正、侧、俯三面，再与确认的锚点投影比较。用同一朝向、尺度和原点定位新增与缺失处。可同时记录轮廓交并比与 1 格容差内的覆盖率。容差检查做两个方向，分别查参考轮廓附近是否有模型方块，以及模型轮廓附近是否有参考方块。误差集中在裙边、孔洞、尖顶或挑台端点时，用局部叠图检查，整体分数可能掩盖这些部位。
3. 用斜侧和仰视图查看两组二维轮廓之间的三维关系，尤其是偏心、截面空隙和平台承接。投影吻合依赖输入的深度假设。带室内用途的设计还要检查必要通路与声明开口。
4. 若整体超过当前运行时的单份制作源上限，仍先统一生成并检查完整几何，再按全局偏移保存为可读取的 SNBT 分区。清单记录偏移、尺寸、源哈希和墙层归属依据。逐份回读后按原偏移合并，比较方块状态和显式墙层。分区边界用于储存，继续修改时使用全局坐标。

## 示例

艾恩葛朗特浮空城以外挑端点之间的 300 格作横向基准。三视图估算主体高约 268 格，置于 300 × 384 × 300 的画布中。主塔、裙边和尖顶分别放样，伸翼和针塔从俯视坐标定位，裂岩与底部透空单独建模。使用者资料留在创作项目，复现时可选同类型参考来建立自己的三视图。 [外观参考图](https://wall.alphacoders.com/big.php?i=700049)

在精修时，先用一段叠板、一道暗槽和一条真实通路检查形体、背衬和尺度。正面验证轮廓和层级，斜视或剖面验证进深、接触与暗缝。样段验收后，沿同一断面基准铺到整栋建筑。各层交由不同作者设计时，先从整塔路线投影楼梯、落脚及通行净空，再发可写域。各片回装后在整塔上重新核对。 [案例复盘与工具开发清单](../development/LARGE_MODEL_ROADMAP.md)

交给使用者审阅时附上三视基准、贝塞尔控制点、制作源及回投影图。使用者看过并明确确认当前粗模后再精修，定稿导出仍走独立流程。 [建筑方案到主模型](../../.agents/skills/minecraft-nbt-modeler/references/architecture-workflow.md) · [SNBT 制作源与定稿](../../.agents/skills/minecraft-nbt-modeler/references/snbt-authoring.md)

## 参考还原的实际审阅顺序

1. **确定还原目标。** 记录参考版本和视角、必须保留的轮廓与功能，区分“看起来有多层”和“每层都能进入”。单张透视图或生成的三视图不能证明背面、内部布局或实际层数；缺失部分列为设计假设，先与使用者确认范围。
2. **先检查尺寸是否能容纳关键构件。** 分别记录制作画布、实际占据范围及独立构件的包围盒，标出接合面、朝向、楼梯入口和所需净空。把比例优先、可用性优先或高度限制写清；构件装回后改变整栋高度或遮挡通路时，更新整体方案并让使用者选择，不能暗中压缩建筑。
3. **按观察距离排序细节。** 远景先看大轮廓、层盘的外挑与内退、上下深浅和不对称；中景看窗口、斜向搭带及构件接头；近景再看凹槽深度、纹样和半砖收口。用正面、斜面及剖面区分实心凸条、退进的空隙与带背衬的阴刻；不能只换颜色来声称几何有进深。
4. **先做小段再铺开。** 选一个包括窗、檐、斜搭带和凹槽的代表段，保留源模型、实际方块和固定机位的前后图；核对净空、背衬、支承和在目标距离的可辨性。失败时记录具体部位、预期和可见差异，再改候选，避免把未经验证的局部方案重复铺到整栋。
5. **分别审阅外观与可用性。** 同机位图对照参考时保留照明、裁切和尺寸信息，明确哪些部位被遮挡或只是推定；整体投影分数不能证明纹样、层级、室内和背面正确。独立构件安装后重新核对入口、往返路径与相邻区域；静态通行和渲染结果分别记录，游戏内放置、光照与交互未检查时写明。

多人或代理协作时，先绑定同一个主稿版本，交付切片原点、可写域、只读邻区以及来自整栋路线的楼梯、落脚和头顶净空；同时保存原始切片和回传差异。逐片核对越界与重叠，再在完整装配上做跨接口往返检查。局部通过不能代替整栋检查；超出当前工具支持时，这些步骤仍需任务脚本和人工核对，不能把项目自建清单称作原生组装主稿。
