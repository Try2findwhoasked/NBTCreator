# AI 工作流：构件参考、截图与任务记录

构件参考扩充为 6 组 45 项，覆盖结构入口、通行高差、房间设施、主题装饰、遗迹自然与自由组合。参考只用于表达需求，不是固定模板；选“自定义部件”后可在要求中自行描述。

小型结构只支持 box、beam、frame。普通 JSON 最多 128 步，严格 Schema 最多 48 步，截断重试时最多 24 步。复杂构件可分成独立预览后组合，或用资产管理的独立结构、选区工具编辑。选区工具编辑每次最多 32 步，读取完整选区，最多 65536 格、4096 段或 128 KiB 摘要。已有工作台序列最多 128 步，小改动可用带基线指纹的最多 16 项增量保留其余步骤。

独立结构和选区编辑能识别常用屋顶、楼梯等表述。螺旋梯可用 `auto_stairs mode=spiral`，歇山顶使用上下两层屋顶组合，需在实图中核对山花和交接。自动检查覆盖可识别的明确建造请求，具体比例、支承和全部设计要求仍需看图与本地验证。普通 JSON 的几何预检能定位步骤时可只修复失败项，再复验完整序列。跨选区依赖、保护和实际改动量仍在绑定原建筑的预览中校验。

## 工作流截图

在 AI 助手 → 内部 AI 中选择工作流，勾选“生成时发送当前建模视口截图”并保存。各流程独立设置，默认关闭。调用时截取当前 3D 画布或当前建筑图片，缩为最长边不超过 1280 像素的 JPEG，通过 image_url 发送；不会截取整个窗口、配置页或日志，也不会把图片数据写入任务日志。

模型必须支持图像输入。启用截图但没有已打开的模型画面时会提示；不支持图像的服务可关闭该开关继续文字模式。当前视图只作为视觉参考，精确坐标仍以局部上下文与本地引擎为准。发送截图不表示精修已获批准，也不能替代真实看图确认。

内部规则框默认至少300px，工作流补充要求至少180px，可继续拖动增高。模型编辑的任务要求和候选文本也加高。

## AI 任务记录

AI 构建和提示词方案请求会记录在当前会话的任务列表中，显示工作流、开始/结束时间、阶段、成功/失败/取消、是否附图、候选摘要和步骤数。API 返回候选与本地预览是独立阶段，后续采用或移动也会追加到同一条记录中。候选生成完成不代表建筑已导出。

日志保存在任务目录的 job.json 中，记录本次文字要求、模型 ID/服务类型与结果摘要，不包含 API Key 和截图 base64。列表只显示当前服务会话的任务，重启后不恢复历史列表。失败原因会写入日志；取消任务时，会尝试中止 API 请求。

## 最近一组 AI 构件整体移动

生成并预览构件后，展开“整体移动最近生成的 AI 构件”，填写 XYZ 偏移，点击“移动并预览”。偏移始终相对于这组构件最初生成的位置，不会反复累加；填回 0 可恢复生成位置，只替换本组工具步骤，保留原建筑和其他步骤。

超出模型边界或违反保护/预算时提示失败。切换源模型后旧构件记录清空；若已手动改动该组工具步骤，先重新生成，避免误移其他内容。移动只是候选调整，最终仍需导出下一版。

## 收起行为

Agent 精修审阅区默认收起，正常保存或切换任务页时不会自动打开方案与运行详情。手动打开的状态在页面内保留。发生相关运行错误时才自动展开详情，审阅/应用失败时展开高级审阅区。
