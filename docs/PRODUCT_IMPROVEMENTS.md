# 产品完善工作清单

目标：完善软件，减少建模时的重复输入、操作切换和重复制作，保留应用与外部 Agent 共用工作区的方式。

本清单记录持续工作范围；局部功能通过测试不代表整个目标完成。

## 构件复用与直接编辑

- [x] 将模型选区或候选选区保存为工作区构件，包含名称、标签、尺寸、锚点和预览。
- [x] 搜索、导入、导出和复用构件；库不进入安装包，路径可迁移。
- [x] 放置、复制、移动、旋转、镜像及网格/表面吸附；使用 3D 手柄减少 XYZ 输入。
- [x] UI 与无界面 CLI 共享保存、读取和放置引擎，工具接口同步暴露。
- [x] 实际预览并另存下一版；保留原稿、源绑定、保护区和预算约束。

## 编辑与恢复

- [x] 有名称的操作历史，支持重命名、临时关闭、重排、撤销和重做。
- [x] 版本差异高亮、相同视角对比和变化区域定位。
- [x] 恢复上次建筑、视角、剖切、选区及未导出的操作与评论草稿。
- [x] 命令搜索、常用工具和可配置快捷键。

## 重复工作

- [x] 参数化操作配方、构件批量阵列和材质主题复用。
- [x] 项目多选、批量预览、检查、状态标记、队列进度和失败重试。
- [x] 玩家尺度、净空、通路和碰撞问题可视化（指定脚位和起终点；游戏内验收另行记录）。

## AI 与 Agent 流程

- [x] 工作台提示词自动归档到对应建筑/版本目录；Skill扫描、完整读取、源绑定与历史修订保留。

- [x] 各使用区域独立配置创作自由度、描述详细度、装饰复杂度和方案变化度；应用与外部 Skill 共用偏好文件。
- [x] 选区内自然语言修改，读取真实方块，逐步审阅和撤销；候选与最终写入共同限制选区。
- [x] 评论归类、重复意见合并、冲突提示及任务状态，保留原证据（重叠候选由人核对语义）。
- [x] 检索并适配已有构件，按任务选择已启用资料片段、显示行号／哈希出处，并保存新资产来源配方。
- [x] 将玩家／通路、结构化保护冲突及候选检查结果转为解释与调整建议；有明确位置证据才可定位，不自动修复。
- [x] 制作批次独立过程目录、模型／任务双向关联、图册与实际路径入口、有限期新增提示及旧目录原地登记。
- [x] Agent 任务回传、同一对象新版本发现、同视角对比及逐条人工评论核对；原评论和批准保持独立。

## 验证与运行约定

- 桌面自动测试窗口默认最小化；保持渲染运行用于验证 3D、选点和截图，不进入全屏。
- 所有测试使用隔离的合成工作区；不修改原 SAODG 模型或迁移参考。
- 每项完成后记录实际测试与可交付物；尚未验证的项保持未完成。
