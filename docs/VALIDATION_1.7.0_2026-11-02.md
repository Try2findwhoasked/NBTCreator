# 1.7.0 · 可读知识库、局部坐标与分离发行包

内置内部资料显示摘要、适用场景和接收方；内部/外部资料可查看原文，外部组列出实际文件，可预览生成的Skill入口。预览只读，不因此选中或发送资料。外部列表变长后修正滚动容器，仍可操作下部知识组。

完善5个流程的基础规则；基础规则随每次对应流程发送，自定义Rule保持原值不被升级覆盖。小型结构返回coordinate_space=local的box/beam/frame候选，API只发送局部尺寸与局部边界；单个方块用lo=hi的box表达。脚本校验局部范围后一次性平移到模型坐标，再走既有本地状态/保护/预算检查、合并、预览和NBT导出，不让模型拼装NBT二进制或palette索引。

发行增加application update和runtime分离ZIP，合并目录等于完整版。应用约33.1MB，运行环境约406.9MB，完整包约440.0MB。EXE本身约238MiB属于Electron引擎，移到运行环境包复用，并非将Electron改成小型原生程序。runtime_id绑定实际依赖版本，应用启动校验环境匹配。旧1.6环境没有该标识，首次升级需配套1.7运行环境。

验证包括API契约14项、内部资料契约1项、压缩包契约3项；界面30项覆盖资料原文预览、流程隔离、外部知识组、真实3D选点、相对坐标构件与立即预览。最终解压检查6项通过，包含分离文件集合/哈希重组、3503文件校验、移除系统Python/Node路径后的CLI、工作区Skill、Chromium和批量PNG渲染。证据：build/portable-1793634009967/results.json；其余回归在build/desktop-*和build/api-desktop-*独立目录。

首次ZIP命令分支测试发现unpack参数数目错误，修正并补CLI测试。一次本地解压发现chrome.dll单比特差异；源文件和ZIP内字节哈希均匹配清单，同一ZIP重新解压后通过全部文件校验和运行检查，原因未确定，未跳过或放宽哈希校验。
