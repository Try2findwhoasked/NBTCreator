# 整栋建筑规划设计

## 使用目标

在 Minecraft Java 1.20.1 的单栋建筑初稿和重设计中，用同一份量化任务书表达体量、分层空间、必要连接和候选偏好。手写与自动生成的布局适用同一规则。规划结果接入现有建筑方案、SNBT 回读、真实图像审阅和手动定稿。默认工作区仍是创作项目。

## 实现路径

- 独立的规划输入和布局结果接到现有建筑方案。布局可以快速检查和比较，建筑方案保存两者的绑定，编译及成品回读复验。采用此路径。
- 直接向建筑方案增加更多单项规则可以保留少量接口，但无法独立搜索或比较通路和功能分区。
- 用完整体素模型直接做每轮搜索能表达任意形状，但每次候选都要重复构造和碰撞处理。实际方块用于选中候选的最终复验。

## 规划数据

采用版本为 1 的 JSON。平面矩形使用含端点的世界 XZ 整数坐标，房间或楼层可由多个矩形组成。空间是可用地面范围，构造层由工作模型表示。楼层使用脚位标高和净空，允许上下层的覆盖范围不同。挑空是本层的保留区，下层可以有连续地面。固定入口、楼梯预留和锁定空间保持稳定 ID。空间 ID、楼层 ID、连接 ID 的引用在求解前检查，空间的来源区分用户、项目和设计推导。

任务书表达建筑画布、逐层可用轮廓、用途、面积范围、目标面积、必须的邻接与通行和入口。布局用房间 ID 关联分配区域及脚位，记录门洞或跨层停靠点。空间标记可以包含交通区，不要求填满闲置占地。设计方案保留原有构件和风格规则，柱网、构件比例、适用的实际承托及图像对照通过既有机制与空间 ID 配合。尺寸字段以格表示，净面积以格²表示。

## 检查与证据

- 布局检查在编译前运行，给出边界、保留区、重叠、面积和所需连接的证据。几何邻接可为开放毗邻或预留一格隔墙。需要直接通行的连接必须有指定开口与两侧在同一水平上的可穿越证据。跨层连接需要有上下停靠点和通过实际楼梯的路线证据。
- 编译和回读用同一份计划。对有规划绑定的制作源，从实际方块重算空间的有地面区域、净空及通路。净地面面积以确切支撑的 XZ 格为基准，扣除墙和登记的结构障碍。可达范围依据站立、净空和玩家碰撞另算。未知碰撞、超过检查预算或证据缺失按待测报告，必做项待测时不得认证。
- 逐项报告目标、实测值、空间或连接、世界坐标以及通过、失败或待测状态。面积偏差和适用的路线偏好供比较。布置无解与搜索预算耗尽分别报告，在项目规范或用户硬条件互相冲突时保留原条件。
- 布局候选、制作版和审批证据使用既有哈希及版本流程。调整后的方案能保留固定空间与上下文，也能按旧条件重新测量。旧方案省略规划字段时沿用原流程。

## 自动布局

首先支持固定的正交楼层占地、指定入口及楼梯预留。为可动空间枚举整数矩形，用有限回溯和面积、邻接过滤得到若干候选，手工输入可由矩形并集表达异形。先定位固定区域，再求解可动区。相同约束、起点及预算给出可重复的候选及排序。对可行候选提供可转入普通建筑方案的定义，后续仍由真实碰撞检查。把搜索结果和报告与候选绑定，保留未受影响的区域及其 ID。

## 桌面与 Skill

建筑工具提供整栋规划入口，支持填写或导入任务书、检查手工布局、生成和比较候选、查看逐层平面及剖面。点选问题显示相应的楼层或范围，打开当前绑定的 SNBT 时可读取成品回执。桌面和公共 CLI 调用同一个 Python 实现。工作区 Skill 的核心入口补充复杂整栋规划路线，专题解释规则来源、如何比较布局、怎样处理硬条件冲突和怎样复验。工具字段从工具目录查询；简单建筑使用已有短路线。生成的创作入口和冻结引擎按现有同步方式发布。

## 与建筑方案的接口

- 候选转接从选定区域导出空间包围盒、位于区域内的站位和楼层标高。保留模板里的构件、开洞与活动，把精确区域附在规划绑定里供成品复验。已选门位和跨层停靠点供后续写入实际构件。使用旧制作源续版时继续采用原上下文和保护规则。
- 自动候选的直通门预留一格墙内的指定开口。跨层搜索使用基线中给定的上下端脚位，必要时绑定已有梯段。成品按该门位逐段核对碰撞，具名梯段由真实踏步脚位逐段证明。已有空间的位置锁定是布局约束，真实方块保护使用原模型机制。
- 净面积归属以声明的空间区域为准，使用实际支撑并排除墙格。楼层挑空按所选脚位检查地面支撑，明示的梯段预留可承接梯段。编译前不合格的布局可返回只读回执。附带规划绑定的建筑在建模与保存前执行硬检查，人工审阅和显式定稿仍走原流程。
- Agent 将适用于当前建筑的用户要求、项目规范及设计推导写入数值字段，保留来源。走廊通过声明为交通空间参与搜索与面积比较。布局有多个候选时，按面积偏差、已布置空间改动和搜索稳定次序返回。

## 验收

用归卷阁说明手工分区和方块回读。覆盖面积不足、房间相撞、挑空误填、开门缺失、楼梯被挡、未知碰撞、过期源和通过情形。验证自动候选在相同输入下可重现，重排保留锁定区域，不可行输入与计算预算耗尽能区分。桌面在默认布局和较窄窗口能操作同一份约束、切换楼层或剖面并定位问题。实际看图确认与显式导出继续由原流程验收。验证建筑流程、冻结 Skill、目录一致性和桌面入口。
