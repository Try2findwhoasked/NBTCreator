# 构件放置、列表与批量整理

## 决定与依据

用户选择在建筑编辑中放置构件（方案 B）。素材库侧栏放置方案要在素材详情与建筑画面之间来回切换。建筑编辑可以复用现有 3D 视口、贴面选点和移动、旋转手柄，适合缩短放置路径。

用户选择建筑版本和创作方案使用可恢复的回收站（方案 A）。只隐藏会把恢复入口留在筛选里。物理删除涉及模型、归档、定稿和交接记录，回收站可以让列表腾出空间，同时保留这些资料。

已选定的界面规则包括点击表面生成暂存候选，由用户确认加入修改（1A），使用建筑编辑左侧放置面板（2A），画布栏并排显示两个独立的取材和标注按钮（3A），素材类别切换和行内多选框靠右（4A），宽屏默认显示可收起的分组侧栏（6A），列表上方显示多选操作（7A），移入回收站前进行一次批量确认（8A）。创作方案的第五项聚焦命令入口集中，具体排法见下文。

代码里，未走受管模型清单的建筑会在效果预览前检查 `interior_probes` 等坐标资料。缺项会使预览失败，界面回滚这次候选，并通过 `showModal()` 重开原详情。素材详情同时叠加了大详情窗的布局和窄检查区的布局。取材移入构件菜单后，原图标的尺寸规则仍限定在画布栏。建筑库已有供批量预览和创作阶段使用的多选，创作方案的单项删除已有保留原文件的索引标记。这些路径分别处理，避免通过放宽整栋检查来解决界面问题。

## 构件放置

```text
素材库    [文件夹] [类别] [搜索]             [整理] [素材库工具]
┌──────────┬────────────────────┬────────────────────────────┐
│ 分类     │ 构件列表           │ 花槽与双座长椅             │
│          │ 花槽与双座长椅     │ 缩略图 / 9 × 5 × 5         │
│          │                    │ [放到当前建筑]  [更多]     │
└──────────┴────────────────────┴────────────────────────────┘

建筑编辑   [残封税仓] [当前版本]             [退出放置 Esc]
┌ 放置构件 ────────────────┬──────────────────────────────────┐
│ 花槽与双座长椅           │ 3D 建筑                          │
│ 点击建筑表面确定位置     │                                  │
│ [重新选点] [旋转 90°]     │ 点击处贴面放置，显示候选         │
│ [高级设置]               │                                  │
│ [加入本次修改]           │                                  │
└──────────────────────────┴──────────────────────────────────┘
```

- 素材库详情展示构件名称、尺寸和缩略图。单击“放到当前建筑”进入建筑编辑并启用表面选点，随后一次画布点击生成候选。没有打开建筑时，该按钮显示“选择目标建筑”，选定目标后直接进入放置模式。打开详情、滚动和勾选素材均不会启动放置。
- 选点按命中表面的格边界对齐，计算和提示都留在建筑编辑。候选可重新选点，也可旋转或使用现有手柄微调。坐标、镜像、阵列、材质主题与允许覆盖收进“高级设置”。已有配方参数从素材详情的高级入口调整，修改后按实际放置的内容重新绑定。选点、撤销与确认都绑定明确的建筑和构件版本。
- 进入放置前，基于当前草稿的有效候选选点并保留已有操作顺序。候选过期时先尝试更新，已有操作缺少必要资料时提示处理该操作，保留现有草稿。“加入本次修改”将这次放置追加到草稿并退出放置模式。连续调位置只更新同一件候选。结果计算中显示“正在预览”，确认时以最后一次选点和参数的结果为准。Esc 或“退出放置”恢复进入放置前的画面和草稿，迟到的计算结果随本次放置取消。
- 缺少 `interior_probes` 等仅供整栋检查的坐标时，允许显示几何候选，标明“缺少室内检查点，已预览位置。保存前请补齐检查资料”。继续使用配置声明的保护范围和墙层、源与素材校验、边界、覆盖规则及改动预算。已关联或按模型规则必需的保护资料若缺失、不可读或不一致，显示具体错误并保留选点。合法的空保护范围按引擎现有规则处理。超界、保护冲突或覆盖失败时就地说明下一步并保留上下文。
- 缺检查坐标的候选在检查与交付区显示缺项和配置入口。补齐并重新检查后，进入现有保存流程。具备检查资料的候选沿用现有 SNBT 制作版保存规则。定稿 NBT 使用单独的显式导出流程，检查状态按实际报告显示。

## 编辑栏与素材库

```text
画布栏  [图片 / 3D] [取材] [标注] [视角]    [原稿 / 候选] [构件] [显示]

素材行  [缩略图]  花槽与双座长椅   9 × 5 × 5                    [□]
素材栏  [文件夹] [搜索素材]     [构件 / 效果 / 纹样] [整理] [工具]
```

- 将“取材”和“标注”还原到画布栏同组，使用相同的按钮与图标尺寸规则。取材保留 3D 前提。构件菜单使用与其他菜单一致的普通左对齐选项行。
- 列表统一缩略图、标题、状态和操作列的对齐方式。素材行的选择框放到右边，仅在整理时出现，点击不会打开详情。长行截断显示，窄窗优先保留条目名称和选择框。
- 素材类别切换放在搜索框右侧，与整理和工具相邻。分类侧栏和搜索仍以当前类别为准。
- “保存当前选区”统一从建筑编辑的“构件”菜单进入。素材库的“素材库工具”保留导入、来源、生成资产、清单和刷新；“整理”处理选中素材与文件夹。已经出现在顶栏的同一动作不再同时出现在其菜单中。

## 建筑库与创作方案

```text
建筑库    [项目与分组] [搜索建筑] [版本：最新] [筛选]            [多选]
多选时    已选 3 个版本  [移到分组] [移入回收站] [完成]
```

- 宽屏默认展开侧栏，点击“项目与分组”可收起或重新展开。窄窗打开可关闭的侧栏，选中分组后回到列表。分组整行支持点击和键盘操作，筛选后有选中状态。文件夹名称长时只截断文字，保留行与管理按钮的点击区域。
- 建筑库继续复用已有版本多选。普通视图仅露出一个“多选”，勾选后才显示整理动作。批量预览和阶段标记从同一个多选上下文进入。归组沿用现有按建筑归组的规则，操作前显示建筑数。以勾选的版本为单位移入回收站，正常列表据可见版本重新计算“最新”。当前筛选范围内没有可见版本时，显示空列表和回收站入口。恢复后沿用现有的创作阶段及分组，原分组已移除时按未归组显示。
- 创作方案侧栏增加同样的多选和回收站入口。归组只修改工作区里的目录记录。回收动作保留现有方案编号、修订、归档文件及已交接任务。恢复后回到原来的待处理或已交接列表。旧版已移除的方案按现有索引归入回收站，每个方案只展示一条当前记录。恢复时核对索引、方案编号和修订，排除改名或迁移留下的旧记录。移入回收站前展示所选数量及条目，遇到版本变化时保留失败项并逐条说明结果。回收站浏览与恢复在同一个列表里完成。
- “版本：最新”、搜索框、“筛选”和视图切换的外框都用 34 个 CSS 像素高，去掉额外的外边距和偏移。在 100%、125%、150% 缩放验收外框高度和顶边对齐，并验证窄窗换行后可用。

## 创作方案的命令入口

用户点出命令分散在五处。设计建议将页面命令收进顶部一个工具栏。左侧负责查找和选择方案，右侧负责读写方案。仅在进入多选后，所选列表上方显示批量操作栏。

```text
[返回]  [起草要求 | 编辑与审查 | 交接结果]          [当前主操作] [更多]
┌──────────────────────────────┬────────────────────────────────────┐
│ [待处理 | 已交接 | 回收站]     │ 方案名称                            │
│ [多选]                       │ 当前步骤内容                        │
│ 方案列表                     │                                    │
│                              │                             已保存 │
└──────────────────────────────┴────────────────────────────────────┘
```

| 现在的控件位置 | 调整后 |
| --- | --- |
| 窗口上方的“方案文件”、载入当前建筑、返回 | 返回与阶段导航进入同一条顶栏。导入、下载、从当前建筑起草要求归到顶栏“更多”。 |
| 步骤栏的批量编写、单条和“更多” | 顶栏只有一个当前主操作和一个“更多”。生成过程中，主操作原位切为“停止生成”。 |
| 左侧列表的生成、交接命令和底部说明 | 左侧只保留列表、待处理／已交接／回收站切换和多选。批量交接从顶栏“更多”或当前多选工具栏进入，两种状态只提供一个入口。 |
| 方案标题旁的“方案操作”“建造与约束”和附加页签 | 单条移入回收站、审查标记等归到顶栏“更多”。建造步骤、保护与通行成为审查内容里的折叠段，添加步骤等表单操作随对应字段出现。 |
| 正文底部的“下一条”“确认并交接”及交接结果旁的复制入口 | 底部只显示保存状态。“下一条”进顶栏“更多”。确认交接和复制读取命令按阶段出现在顶栏同一位置。 |

主操作根据当前状态切换。未选方案时优先显示“批量编写”，单条新建可从“更多”进入。所选草稿待生成时显示“生成提示词”，有待采用的生成结果时显示“采用并审查”。审查阶段使用“确认并交接”，交接成功后显示“复制读取命令”。已经采用手工内容的方案可以直接进入审查。顶栏“更多”按当前阶段提供项目规范、重试、完整提示词预览或下载，以及当前方案操作。

多选时在列表上方显示“已选 N 项”“移到分组”“移入回收站”“完成”，在回收站里将前两项整理动作换成“恢复”。移入前展示名称和数量，一次确认执行所选批次。普通浏览时该操作栏收起。窄窗可压缩间距、换行或使用“方案列表”打开左栏，仍使用同一套命令入口。

## 视觉规则

沿用 NBTCreator 的浅色主题和工作区主题设置。默认配色使用画布周围底色 `#F3F6F8`、面板 `#FFFFFF`、边线 `#D5DFE6`、主文字 `#243746`、主操作 `#326B91` 和警示 `#AB342C`。文字沿用 Microsoft YaHei UI 与现有系统字体回退。标题和说明左对齐，选择框与批量操作形成固定尾列。“放置构件”的画布模式提示是放置流程中最醒目的变化，其余信息以短状态文字呈现。

## 验收范围

- 复现缺少室内检查点的旧建筑放置场景。验证能在同屏得到候选，错误仍在当前界面可纠正。使用合成测试建筑同时验证完整检查、已有保护冲突、重选和取消。
- 验证多选不打开详情，批量归组、移入回收站、重启后查看及恢复。检查模型、方案修订、已交接任务和定稿文件保持可读。旧版已有删除记录仍可识别，恢复操作须核对当前归档修订。
- 在普通窗口、窄窗口和高缩放下检查面板无重叠、菜单图标正常、分组可点击、列表与顶栏对齐，保留键盘焦点和关闭方式。
- 从创作方案的空列表、生成、审查、交接和多选状态分别验收。正常编辑仅有一个页面工具栏，检查常用命令有没有重复出现，批量生成期间的停止操作是否仍在同一位置。
