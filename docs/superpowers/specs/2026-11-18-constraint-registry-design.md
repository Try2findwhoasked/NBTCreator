# 约束注册器

创作方案的「我的项目」用同一组勾选项展示内置和当前项目的约束。1×1、2×2、L 形等旧模板的规则数据迁入内置注册文件。自定义约束沿用现行项目目录及旧资料读取。归档形状目录继续提供建筑分类。应用只在用户勾选后将内置约束写入方案，已保存方案仍以原快照为准。

可以把内置定义复制到各工作区，或由注册器在查询时合并来源。采用查询时合并，使已有项目直接可用，内置更新只维护一份数据。界面提供同一套查看、勾选和约束校验，内置规则通过「从模板起步」可另存成可编辑条目。

内置约束 ID 和版本固定写在注册文件中。独立建筑模板采用参考尺寸。内置约束可被项目房间引用，实体房间的归属目录沿用项目约束。建筑库按已经登记的引用和旧交接记录计算房间关联。建筑库的筛选栏提供同一套已登记约束，支持形状和实际约束引用组合筛选。筛选控件采用一致高度和单个展开箭头。
