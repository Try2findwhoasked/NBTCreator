# 显示设置分组设计

## 目标

让建筑编辑的“显示”菜单在约 300 像素宽的贴边浮层内清楚呈现画质、图层、剖切和辅助显示，保留用户已选定的标注优先工作流。保护区默认不显示；玩家路径作为直接显示开关，不能触发或暗示检查已完成。

## 方案

用户选择一屏分组。画面区依次放画质、图层和剖切；辅助显示区放选区框、保护区和玩家路径开关；底部保留“检查路径”和“保护区详情”。图片模式只显示图片缩略图入口及提示，画布栏的视角位置继续选择图片。

折叠分区需要额外点击，两页签布局会让剖切与保护区切换变慢，因此不采用。检查面板原有的范围、冲突和路径数据仍由各自模块管理；菜单中的开关只同步显示状态。无路径结果时，玩家路径开关不可用，并明确给出检查入口。保护冲突和显式定位仍可主动打开保护高亮。

## 约束与验收

- 保留已连接的控件节点及事件处理，不更改保护规则、路径算法、源哈希或导出。
- 浮层宽度不超过可用视口，内容最高不超过视口高度的 70%，窄窗口可滚动。
- 3D 与图片模式切换后，菜单只显示适用的项目；切换建筑或结果失效后，路径开关状态同步。
- 验证直接开关、详细面板、保护冲突、视口布局和桌面冒烟测试。
