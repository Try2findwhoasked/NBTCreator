# GDMC 镇政厅频谱素材实施计划

目标是从同一固定版本的镇政厅蓝图提取可装配构件和重复纹样，在素材预览里调节周期与相位后再复制或放置。范围为 Minecraft Java 1.20.1，沿局部 X 轴的一维周期，保留有厚度的 YZ 截面。

- 在独立素材库登记来源、许可、原始方块坐标和分类信号的实数 FFT 系数。选段要含多个完全一致的周期，默认参数逆变换后与源区逐格比对。
- 在共享引擎增加 `spectral_repeat` 配方，限制尺寸和方块预算。周期和正向相位偏移的单位均为格，空截面保留为空气。检查奇偶周期、负偏移、非整周期裁切和非法频谱。
- 在素材库和参数化构件面板接入周期、相位字段。修改后重新预览，复制和放置绑定本次预览的内容哈希。
- 同步拓展库和工具目录，检查真实几何缩略图、改参前后候选、桌面控件与离线加载。
