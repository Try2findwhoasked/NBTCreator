# 大型组装主稿实施计划

**目标：** 按[大型建筑复盘](../../development/LARGE_MODEL_ROADMAP.md)交付可登记、编辑、渲染、校验和协作回装的大型制作源，再接入参考图与审阅工具。

**约束：** 保留单份 SNBT 每轴 294 格的约束和独立导出流程；旧制作源、历史、保护、用户确认与 CLI/UI 共用引擎契约继续有效。制作分区与协作切片分开。所有失败不得覆盖主稿或静默丢失墙层。

**现状与选择：** 现有 `Volume` 用稀疏方块字典，`WorkingModel` 的多个候选仍复制整份字典；碰撞空间使用按 Y/Z 分配的行；渲染会展开完整快照。34.56 万块合成场景的批量渲染进程树采样约 2.47 GiB。直接放宽 `Volume` 和 SNBT 的全局限制会同时改变旧入口的内存与导出语义，因此使用明确标识的组装清单、独立的大尺寸模型与按需分区，并逐个接入既有工作流；资源使用须明确设限与报告。

## 第一阶段：组装源

- [x] 定义版本化组装清单和有界读取器：记录画布大小、分区相对路径、整数偏移、尺寸、源哈希及显式墙层；拒绝路径逃逸、符号链接、重复占用、越界、无效状态和变更中的分区。清单及全部分区共同构成源绑定。
- [x] 用独立的稀疏模型读取和查询全局坐标，按合法分区写入新版本并逐份回读；保留源文件、方块状态和墙层，不将制作分区当作运行时结构导出。
- [x] 接入登记、历史归档与恢复；验证任一分区被替换、移动、删除或写入中改变时，旧绑定会失效，恢复后清单及分区哈希仍一致。
- [x] 在 `model`、`patch` 和 `render` 中接入同一组装源。候选写入与渲染结束前重新核对清单及每一分区；大画布的碰撞查询避免按整个空画布分配密集栅格。测量并报告操作耗时及内存。
- [x] 合成 300 × 384 × 300 夹具跨多个 Y 分区，核对全部方块状态、墙层、画布和全局偏移；验证跨分区路径以及保存、回读和匹配机位渲染。

## 第二阶段：协作切片

- 输入采用受信任的交接请求：组装源路径与 SHA256、上下文、全局切片范围、其中的可写范围和新输出目录。切片可包含画布外的只读邻区，但可写坐标必须在宿主内；单片尺寸仍受 SNBT 294 格上限约束。
- 签发时保存真实方块和墙层的局部 SNBT、局部到全局偏移、可写域、宿主清单及分区哈希、上下文哈希和局部保护。全局路线由现有静态走测求出，将玩家扫掠净空及支撑格映射到切片；不能只保护落脚点。
- 回装请求必须由协调方提供签发时的切片清单哈希、候选 SNBT 哈希和原组装源哈希；不能信任片作者重新提供的范围。全体片先在内存候选中按方块状态与墙层计算差异，拒绝未授权坐标、重复写入和不匹配的基线，再执行整塔保护和路线检查。
- 成功后复用 `WorkingModel.patch` 和不可变 `save_draft`，保存来源、切片清单与候选哈希、变更坐标摘要及检查结果；相同请求重试需复用结果，过期或失败保留原主稿和每片，不自动批准或导出。

- [x] 从固定组装版本签发切片，包含局部原点、坐标变换、可写域、只读邻区、基线与全局路线投影的占位和支撑保护。
- [x] 回装前检查每片基线、预期旧值、全局写入域、保护和片间重叠；在临时完整候选中应用全部变更并检查全局路线。任何冲突返回坐标，不改变主稿和切片。
- [x] 发布带源绑定的回装收据；覆盖中断重试、重复回传、负偏移、边界、过期和四片楼梯净空冲突。修正后检查入口到上层及返程。

## 第三阶段：参考与审阅

- 参考登记保存每张图的内容哈希、视向、屏幕轴正负、像素原点、每格尺度和锚点依据；遮挡与推定区域单独记录。导入或重新配准时保留旧记录，不把图像模型的推断当成用户确认。
- 锚点编译将同高度的四条边界分段拟合为受限三次贝塞尔，固定端点并在局部极值处限制手柄；按明确的高度采样生成顶点数及顺序一致的全局 XZ 截面，复用 `geometry.loft`。台阶、缺口和孔洞作为独立边界保留。
- 回投影以实际方块为输入，按登记变换生成正、侧、俯视轮廓；全局和指定局部区域分别输出交并比及双向一格容差覆盖，并保留可检查的叠图。未提供轮廓、遮挡或深度信息时报告未知，不能以分数替代人工看图。
- 正交材质图的投影类型、视体尺度、机位、裁切和光照都写入图像与审阅包的绑定；透视兼容入口保持原样。A/B 包对每个来源、候选、机位配置和图片哈希校验，输入变化即失效，盲评与用户批准分开。
- 曲面纹样应以已登记的偏心、退台截面为参数基准，按 UV 采样后在真实宿主上寻找与连续曲面法向一致的外露方块面；找不到真实表面或法向不明确时报告位置，不把解析曲线当成支承。切槽沿实际外露面的内向逐格检查完整宿主和最小背衬，凸沿、嵌纹和空气切口作为同一候选中的不同材料/写入，经过既有保护、预算和路线策略。
- 环段、暗缝、竖肋、窗列、斜搭带和裙边分片复用同一截面、厚度、搭接与收头基准；不自动镜像用户声明的不对称。纹样掩模作为可重用数据绑定哈希，结果逐项报告切深、背衬、未映射或截断笔画及保护冲突。代表段须同时保留正面、斜面、剖面和远景证据，再由使用者决定是否铺开。

- [x] 登记三视方向、尺度、原点、锚点、依据和不确定性；从同一输入重现截面与回投影，分别报告关键局部误差和双向容差覆盖。
- [x] 扩展偏心曲面构件和带深度的纹样，检查切深、背衬、保护、接触和连续性，生成代表样段及固定机位对照。
- [x] 使用者确认代表样段可作为整栋铺排的基准。
- [x] 扩展现有审阅流程，绑定来源、模型、机位、光线、裁切和图像哈希；提供局部及匿名 A/B 包，输入变化时使旧证据失效。盲评与用户批准独立。

曲面入口目前可从哈希绑定的截面、宿主和可复用掩模生成独立候选，并重算实际侧面、切深、背衬、保护及连续性；支持同符号重复写入合并和有限密采样。它只检查局部外露侧面，尚未证明与室外空气连通。合成偏心退台样段的材质渲染暴露出斜带和纹样断裂，不能视为代表样段通过；仍需解决可复用构件的搭接与收头，制作通过检查且可读的斜带、暗窗、切槽、实体卷纹组合，并留存匹配机位的人工审阅证据。审阅包的来源、机位和图像绑定已有自动验证；意见可记录部位、参考区域、预期和复核条件，并可绑定已登记图源的像素区域。曲面候选可绑定针对同一宿主的具体意见，原证据变化时失效；后续复核记录可关联候选、新观察和未解决项。意见及复核状态不表示问题已解决或得到批准。

后续处理曲面断笔时，可参照 `nbt_cylinder_fit.py` 已有的实际半格拓扑与转角连接，而不是仅增加 UV 采样。连接只允许作用于源掩模中本来连续的笔画，并须保留纹样孔洞、实际支承、材料形状、保护和预算；歧义、背衬冲突或无法证明支承时报告而不猜测。曲面侧面与圆柱规则不同，不能直接套用圆柱柱芯或隐含对称假设。分别验证实体凸饰与带背衬的凹槽，再记录不同方向和距离下的真实图片。

本轮先实现显式选择的单格曲面连接：仅在同一掩模笔画的相邻 UV 采样或同一格内采样之间，针对相差两个轴向步长的单层凸饰检查中间格；连接格必须使用原材料形状，在半格层面同时接触两端，并经两端实际宿主面支承。转角中间格允许通过已支承的凸饰连接宿主，不虚报其直接贴面。候选位置不唯一、受保护、与其他写入冲突或会破坏来源笔画的孔洞时拒绝；不为缺失路径寻找远程替代，不改变宿主、不镜像，且把连接及支承逐项写入可重算回执。切槽和嵌纹不套用凸饰规则；它们需要独立的深度和背衬连接检查。

目前单格凸饰连接已实现并验证：带孔洞的断笔暂时拒绝自动连接，因为仅比较孔洞数量不能证明位置保持；多层凸饰和周期接缝也未支持。更新后的无孔合成纹样在偏心宿主上增加 5 个连接后，剩余 2 条断笔属于切槽和暗窗，仍未通过样段验收。

凹槽已有独立的显式连接策略：仅在原掩模同笔画邻近采样之间寻找唯一中间宿主；该宿主必须有实际外露面，沿该面的内向逐格验证完整宿主、切深与最小背衬，全部写入须通过保护、原有支承与冲突检查。每个中间宿主的完整切口都计入预算和回执。若多个面或中间宿主同样可行、需要切掉其他构件的背衬、无法保持孔洞或没有可证实的连续路径，拒绝候选并保留原稿。嵌纹内层状态与空气切口分别检查和重放，不能把凹槽连通当成饰面材质连通。

合成探针 `build/curve-representative-nxu9lmg3` 在偏心退台宿主上同时尝试斜带、暗窗、切槽和实体纹样。按实际半格形状核查有 4 条断开笔画、5 个量化合并掩模格；正面图中的实体卷纹也未呈现清晰卷曲。该目录是本机调试输出而非用户批准或交付样件，后续应生成可复现的通过样段并重新出图。

后续连接探针 `build/curve-representative-0e5vwmko` 使用无孔的实体笔画，凸饰连接已修复但切槽和暗窗仍有断笔，另有 7 个量化合并掩模格。合成输入生成已移入 `tests/support/curved_surface_fixture.py`，真实 CLI 和冻结工作区回归检查连接与未解决诊断；图片仅供开发核查，不代表用户批准。

联合探针 `build/curve-representative-e6fvrh4o` 在同一偏心宿主对凸饰和短凹槽分别连接，半格连通性通过，仍有 7 个量化合并格；当前暗窗和切槽过短，不能以此冒充满足文档的可读代表样段。它只证明混合连接、背衬回放和拒绝越界的实现路径，仍需制作尺寸相称、具有清晰斜搭板、暗窗、切槽和实体卷纹的样段及多机位证据。

构件复用仍需设计数据契约：当前掩模一格只有一个动作，无法直接表达同一 UV 上有暗窗、背板和外凸斜搭带的多层关系；现有支承检查也会保守拒绝对支承格换材。不能只把现有掩模按名称包装成环段或窗列并宣称支持搭接。应先定义显式层次、厚度、端部及允许接触／覆写的规则，让实际候选逐层核对宿主、保留背衬、保护与墙层，再将数据配方放入独立资产库；外部库目前仅支持 `parametric_recipe` 和 `component`，新增类型须同步离线读取、内容哈希、统一浏览及放置契约。

曲面入口现已支持向后兼容的版本 2 分层掩模：每层各自声明相同尺寸的符号网格及材料／切深，跨层 UV 重叠须由层编号对显式许可；所有层从同一宿主和截面取样，最终同时计算实际写入，互相冲突则拒绝。外凸层可按符号显式声明允许的完整支承状态与墙层：宿主不变或最终恰好成为该状态才可接受；空气、半块、未声明材料或被破坏的凹槽背衬均拒绝。默认保留原宿主，版本 1 语义和回执保持不变。所有层合并前检查共享预算、保护和实际支承，合并候选复用工作模型的路线校验；回执记录映射、换材和重叠并可重算。真实合成宿主的斜带／暗窗跨层及共享 CLI、冻结入口已覆盖，`build/curve-layered-glox41as` 留有多机位调试图，但暗窗仍短且存在断笔和量化合并，尚不满足代表样段验收。可复用配方和独立资产库协议仍待实现，不把项目数据塞进应用快照。

现有外部资产可以通过 `asset-libraries resolve` 按来源、库版本、清单、资产和编译内容哈希离线取得合法构件；后续可评估把用户明确选择的构件切片和材质映射编译为分层掩模，保留这些绑定并在候选验证时重查。不得从方块颜色猜测挖空、背衬或墙层含义，也不得把固定体素切片称为已经支持参数化环段。若现有构件格式不足以表达搭接与收头，仍需扩展独立库协议及统一浏览入口。

已实现不改变资产协议的复用入口：调用者为每层显式选择本地构件或完整来源绑定的已连接构件／参数化配方，指定 XY 切片、画布偏移、重复数量与间距，并逐一将切片中实际出现的材质编号及墙层映射到掩模动作或明确忽略。生成可供曲面工具使用的分层掩模与组合回执；回执绑定来源、参数和编译内容，验证时离线重新解析所有来源并重算掩模。自动镜像、隐式裁切及从颜色推断动作均禁止。此入口复用既有素材和尺寸参数，但不声称已经实现专用环段、收头或曲面素材浏览器。

复用既有 `parametric_recipe` 协议新增平面 UV 模板生成器，而不是把特定建筑数据硬编码到应用：按明确尺寸生成环段、暗缝、竖肋、窗列、斜带和裙边轮廓，分别约束宽度、起终位置、节奏及两端收头；斜率和左右收分均显式，不自动镜像。模板只是可预览的平面构件，切口、材料、墙层和曲面宿主仍须通过 `curve compose`／`curve plan` 指定并验证。六项数据配方写入独立资产库，在素材浏览器中沿用原有来源、版本、编译内容和真实预览绑定；不能把平面模板预览称为曲面或游戏验收。

六项模板已进入独立资产库 1.1.0 和本地发行快照；素材界面可真实预览并复制来源引用，平面模板不能直接冒充曲面成品放置。为使不支持新配方的旧引擎明确拒绝，应用版本与资产兼容检查同步到 4.3.1；此前固定的 3.1.0 检查已修正，旧版 `app_max` 限制可能需要库维护者更新。共享 CLI、冻结入口、素材界面和原有资产库回退／隔离回归均已覆盖。

凸饰连接已扩展为显式限制的最多三个中间格；存在多个同等路径时返回端点和候选，允许调用方明确选择，并在重算时重新检查保护、接触、预算及孔洞。允许按层关闭连接，跳过的断笔仍保留诊断。大型样段的两条试验路径均被孔洞拓扑检查拒绝，不能据此选择任一路径或认定样段通过；下一步需调整模板与采样并重新检查完整的四层结果。

对该样段做了 12 组曲面跨度和采样密度探针，均仍有断笔和量化截断；加密采样可减少部分断笔，但不足以通过。探针位于 `build/curve-sampling-probe.log`，不生成候选、不构成人工审阅。

进一步检查发现，原斜带采样结果已经包含一个额外环孔，连接后变为两个；有一个环孔可在真实宿主旁用单格补上，另一个没有发现安全的单格补点。将样段移到 `u_start=0.25` 后，斜带通过连接和拓扑检查，但暗窗仍无法连接：部分断点的两个中间格分别为空气和被宿主遮挡的实体，均不满足原始外露面规则。扫描其他方向、高度和采样密度也未得到通过的暗窗／切槽组合，不应简单增加密度或放松支承约束。

为继续定位此类问题，凹槽连接失败现在返回 `CURVE_RECESS_DISCONNECTED`：分层请求包含出错层，错误列出有界的源采样对、实际宿主和法向，并分别报告切口与材料分量。真实共享 CLI 在上述暗窗上返回了 `windows` 层和 16 对断点，未生成候选；这些诊断不表示建议路径已经可行。

使用同一偏心退台轮廓内的稳定墙段，重新选择窗格、切槽和卷纹的位置。复跑命令为 `mise exec -- python -B tests/engine/curved-surface-review.py`。输出 `build/curve-review-vlgx5caz/acceptance.json` 记录 246,591 块宿主、688 处改动、9 格凸饰连接、2 格完整空气退深、288 个检查背衬的实际面，以及保护格冲突和原稿哈希复核。四层都没有断开的笔画，斜带仍有 3 个量化合并格。正面可辨斜带、双暗窗和开口卷纹，槽口的进深在斜面及剖面更清楚，远景能定位整个样段。两次生成的前后四视图像素哈希一致。审阅包分别绑定原稿和候选的约 12 MiB 体素快照。

使用者回复“可以，尽快完成”，确认上述样段可以作为铺排基准。此次确认对应候选的四视图清单 SHA256 `26db9c1d7515ab7984d3ea937444f48a11b798f45a470ee2e62a0ef7db221e8c`，范围为可复用样段验收。

四种来源绑定模板的合成探针 `build/curve-representative-stencils-77dc7g_r` 已生成正面、斜面、剖面和远景：包含斜带、三段暗窗、切槽及回环纹样，并记录 12 个 UV 搭接与 14 个支承换材。但 410 个掩模格中 62 个量化合并，四层各有断笔；最大连续修改范围和完整空气深度均为 3 格。图中回环纹样和切槽仍不够清晰，尚不能作为通过的代表样段或用户批准。

分层候选需允许用户显式关闭某一层的凸饰或凹槽自动连接，避免带孔纹样阻止其他可安全连接的层；未连接层仍须保留失败诊断，不得据此声称整段通过。连接总预算仍按实际启用的所有层累计，配置和跳过项目写入可重算回执。

工作区知识选择器的建模资料组现在包含大型组装、三视参考和曲面路线；未启用该组时不自动列出这些专题。现有创作项目及其已生成的 facade 未被改写，后续仅通过正常的显式同步更新。

实际内置素材探针 `build/curve-bundled-5pfvyu2p` 将现有回环折线边带的明确切片映射到偏心宿主；271 个掩模格中 95 个量化合并，笔画未连通，真实图中也难以辨认。自动回归保留这一失败诊断，不能把资产来源哈希正确当成视觉质量通过；应调整样段尺度、图案与可辨性，再检查搭接、端部和人工审阅。

更大尺度的合成探针 `build/curve-large-pattern-at_rjdud` 使用约 21 万方块的加厚偏心外壳和来源绑定的双色素材。显式允许更深连续修改后，逐面检查得到最大修改范围 5 格；其中包含填入的实体材料，并非 5 格空气深槽。两层仍各有断笔，612 个掩模格中 167 个量化合并。图案比小尺度可辨，但深度和断笔尚未满足设计验收，不能作为用户确认或整塔铺排依据。`max_effective_depth` 只接受同符号已规划的连续改动，不新增切块，仍须在修改范围后保留原始完整背衬。

四倍采样的后续探针 `build/curve-large-sub4-7ean9_cd` 将量化合并降到 156 格，但两层仍未连通；1,364 个采样面中有 143 个连续修改范围超过声明深度，最大范围为 5 格，最大完整空气深度为 0 格。说明增密没有解决根本的曲面断笔，也不能把实体换材解释为凹槽；该图仍不是代表段验收。

上述内置素材探针绑定的是资产库 1.0.0；将本地发行快照更新到 1.1.0 后，它们只能作为历史图像观察，当前来源核验应视为过期。后续必须以新快照重新生成并重新看图，不能沿用旧回执充当当前证据。

## 验证

装配尺寸选择沿用受管实例的 `model update`。只读 `preflight_update` 用同一编译、占用、保护和预算逻辑生成内存候选，对比实例与整栋实际包围盒、已声明的接口、主路线及往返分段。越界时报告拟放置包围盒。几何或声明缺失时会报告检查范围。用户选定后，`update` 可传入预检哈希，重新计算相同候选，并把选择绑定保存在实例和预览回执。旧的直接更新入口继续按原有规则处理。

回归验证了具名接口随构件抬高、越界位置诊断、主路线和返程阻断、宿主与方案变化后拒绝旧哈希。共享 CLI 的预检结果可由冻结工作区入口复算，选定方案随制作版回读，并绑定预览源和快照。用法见[工作模型](../../../.agents/skills/minecraft-nbt-modeler/references/working-model.md#预检构件尺寸与安装位置)。

每个阶段先增加能复现失败的回归，再运行对应引擎和真实 CLI 检查；前端或渲染变更先构建前端，运行实际图片和桌面检查。阶段交付前执行 `mise run doctor`、`mise run check` 和适用测试，保持未完成项未勾选。所有图片证据只说明其覆盖范围，游戏内放置、光传播和人工确认另行记录。

交付复核通过了环境、工具目录、素材快照和迁移归档校验。真实渲染检查覆盖天空的两种画幅、两档质量、空景及实体遮挡。历史回归覆盖超过 64 MiB 的旧索引、并发发布和失败重试。规模夹具在 300 × 384 × 300 画布上回读了 382,201 个方块，回装四片并通过返程检查和材质渲染。最终模型套件通过 122 项，Windows 权限不足时跳过了真实符号链接创建用例，分区路径的符号链接检测仍有自动回归。已确认的曲面候选和四个机位的审阅绑定也通过了最终重算。
