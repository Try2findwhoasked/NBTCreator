# 创作方案「我的项目」实施方案

**目标**　让用户直接勾选约束。面板固定叫「我的项目」，约束范围随建筑库的项目或当前建筑变化。

## 界面

- [x] 在「编辑与审查」顶部显示「我的项目」和可勾选的约束。每行显示名称、适用范围和修订号。展开一行可看规则和来源目录。
- [x] 约束列表下保留管理、Agent 创建和刷新入口。管理时直接打开当前范围。工作区没有可用约束时显示简短空状态。

## 来源和引用

- [x] 建筑库用已编目的建筑文件和目录确定约束范围。新方案显示当前项目的共用约束。库内只有一个项目时可直接使用该项目。没有明确项目时显示工作区共用约束。
- [x] 从建筑库打开建筑后，通过「为当前建筑写修改要求」创建或载入修改方案。新修改方案依次核对建筑专属、形状和项目共用约束。可同时生效的规则自动勾选，最多引用 16 项。冲突项显示原因，可以手动调整。
- [x] 重开已有方案或重新载入同一建筑时，显示原来已引用的版本和勾选状态。手动取消的规则由用户重新勾选。约束更新后通过「改用第 N 版」更新快照。

## 验证

- [x] 用两个合成项目验证切换范围。验证空白方案、确切建筑和另一栋同形状建筑的约束能区分，并测试冲突、旧快照和 900 像素窗口。
- [x] 构建前端，运行引擎约束、提示词契约和桌面回归。
