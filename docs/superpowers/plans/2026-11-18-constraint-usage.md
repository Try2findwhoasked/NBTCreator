# 约束生效摘要与房间关联实施计划

创作方案沿用统一的约束选择区，在起草和审查显示已选数量。展开后从生效方案和已选快照读取形状、尺寸、网格及来源。勾选新约束时按同一校验器识别冲突，确认替换只移除冲突规则。归档形状变化时，提示被移除的目录约束。

建筑详情按规则列出房间登记、交接快照、初稿回传、房间专属规则或手动关联。沿用建筑库多选栏及现有确认对话框，把多个选中版本合并为唯一旧房间，确认后写入工作区关联记录。批量操作对比选中时的文件信息，只处理符合条件的未关联旧房间。新布局按房间自身记录读取。归档数据和原模型保留原样。
