# 约束注册器实施计划

**目标**　让内置及自定义约束在同一入口可见、可勾选并按已有快照协议存档。

**架构**　以 JSON 保存内置规则，由 Python 注册器读取并合并当前范围的约束。Electron 与 CLI 共用该查询。形状分类沿用已有形状键。

**设计**　[约束注册器](../specs/2026-11-18-constraint-registry-design.md)

- [x] 提取内置定义并验证稳定 ID、修订、规则校验和单条查询。
- [x] 让起草、审查、管理入口共享注册器，验证选择、规则冲突和旧快照恢复。
- [x] 将已引用的内置规则接入建筑库及房间引用。验证已有项目读写、实际房间联动和桌面交接。
- [x] 在建筑库增加约束筛选并统一筛选控件尺寸。桌面回归检查高度、展开箭头及实际引用筛选。
