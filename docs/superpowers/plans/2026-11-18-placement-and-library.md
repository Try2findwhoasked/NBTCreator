# 构件放置与列表整理实施计划

**目标**　让构件在建筑画布上先定位预览，再加入草稿。同时统一库列表的多选操作和创作方案的顶栏。

**设计**　[已确认的界面方案](../specs/2026-11-18-placement-and-library-design.md)

- [x] 在 `component-editor.js` 复用手柄会话与候选预览，接入 `asset-workspace.js` 的明确放置入口。将试放与提交分开，取消恢复原候选和编辑状态。
- [x] 在构件预览请求中处理仅缺少整栋检查坐标的旧建筑，保留源绑定、已配置保护、覆盖和预算检查。制作版保存和 NBT 导出继续走现有验证入口。
- [x] 在 `studio-workspace.js`、`library-browser.js`、`library-actions.js` 与库样式中实现并排取材标注、可收起分组侧栏、工具栏对齐及右侧素材多选。
- [x] 在 `project-batch.js` 与工作区索引中加入归组、版本回收和恢复。筛选及“最新”计算使用可见版本。
- [x] 将 `prompt-console` 的页面命令收进一个顶栏。实现方案多选、归组、回收和恢复，保留旧删除标记及已交接任务。
- [x] 用 mise 跑引擎与桌面回归，核对预览撤销、回收恢复、交接、点击和缩放布局。
