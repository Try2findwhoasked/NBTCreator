# Agent Knowledge Contract Implementation Plan

**Goal:** 从工作区入口读任务、找参考并可追溯地保存引用，减少外部 Agent 读取量和手工参数。桌面对外 Skill 设置暂时只读。

**Architecture:** 冻结入口调用共享引擎。检索区分 `external_agent` 与 `internal_ai`，API 只读取内部授权集合。证据按来源回查，短编号不是授权。知识、资产和验收保持独立。

- [x] Python 真实引用输出跨端验证。网页不用伪造行号。桌面隐藏知识组开关和写入口，保留配置及浏览。
- [x] 外部入口检索其启用资料；查询回执提供 `R1/R2`，打包与取证不重跑搜索。默认局部读，全文显式。覆盖跨作用域、撤销、篡改及旧集合。
- [x] 外部入口先读任务。两类任务首读都返回阶段、源状态、下一步；长内容按需展开，不改租约或机器 API。
- [x] 书库基准补无风格提示的设计题和无证据题，记录证据排名、阅读量、调用次数。用主题关联资产搜索，不把历史证据当作可放置资产。
- [x] 用新建工作区盲测公开入口，修复可复现的反馈并复验。运行检索、任务、工作区及桌面回归，保留用户原改动。

## 验证记录

- 首轮只看公开入口的离线盲测发现 `--request` 误传内联、书库筛选依赖手抄编号、回读不回显集合身份。修订文件与 stdin 契约、加入 `source_kind: library`、展示原文行号并回显 `id` 与 `sha256`。
- 第二轮无需预查库编号，4 次调用走通书库的检索、原文、集合与回读；区分项目要求、历史出处和可复用配方。观察到未加查询的目录输出 121 项，约 100 KB；把限量查询示例前移至默认入口。
- 按新入口复测，资产筛选返回 4 项、1,854 UTF-8 字节，原全目录为 100,036 字节。候选可直接回读和预览，三次调用共 4,887 字节，未放置资产；生成的工作区入口约 1,470 字符，改前约 6,420 字符。
- 真实离线书库 15 本、9,108 段：既有 30/30 查询在前五项命中；新增 3 道设计题的充分证据排名 2/1/1 且集合可回查，无关题不返回证据。这是小样本检索回归，不代表图版或无证据领域已覆盖。
- 构建、`mise run check`、引擎/工作区回归、桌面 smoke（32 项）与桌面检索（15 项）通过。额外运行的完整 API 和目录套件分别停在提示词采用断言和隐藏预览控件，不据此声称全量桌面套件通过。
