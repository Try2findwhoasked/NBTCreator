# 整栋建筑质量评分实施计划

**目标**　让同一份 Python 报告支持建筑方案检查、真实审阅和续版复验。

**设计依据**　原工作树中的 `docs/development/BUILDING_QUALITY_FEEDBACK.md`。

1. 扩展建筑方案目录和审阅请求。方案登记阶段、清单版本、需求条件、路线用途、风格部位、代表节点和机位。保留缺项及适用性原因。
2. 在 `nbt_building` 中实现五维聚合、静态通路门槛和问题定位。接入 `plan-check` 及 `plan-build` 已有冲突回执。归卷阁反例验证梯顶和柜台操作侧，覆盖率测试验证未知与待测权重。
3. 把量表观察接入 `review-record`，复用出图验证及审阅修订。用 `quality-check` 读取最新有效证据，用 `quality-compare` 和 `review-compare` 复验可比项及持续问题。验证换机位、只修一个节点和旧记录过期的结果。
4. 在桌面检查与交付页增加显式评估入口，直接显示共享 Python 报告。跑真实归卷阁相机出图、同机位候选及桌面流程。正式切换默认入口前，按草案独立核对等预算盲评的修复率与路线回归。

## 后续立面频段实验

把建筑表示为沿 Z 排列的一叠 XY 截面，占用数组按 `[Z, Y, X]` 排列。固定每个 `(x, y)`，对 `M[:, y, x]` 沿 Z 做一维实数 FFT，即 `rfft(M, axis=0)`。各评分项在同一份频谱上乘各自的频段掩码，再按原 Z 轴长度做 `irfft(..., n=M.shape[0], axis=0)`，把响应还原到体素坐标，保留 X、Y、Z 三个方向的定位。

| 频段 | 对应的评分证据 |
| --- | --- |
| 低通 | Z 对应进深时，辅助观察前、中、后三段的体量和连续进深。 |
| 高通 | 标出沿 Z 的一格凸出、凹入或构件断头。结合预期构造或同类构件，区分正常边缘与实际偏差。 |
| 带通 | 对沿 Z 重复的梁架或开间，检查预期重复周期附近的响应。例如节距为 6 格时，取每格 `1/6` 周期附近的频段。 |

高通响应同时包含设计中的正常边缘。疑似偏差须对照原始方块、设计位置或同类构件，确认偏差量、世界坐标和构件 ID。玩家通路和净空继续用原始方块状态及碰撞检查，归卷阁移柜堵梯口可用于复查通路判定。

首批对照使用同一建筑的三种梁架布置，分别为沿 Z 规律排列、单跨沿 Z 偏移一格、设计允许的端跨变化。检查能否定位偏移的梁架，以及是否误报允许的端跨变化。反馈记录该跨的构件 ID、设计 Z、实际 Z 和有符号偏差，并用同一范围的原始几何复验。

## 风格评分基线与验证

按已登记的风格特征和适用部位融合证据。低通记录体量，高通记录局部边缘和短尺度细节，按需用带通核对重复节奏，再加入原始构件尺寸和材质角色。每个部位输出 0–4 档，沿用现有量表先汇总适用部位、再按风格特征等权汇总。必经通路、净空和建筑缺陷由原始几何及对应规则复核。频段响应用于提供尺度线索和疑点位置。

MATLAB 用于离线原型验证和实验复现。正式评分沿用现有 Python/NumPy 链路，安装、运行和打包使用现有依赖。

### 离线合成试验结果

试验摘要记录了 8 组建筑用于训练、4 组建筑整栋留出，共 192 个测试样本。样本组成 96 对，同对几何相同，只改变梁材是否符合目标风格。误差为 100 分制的平均绝对误差。

| 模型 | 平均绝对误差 | 96 对样本的排序结果 |
| --- | ---: | --- |
| 仅几何的神经网络 | 12.71 分 | 全部打平 |
| 加入材质的线性模型 | 2.16 分 | 96 对均正确 |
| 加入材质的单隐藏层网络 | 2.21–2.56 分 | 96 对均正确 |

这些结果来自规则生成的标签，支持评分链路验证，并说明材质输入对区分这组构造至关重要。首版基线采用规则加权或线性模型。在按整栋留出的真人评审集上，用同一量表和同一测试划分比较基线与单隐藏层模型，确认后者有增益后再采用。

### Python 量化基线实施

- 在 `plan.quality.style[].sites[].quantitative` 登记固定世界采样范围、按构件拆分的目标体素盒、材质角色、允许的具名构造变体，以及各风格评分项使用的频带。同步工具目录的方案和建模入口契约。
- 在 `nbt_building` 用 NumPy 比较两份已对齐的体素占用场。频带、构件尺寸、材质角色三组证据等权，频带内与构件内按适用项等权。每组先归一至 0–1，综合拟合度按 `floor(4 × 拟合度)` 转成现有档位。登记了机位时，实际审阅作为第四组证据。
- 允许变体由既有方案显式给出。原始方块用于复验位置、尺寸及材质。评分明细列出世界坐标、构件 ID、期望与实际尺寸、测得的位移和材质差异。采样条件、材料角色及计算版本绑定候选对照。
- 回归覆盖规律梁架、单跨沿 Z 偏移一格、允许端跨变化、同几何换错梁材、缺失构件及频带分辨率限制。经建模、制作源回读及 CLI 优先问题验证，使用现有桌面报告显示同一结果。
