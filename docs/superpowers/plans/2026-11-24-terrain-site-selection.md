# 单栋建筑联合选址实施计划

建筑几何保持刚性变换。地基、门外落脚平台及接路在同一次候选评估中检查，以真实编译后的方块差异和静态步行结果排序。候选采用与现有梁架候选相同的工作模型入口，预览和采用分别调用。输入是绑定的制作源或已编译内容哈希的配方，宿主使用现有 WorkingModel。

## 实现与验收

- [x] 在 `nbt_geometry/terrain_roads.py` 复用道路搜索、楼梯放置和逐段步行检查。加入端点保留、失败位置与显式水上桥接。
- [x] 在 `nbt_building/site_selection.py` 枚举调用方声明的 XZ、首层标高、四分之一转与道路选项，受同一组合上限约束。用全模型补丁检查修改预算、已有实例、保护、留白和必需路线。候选分别通过道路、入口和工位检查。
- [x] 注册 `site_selection` 和 `adopt_site_selection`，同步工作模型契约。预览写入新目录及回读回执，采用重新计算绑定的候选并使用现有保存动作落盘。
- [x] 用相同入口亭做平地、坡地、真实水方块河岸与保护反例。每组的固定位置后接路使用同一建筑、道路参数、土方计数和碰撞检查。保存隔离工作区的请求、回执和纹理图，重验源哈希、墙层、继续编辑和拒绝原因。
- [x] 运行 `mise run check`、选址专项、`roads`、`architecture-workflow` 和桌面冒烟。将空间图工作树的归卷阁 SNBT 接入场地选址，验证从既有路口经外廊到收卷台的通路。

选址阶段只支持单栋及单格宽的接路。候选必须使用已提供的场地和道路范围。静态桥跨证据限于桥面净空及步行可达，不作结构荷载或游戏水流仿真。
