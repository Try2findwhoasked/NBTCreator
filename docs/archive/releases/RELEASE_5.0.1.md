# NBTCreator 5.0.1

- 梁架候选可选用原模型中已有的梁柱做局部匹配。报告会标出错位和缺件，候选可按指定高度检查柱间净空。
- 可从已拉正的参考图检测重复纹样，并在平面、圆柱和开放曲面通铺。开口和保护区裁切后保留铺排相位，圆柱闭合会检查周期。
- 可将参考檐口的局部起伏移植到单开间直檐。候选保留屋脊和三轴正投影，并在预览和采用时复验接缝与支承。
- 创作 CLI 评估和整栋建筑评分设计已纳入文档导航。本地和 CI 共用测试套件清单，打包仍走 Windows 验证流程。

## 下载与升级

Windows x64 首次安装可使用完整便携包。已有匹配的运行环境时可下载应用更新包。各 ZIP 随附 SHA-256 和逐文件清单。Python 和 Git 由系统环境提供。

本版本由 Agent 辅助实现与验证。
