# NBTCreator 4.3.2

- 大型建筑可将多个分区登记为一个组装主稿，统一校验墙层、接口和跨分区往返通路。协作切片回装时会检查来源、可写范围和冲突。移动构件或修改尺寸前，可先预检受影响的接口与路线。
- 新增三视图配准、轮廓回投影和同机位 A/B 审阅。可按比例和锚点核对模型与参考图，并保留候选、机位和实际渲染的绑定。
- 曲面建模新增六种可复用模板，支持在偏心和退台表面布置分层凸饰、暗窗与切槽，并检查切深、背衬、保护区和笔画连通性。
- 改善大模型链路，修复批量材质预览天空黑三角，支持大体积快照进入同机位审阅，并在写入时迁移旧版本历史索引中的文本预览。
- 强化 Agent 的候选来源核验、任务回传和冻结渲染运行时恢复。建筑选材补充 1,003 条方块外观标签与实纹理小样复核流程。

## 下载与升级

Windows x64 首次安装可用完整 Portable 包。已有匹配的运行环境时，可下载 app-update 包。ZIP 随附 SHA-256 和逐文件清单。Python 和 Git 由系统环境提供。

本版本由 Agent 辅助实现与验证。
