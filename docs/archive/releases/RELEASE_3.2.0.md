# NBTCreator 3.2.0

本次更新把建筑用途、活动路线和参考图中的构造节点落实到完整模型，并增加曲面屋顶与凹窗立面工具。

## 建筑方案与审阅

- 对外 Skill 区分纯文字和参考图两条初稿路线，补充屋檐、门窗、梁柱交接及参考图未展示部分的设计依据。
- 方案可关联需求、空间、构件和审阅位置，按有序活动检查实际脚位、通路、操作面的方向、工作高度与距离。
- 审阅记录逐项关联机位和位置，交付摘要列出已查通路、已看及待看位置、待回查问题；改模后继续按源版本复验。
- 提供归卷阁和归卷院公共接口样例，对照正常使用、堵住梯顶、站错柜台侧，以及街道到室内的活动路线。

## 构造工具与修复

- `auto_roof` 新增 `curved_hip`，可调整曲率、檐口起翘和翼角，连接相邻屋面顶皮；继续检查保护区、已有占用、范围和写入预算。
- 新增 `facade_compile`，生成真实内退窗洞、窗台和层带，返回开口坐标，并接入对象图与完整工作模型。
- 补齐花植和灯笼的静态碰撞处理，复验对应支撑与通路场景。

## 发布与兼容

本版本由 Agent 辅助实现与集成。版本文件与锁文件同步到 3.2.0，初始效果资源按本次引擎重新生成校验，CI 增加曲面屋顶和建筑开间回归；没有升级依赖或运行环境。

“完善模块化建模对象库”任务不在本次发布范围：新增对象配方库、楼梯扶手与柱式扩展保留在原任务分支。发布内容独立提取，相关参数化契约和界面保持 3.1.0 的版本。

本地验证包括工具目录、Skill、冻结归档、API、桌面烟测、建筑方案、屋顶、立面、碰撞、注册器和工作区回归。Windows 发布门禁另行构建并验证完整 Portable、应用更新包、运行环境包及真实发行版 EXE，全部通过后自动创建 Release。

静态通路与材质预览不证明游戏内表现或审美验收。真实用户看图确认、制作版保存及显式 NBT 定稿导出继续分开执行。
