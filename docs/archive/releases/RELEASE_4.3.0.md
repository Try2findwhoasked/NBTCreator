# NBTCreator 4.3.0

- 外部 Agent 可从工作区入口查看工具路线、检索已启用的参考资料，并读取带来源和行号的摘录。桌面端可预览工作区已启用的知识文档。
- 构件检索支持按关键词浏览候选，并保留素材来源与版本。Agent 任务客户端补充了只读检查、领取和回传的操作指引。
- AI 起草可按选中的设计项提出建议，固定尺寸和项目约束继续生效。润色已有正文时可指定局部修改，并在交接前预览和采用修订稿。
- 只读规划的提示词明确本阶段的检查范围，以及后续制作、精修和定稿所需的确认。
- 项目采用 AGPL-3.0-only，仓库注明了上游来源和适用许可证。

## 下载与升级

Windows x64 首次安装可下载完整 Portable 包。运行环境匹配时可使用 app-update 包，也可下载配套 runtime。各 ZIP 附 SHA-256 和逐文件清单。Python 和 Git 由系统环境提供。

本版本由 Agent 辅助实现与验证。
