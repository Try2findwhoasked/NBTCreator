# NBTCreator 4.0.0

4.0 更新 Minecraft Java 1.20.1 创作工作台，支持按项目管理建筑约束、房间和设计交接，并为外部 Agent 提供可独立运行的 Windows 创作工具。

## 工作台与项目约束

- 项目可按约束组织房间、方案和制作版本。既有项目可通过独立迁移工具预检，再迁移到新目录并验证结果。
- 密闭要求、是否开洞和洞口净尺寸按项目配置。需要接入 SAODG 时，可显式选用独立的 SAODG 约束扩展。
- 更新建筑编辑视图、素材库和构件放置流程。工作台的待领取清单在外部 Agent 接手后移出对应方案。

## 外部 Agent

- 紧凑任务视图展示阶段、约束、源匹配和发布修订差异。完整正文、方案、操作计划和坐标可按需展开。
- 增量诊断对照两次原始回执，识别新增和持续问题，并附回执中的证据位置。审阅摘要列出待看的机位。
- 本地任务客户端支持领取、续租、释放和回传。请求中断后可用原请求编号和参数恢复，避免重复登记。
- 建筑知识书库支持离线索引与按任务检索。内外 Skill 增加纹样选用与细节程度指导。已有创作项目可在应用内同步 Skill 获取新入口。

## 下载与升级

- 首次安装或从旧版升级时可下载 Windows x64 完整 Portable 包。已有匹配运行环境可使用 app-update 包，配套 runtime 也可单独下载。各 ZIP 均附 SHA-256 和逐文件清单。
- 完整 Portable 包内置 Electron、mise 和出图用的 Chromium。请通过系统环境提供 Python 和 Git，启动后可用 `doctor` 核对依赖。
- 整栋初稿继续通过真实缩略图审阅。用户批准后进入精修，正式 NBT 由明确的定稿操作导出。

本版本由 Agent 辅助实现与验证。
