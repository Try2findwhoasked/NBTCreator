# NBTCreator 3.3.0

本次更新整合模块化构件和统一素材库。建筑构件、效果预设与纹样继续使用同一素材工作区；外部素材库可以显式连接，浏览、预览、复制或直接放置。

## 素材来源与安全边界

- 自带 121 项独立素材库快照，涵盖可调配方、精细构件和纹样；构件数据继续在独立的 `NBTCreator-AssetLibrary` 仓库维护。
- 支持本地目录和 HTTPS 素材库的显式发现、连接、刷新、停用、回退和移除。日常列表与已缓存素材读取离线完成；连接和刷新才访问网络。
- 预览、复制及放置绑定素材来源、版本、清单、条目和编译内容的哈希；来源变化时要求重新查看，避免沿用过期预览。外部素材库仅接受受约束的 JSON 数据。
- 复制的构件保留来源记录与待看图状态；直接放置仍经过现有候选、保护和手动导出流程。

## 构件建模与界面

- 新增楼梯扶手、栏杆、柱式、梁、托架和门窗框等模块化配方，并补充尺寸、材质、连接与通路检查。
- 素材工作区统一显示本地、自带和已连接来源。配方可先调整参数并查看真实 3D 预览；本地复制与原来源保持区分。
- 测试按引擎、Node、桌面和共享夹具分层，命令入口及文档同步更新。

## 发布与兼容

本版本由 Agent 辅助生成和集成。`package.json` 与锁文件更新至 3.3.0，初始效果资源按合并后的引擎重新校验；未升级依赖或打包运行环境。Windows 发布门禁新增素材库、模块化构件及统一素材工作区回归。构建通过不代替真实建筑的看图审阅或游戏内验证；制作版保存与显式 NBT 定稿导出仍是独立动作。
