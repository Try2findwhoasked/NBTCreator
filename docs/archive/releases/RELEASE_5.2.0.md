# NBTCreator 5.2.0

- 整栋建筑可先规划楼层、房间面积、楼梯和必要通路，再比较可建造的布局候选。地形选址会同时核对地坪、道路净空、土方和建筑入口。立面可按建筑语境与现有构件尺寸生成候选。
- 整栋初稿支持经济档和最高质量档。外部 Agent 可直接登记建筑要求并接手任务，编译和验证结果会连同审阅证据一并回传。复杂项目可在制作批次冻结参考图、制作源和空间接口，再分区签发任务、核对补丁并合模。
- 建筑审阅会推荐机位和取景范围，记录实景观察，并用同一组机位比较基线和候选。失败回放绑定制作源和复验条件，完整写入后才发布回放包，便于复查受阻路线或不匹配的操作面。
- 物件关系锁可约束构件的承托与接触位置，并在局部编辑时报告受影响的关系。新增参考图家具流程，用于拆分两格高椅、桌和柜的部件，复核纹理预览和安装净空。
- 内置素材库加入 GDMC 建筑素材、原创肋拱与频谱配方。窗列、屋顶尖饰、条纹摊棚和书架墙可调整铺排宽度、周期与相位后预览和放置。部分构件的显示名称已更新。
- 整栋建筑续版可复用输入和承托条件一致的构件及连接，随后重新核对保护区域与实际通路。建筑生成基准按相同预算和验收条件比较各做法，并记录失败原因。

## 下载与升级

Windows x64 首次安装可使用完整便携包。已有匹配的运行环境时可下载应用更新包。各 ZIP 随附 SHA-256 和逐文件清单。Python 和 Git 由系统环境提供。

本版本由 Agent 辅助实现与验证。
