# NBTCreator 4.2.0

- 建筑参考支持连接本地书库、离线检索和按工作流启用。可以主动联网查找公开原页，将可核对的摘录加入参考集合，或收藏后离线检索。
- 建模工具目录补充了按用途查找操作、查询参数和审阅入口。预览修复了书架纹理和天空接缝。通路检查能区分干路障碍并定位梯段失败。
- Agent 任务绑定模型和保护配置。过期会话无法提交新制作版，回传需与任务原版本有可核对的派生关系。明确要求定稿时，使用审阅时记录的源和输入哈希导出。
- 项目修复支持当前的 SNBT 制作源，另存修复候选并保留原文件、方块、墙层及自定义标签。制作版保存和编辑检查共用室内探针校验。
- 开发入口支持通过 mise 启动桌面、检查工具目录和运行现有测试套件。引擎和桌面源码按职责重新归置。

## 下载与升级

Windows x64 首次安装可下载完整 Portable 包。运行环境匹配时可以使用 app-update 包，也可以单独下载配套 runtime。各 ZIP 附 SHA-256 和逐文件清单。Python 和 Git 由系统环境提供。

本版本由 Agent 辅助实现与验证。
