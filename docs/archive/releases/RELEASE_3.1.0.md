# NBTCreator 3.1.0

本次更新完善复杂建筑从设计、生成到审阅回查的流程，并改进提示词编写、AI 输出约束和更新下载。

## 建筑设计与生成

- 可执行建筑方案统一记录空间、楼层、材质角色、共享尺寸、构件与连接关系，使用现有编译工具组合完整主模型。
- 新增全局围护与屋面闭合、梯段支承和直梯护栏、跨高梁及托座；保存前复查实际净空、通路、承托接触、材质和比例。
- 整体、构造、细节三个尺度使用真实相机和纹理图审阅，问题绑定制作源、图像及构件 ID，新版本重新定位和看图。
- 建筑动作、构造系统、设计检查提供注册器；工具参数仍以统一目录为准。查询入口为 `capabilities --architecture`。
- 原版细件进一步参与纹样拟合，包括活板门、石墙等形状；几何拟合、保守碰撞包络与精确支撑分别报告。

## 提示词与 AI

- 提示词方案增加空间体验、材质分工、光线氛围及避免事项等设计项，明确固定或参考尺寸。
- AI 只改写勾选的设计字段；批量任务保留人工模板与改写范围，提示词编写阶段不生成施工工具步骤。
- 增加可选严格 JSON Schema 输出，与本地字段、范围和固定尺寸检查衔接。不支持的接口明确报错，不自动降级。
- 知识读取采用有界并行和相关片段，保留排队时的资料快照、完整人工规则以及显式检索的证据与来源。

## 更新与兼容

- 修复更新检查、凭据操作与下载的互斥、失败状态及重试行为，拒绝缺少完整校验资料的发行包。
- 继续提供完整 Portable、应用更新包和运行环境包，各附 SHA256 与逐文件清单；运行环境不匹配时使用配套包。
- 默认保存 SNBT 制作版；真实用户看图确认和显式 NBT 定稿导出保持独立。已有工作区通过应用同步新 Skill。

## 验证与范围

本地通过 116 项 API 测试、19 项建筑流程测试、31 项桌面烟测，以及主模型、工作区、批量提示词、严格输出和更新重试回归；三种建筑已通过公共 CLI 与冻结入口生成真实预览。初始效果资源已按当前引擎重新生成并校验。

发行门禁继续检查 Windows Portable 构建、解压、独立运行环境和打包版 Electron。静态验证及纹理预览不证明审美质量或游戏内表现；游戏验收记录仍需实际证据。自动护栏目前支持直梯，转弯平台需显式设计，未进行现实结构荷载求解。

本版本由 Agent 辅助实现与集成。详细流程见[建筑方案闭环](https://github.com/Try2findwhoasked/NBTCreator/blob/v3.1.0/.agents/skills/minecraft-nbt-modeler/references/architecture-workflow.md)。
