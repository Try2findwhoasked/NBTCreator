# NBTCreator 5.0.0

- 频谱建模（梁架节奏原型）开放试用。可指定间距、起点、材质和改动区。引擎先检查保护区、留空、支承、通路和改动预算，再用一维 FFT 分析沿纵深排列的周期，结合实测间距、几何和材质给候选排序。预览后可凭候选哈希显式采用。
- 创作 CLI 的速查按任务列出起步命令、参数契约、输入来源和接续步骤。请求文件缺失、JSON 解析、版本绑定过期和输出冲突提供可定位的诊断。
- 整栋建筑质量评分开放试用，覆盖完成度、美观度、玩家通路、风格和细节。报告列出证据覆盖率、必要路线和操作面阻塞，并支持同条件的版本复验。可从 CLI 或桌面显式查看，既有反馈流程继续作为默认入口。
- 修复 Windows 上快速改名后配方列表可能继续显示旧名称的问题。

## 下载与升级

Windows x64 首次安装可使用完整便携包。已有匹配的运行环境时可下载应用更新包。各 ZIP 随附 SHA-256 和逐文件清单。Python 和 Git 由系统环境提供。

本版本由 Agent 辅助实现与验证。
