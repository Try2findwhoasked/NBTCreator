# NBTCreator 4.1.0

## 编辑会话与版本发布

- 启用草稿恢复时，桌面提交版本发布请求前会保存当前编辑会话。若同一建筑已有更新的制作版，当前发布会停止。重新打开原版本可以恢复候选参数、预览和镜头，再核对如何继续编辑。
- 草稿写入遇到暂时错误后，可以重试保存同一候选。原制作源和已发布的新版本继续保留。
- 编辑会话的读取、保存与图片证据恢复移入独立服务模块，继续使用统一的工作区校验和本机 HTTP 访问控制。
- 新增自动化回归，覆盖桌面和 CLI 并发发布、历史派生与 CLI 写入、同一父版本的建筑方案并发重建，以及发布冲突后的桌面重启恢复。

## 下载与升级

首次安装可下载 Windows x64 完整 Portable 包。已有匹配运行环境的安装可使用 app-update 包，配套 runtime 也可单独下载。各 ZIP 附带 SHA-256 和逐文件清单。Python 和 Git 继续由系统环境提供。

本版本由 Agent 辅助实现与验证。
