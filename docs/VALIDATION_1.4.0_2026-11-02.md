# 1.4.0 · 首次创建方案与AI小型结构

- 提示词工作台默认创建完整初稿，不再自动载入正在查看的旧建筑；增加“新建初稿”入口，修改已有作品需主动载入。
- 共用目录清单新增8类建筑形状预设，选择后填写尺寸、占地与cells草案。新建模式隐藏已有主模型/保护/审阅路径，按形状和名称显示只读相对归档根目录；实际版本由Agent按skill分配，不在编辑方案时伪造NBT产物。
- 增加空间分区/楼层高差和玩家动线字段。AI完整初稿方案必须补齐主要设计字段与初始构造步骤；采用后回填表单，再由用户复制给Agent实际制作。阶段、路径、保护与批准不允许由AI改写。
- 模型编辑增加AI小型结构模式和构件参考。候选为受局部范围限制的box/beam/frame步骤，先校验坐标、端点、厚度、材质与数量，采用后追加工具序列并调用本地引擎预览。原模型保持，仍需主动导出。
- 完整提示词保留skill的建模顺序、存放规则、初稿看图与精修确认、原版NBT格式、分项验证和交付要求；初稿总方块量不误用精修变化预算限制。
