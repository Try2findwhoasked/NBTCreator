# 1.7.1 · 部件容错与3D旋转修复

- 原选点模式在OrbitCamera的pointerdown直接拒绝左键，导致无法转视角。现在单击仍选点，拖动超过5像素后转视角，拖动过程不新增标记；适用于评论、取材和AI放置。
- 小型结构最多128步，允许简短blocks/steps格式、数字字符串坐标、缺省说明/归属/总选区、梁宽与边界推导、方块状态对象和carve/air开口。不要求手工补齐样板字段。未声明坐标空间时按API约定的局部相对坐标处理，明确声明全局空间仍拒绝。
- 部件数据规范化后仍检查模型边界、方块状态、保护与变化预算，拒绝代码。既有局部编辑模式保持显式局部选区要求；小型构件可使用当前模型边界作为可用空间，3D放置范围最多64格且不扩展模型。
