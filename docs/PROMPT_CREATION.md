# 首次创建模型与AI方案

提示词方案页默认用于首次创建完整模型，不自动载入模型编辑正在查看的建筑。“新建初稿”清空已有模型关联；“载入当前建筑与参数”才切换到已有模型的只读规划。已有作品精修仍需对应源、保护设置与真实看图确认。

## 形状与保存位置

建筑形状使用skill的8个标准目录键：single、long、square、l_shape、t_shape、cross、irregular、standalone。选择后自动填写尺寸、占地关系和有效cells草案，可再按设计调整；这些是设计起点，不代表实际几何已生成或验证，最终按真实模型登记形状。

新建时不要求填写已有主模型、保护文件或审阅目录。归档根目录由形状与中文名生成相对路径 `nbt_models/<形状>/<中文名>`，字段只读并随名称更新。实际制作由Agent使用skill的nbt_library.py new分配新的日期版本，保存主模型、脚本、NBT、图片、坐标、验证及room_description.json；本页不会仅因选择目录就在磁盘上生成建筑。

## AI完整初稿方案

选择“生成完整初稿方案”，填写主题与用途后生成候选。候选必须包含名称、主题、用途、空间分区、楼层高差、玩家动线、整体材质与构造、顶构、地面、墙面、道具细节及非空构造步骤。审阅并采用后回填左侧，可继续编辑、保存参数和复制完整提示词。

将提示词粘贴给同工作区Agent后，由Agent完成实际建模、密闭后开洞、通路验证与审阅图交付；不能将方案回填或“参数有效”理解为已有NBT、设计已合格或获得精修批准。AI文字润色仍保留本地存放规则、阶段和交付约束。既有源路径、阶段、保护与批准不允许由AI改写。

## 模型编辑的小型结构AI

在“修改范围”中明确局部XYZ选区，再到AI建模选择“AI 添加小型结构”。参考类型有石柱/支承、拱门/门框、台阶/楼梯、平台/桥段和矮墙/护栏，可补充材质、尺度和使用要求。

候选只支持方块区域、梁和边框，最多32步；选区、端点、厚度、材质格式与候选写入量先做本地校验。采用后追加到现有工具序列，交给同一Python引擎计算效果预览；实际状态合法性、保护区和变化预算仍由引擎检查。它不会直接导出或覆盖源文件，满意后点击“导出建筑下一版”。方案生成期间模型或参数发生变化时，需要重新生成候选。

API只发送本次要求、设计参数或局部选区/材质摘要，不自动发送本地路径、完整模型、图片和确认记录。真实API模型可能返回不完整或不合规方案，界面会拒绝或要求重新生成；本机模拟服务联调不能代表真实模型的设计质量。
