## NBTC-004 渲染入口误以 gzip 错误提示不支持的 JSON

- 2026-11-22 登记，源码 `1a809da` 上用合成源复现。
- 普通渲染快照或项目自建的组装清单传给 `render --source`，底层报 `BadGzipFile`。指定 `--snapshot` 时仅接受经校验的控制候选，这是现有入口契约。
- 建议增加显式类型识别和下一步指引。组装主稿的正式支持列在独立开发项。详见[大型建筑复盘](development/LARGE_MODEL_ROADMAP.md#软件问题)。
- 活动源码的 `render --source` 已支持原生组装清单。普通渲染快照和未登记的项目自建清单会得到格式指引，控制候选继续使用 `--snapshot`。
