# NBTCreator 2.0.0

面向建筑师重新整理工作区，保留 AI 编写、人工审查修改、自动保存及人工触发外部建造助手的流程。

- 创作方案支持多条独立提示词、批量生成、逐条审查修改和明确交接；任务与标注接口分离。
- 建筑编辑面板可调整宽度；长名称、分类、说明和标注上下文自动换行，高缩放窗口重新排布操作区。
- 3D 左下角增加 XYZ 方向控件，支持正反六向对齐，保留观察点、距离、图层和剖切，不重建模型。
- 素材库区分建筑构件、装饰构件和效果预设，合并重复管理入口，标记内容哈希相同的构件。原资产及其 ID 保留。
- 制作版采用 SNBT，修复快速目录扫描错误地按 gzip 识别 SNBT 的问题；兼容旧 JSON.GZ 与 NBT，支持继续预览、编辑及保存新版本。
- 标注自动保存至被标注版本；内置 Git 记录版本来源，可对比并从旧版另存。人工定稿后在 `_exports` 镜像层级输出 NBT。

便携版内置 Python、NumPy、Pillow、SNBT 解析库、Chromium 和 Git。完整解压后运行 NBTCreator.exe；选择创作项目作为工作区。用户资产和访问密钥不包含在发行包中。

正常保存、提示词已审查和助手声明完成不构成精修看图批准；定稿导出不代表游戏实测通过。
