# 大型建筑建模复盘与下一步开发

2026-11-22 以艾恩葛朗特浮空城项目回查。案例覆盖参考图配准、曲面外壳、凹刻、独立顶宫安装、分层室内协作及同机位盲评。软件侧对照源码 `1a809da`，现场使用工作区冻结运行时 `5422e25b7f422bd5`。

## 已有工具与能力缺口

### 统一大模型源与分区协作

- 活动引擎的 `Volume` 和 SNBT 读取限制为每轴 294 格。当前源码探针接受 294，拒绝 295。已有 `nbt_whole_cut.py` 可为符合条件的完整主稿生成 48 格分片和回读证据，仍要求 48 网格和有限高度。本案例由项目脚本支持多 Y 层、任意偏移的独立大型建筑。
- `WorkingModel` 已支持作用域补丁、保护与保留盒、`protected_paths` 以及声明路线复查。需要把这些能力带进大模型交接。切片输入须含宿主版本、局部原点、可写域、只读邻区和从全局路线投影来的占位与支撑保护。回传按块状态和墙层校验，过期、越界及相互重叠的写入须明确报告坐标。
- 两类切分分别保存语义。制作源分区用于读写、预览和归档；协作切片用于派工和局部编辑。运行部署所需的格式与接缝检查使用单独规则。用户确认将顶宫从原接合尺寸增高时，由装配变更记录更新边界、落点和路线。

### 从参考图到可编辑构造

- 已有 `geometry.loft`、`section_sweep`、`bezier`。缺的是从多张参考图到这些几何输入的配准与拟合入口。需要按图保存正交方向、原点、比例、像素对应坐标及锚点置信范围，区分原画中的可量读信息和生成图提供的造型建议。使用同尺度回投影与关键构件局部误差，联动高度包围盒和版本。
- 已有 `parametric_surface`、`surface_fit`、`pattern_microfit` 和 `pattern_mount.embed_depth`。平面浅槽嵌入和圆柱外覆已有各自的支持范围。案例需要跨非圆椭圆截面、偏心和退台的曲面 UV 映射，沿实际表面外法线查宿主厚度，并在同一候选内表达凸沿、带背板的凹槽和浅雕。
- 需要将环段、暗缝、竖肋、窗列、斜搭带和裙边分片保存为可复用构件。由同一截面基准生成它们的搭接、厚度和收头，保留规定的非对称性。把纹样作为可复用切割掩模，候选使用合法方块、半砖和楼梯状态，报告实际切深、保留背衬、截断笔画和受保护点。按样段的正面、侧面和剖面校核后扩展到整塔。

### 审阅与验证

- 已有批量材质渲染、机位约束、差异和历史。材质机位目前使用透视参数及 day/night，细刻深度的半格剖切由几何诊断工具提供。需要共享注册后的正交相机和参考图叠层，保存光线方向、色温、背景和曝光，组合形状证据与材质证据。先加入相同机位的背景渲染健全性检查。
- 输出同图源、同机位、同光照、同裁切的匿名 A/B 审阅包。保存比对范围、版本、图像哈希、结论与余差。把整塔远景验收、末端和槽底近景、功能走测、用户确认和游戏实测分开记。局部参数试验和截图可放在有预算的临时批次中，由作者选择何时保存新制作版。

## 开发过程的改进

1. 在出首个样件前写清单位、方向、包围盒、接口以及不确定的图源信息。原画比例、生成参考和用户选定的 50 格顶宫各有用途。固化图源到模型的变换和用户修改尺寸的决定。
2. 先做一段有代表性的叠板或凹刻，固定视角、光照及验收范围，再改整塔。本次早期反复换色和纹样，较晚才稳定区分暗窗、槽、板面和檐口。后续先验开口与背板，再评表面色阶和纹样。亮度对比和渲染光线分开留证。
3. 可写域要从整塔的所有必要路线生成。首次切片仅保护了已知楼层与部分顶宫梯段，漏掉第二段梯的 9 格。使用同一交接工具派发后，还要在临时整塔副本做接缝和往返走测，走测失败先定位最小冲突，再交由该片作者处理。
4. 项目脚本的错误按项目回归处理。曾把 `collision_cells()` 的双元素返回值直接拿去比较完整块占用数，导致背衬诊断误报为零；也曾在项目的平面写入助手中以空材质参数清块，触发 `KeyError`。合并前为整块、半砖和空气三种边界做小探针，统一使用引擎的返回契约，避免各版本脚本靠私有调色板序号传递几何。
5. 产品验收补一套规模相称的、可共享的合成夹具。现有小模型的检查继续保留。新增用例覆盖大主稿载入、保护、轮廓、实际取图、分区回装、历史恢复和各入口错误诊断。避免携带本案例的用户原图、私有路径或存档进入产品仓库。

### 把审阅意见转成可执行修改

本次“凹下去但看起来像贴条”“层次不明显”“两边过于对称”分别涉及几何深度、远景读法与构件布局。工具不应把它们都归成更换材质或增加纹样。建议在审阅记录中保存部位、参考图区域、预期关系、模型版本、观察机位和待复核条件；修改候选关联原意见，保留未解决项。样段的侧视／剖面检查切深、背衬和接触，远景检查大层级，局部图检查窗、斜带和收口。审阅意见和盲评结论均不自动变成用户的精修批准。

独立顶宫的安装还暴露了尺寸决策缺口：原尺寸、可用楼层、接合高度、整体上界和通路会互相影响。后续装配工具应在变换前显示旧／新包围盒、受影响接口和路线，并在用户选择方案后绑定该决策到候选；改变构件、位置或宿主时重新计算。当前可按[参考还原审阅顺序](../guides/ORTHOGRAPHIC_BEZIER_MODELLING.md#参考还原的实际审阅顺序)手工记录，不表示已有自动检查。

协作回装需要可恢复的事务：先校验所有分区基线和坐标变换，再在临时副本合并并检查全局保护及路线；任一片过期、越界、重叠或验收失败时保留原主稿和各片，提供冲突坐标及重试入口。合成验收应覆盖中断后重试、重复回传和负偏移或边界坐标，确保不重复应用、不丢失其他分区修改。以上为待开发要求，现有手工回装不具备完整事务保证。

## 排期和完成条件

| 优先级 | 交付 | 完成条件 |
| --- | --- | --- |
| P0 | 修天空渲染和格式诊断，补预览回归。历史索引改轻量化并补空间预警与失败重试。 | 已知问题三项有对应自动回归。预览仍校验源和图像绑定。历史迁移与并发写入验证通过，草稿和旧版本均可恢复。 |
| P1 | 先实现可登记的稀疏组装主稿，再复用现有 `model`、`render`、`patch` 和路线工具。随后发布带范围和基线的编辑片及回装收据。 | 合成 300 × 384 × 300 模型容纳 y0–293 的建筑，任意合法分区回读后状态、显式墙层和源哈希可核对，路径能跨分区。用四片并行补丁重现楼梯净空冲突，错位与过期时可定位并拒绝，修订回装后入口至上层及返程通过。 |
| P2 | 引入参考注册与正交审阅，再做曲面放样、环段和带深度的布尔纹样。 | 同一组锚点能生成可重复粗模和局部回投影。真实台阶、孔洞和遮蔽推定可分别复核。一个偏心曲面样件同时含斜搭板、暗窗、切槽和实体卷纹，统一检查宿主厚度、保护区、连续性和渲染可读性。 |
| P2 | 将盲评和差异证据做成同机位审阅包，支持局部样件复用。 | 版本、摄像机、光照、裁切与各图 SHA 一致，输入变化时旧证据显式过期。盲评结果和用户批准分别保存。 |

先做 P0。大型主稿和保护交接应早于绑在项目脚本上的新几何工具。直接调大 294 的上限会扩大现有模型和碰撞栅格的分配范围，先用代表性夹具量测载入、补丁、渲染与版本追加的耗时和峰值内存，再确定稀疏存储与局部查询的实现。
